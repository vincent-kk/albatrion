# `VirtualNode.defaultValue`가 읽을 때마다 새 배열을 돌려줍니다

- **종류** — 동작 결함 후보입니다. 소스에서 본 것이며 재현 실행은 하지 않았습니다. 속도 작업 범위 밖이라 고치지 않았습니다.
- **내용** — 값이 바뀌지 않았는데도 `defaultValue`를 두 번 읽으면 서로 다른 튜플 배열 참조가 나옵니다. 패키지 설계 값인 "같은 값을 두 번 읽으면 같은 참조를 돌려준다"와 어긋납니다.
- **영향** — 이 값을 의존성 배열이나 메모 비교에 쓰는 소비자는 매번 바뀐 것으로 보게 됩니다.
- **출처** — `schema-form` 우선순위 2 속도 작업 중 가상 게터 행을 프로파일하다 발견했습니다.

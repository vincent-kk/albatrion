# Tuple Arrays

A Draft 2020-12 tuple uses prefixItems to describe each position. Its validator must understand that dialect. This demo uses Antd6's default array input with the 2020 validator; use its Add action to create items. See [array data and UI](../core-concepts#arrays) for the distinction between item creation and UI slots.

For inferred tuple values and the limits of static length checking, see [TypeScript inference](../api-reference#typescript).

## Select the dialect {#validator}

```ts
import { registerPlugin } from '@canard/schema-form';
import { plugin } from '@canard/schema-form-ajv8-plugin/2020';

registerPlugin(plugin);
```

Use the 2020 entry or another complete validator supporting that dialect. For the package choices and defaults see [validation](../validation#ajv-entries).

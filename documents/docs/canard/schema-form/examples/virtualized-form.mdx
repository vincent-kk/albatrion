# Virtualized Form

Inspect deferred input mounting in this client-rendered example. The full node tree remains available while some input DOM is deferred.

## Live example {#live-demo}

<LazyDemo load={() => import('@site/src/components/demos/examples/VirtualizedFormDemo')} />

This demo uses VirtualizationBackfill.None so scrolling reveals the deferred inputs. For defaults, DOM availability, SSR/hydration, IntersectionObserver fallback, and Suspense limits, see the [virtualization contract](../api-reference#virtualization).

## Usage and evaluation {#usage}

```tsx
import { Form, type JSONSchema, VirtualizationBackfill } from '@canard/schema-form';

const schema: JSONSchema = {
  type: 'object',
  properties: Object.fromEntries(
    Array.from({ length: 40 }, (_, index) => [
      `field_${index}`,
      { type: 'string', default: `value_${index}` },
    ]),
  ),
};

export function DeferredForm() {
  return (
    <Form
      jsonSchema={schema}
      virtualization={{
        threshold: 30,
        eagerCount: 20,
        backfill: VirtualizationBackfill.None,
      }}
    />
  );
}
```

Measure first interaction and the time until every input is available separately. Virtualization can reduce initial DOM work while adding later reveal work; no form-size or mobile timing guarantee follows from enabling it. Use [request-only validation and consumer scheduling](../core-concepts#performance) when those address your measured costs.

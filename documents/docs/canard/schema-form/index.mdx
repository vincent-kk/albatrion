## Coding-agent assets {#agent-assets}

The installed package includes consumer rules, `schema-form-skill`, and its knowledge documents in `docs/agents`. The skill can be loaded for schema-form work or invoked as `/schema-form-skill` in a host that supports that invocation.

After installing `@slats/agents-assets-sync` in your project, preview injection before applying it:

```bash
yarn exec inject-agents-settings --package=@canard/schema-form --agent=claude --scope=project --dry-run
yarn exec inject-agents-settings --package=@canard/schema-form --agent=claude --scope=project
yarn exec inject-agents-settings --package=@canard/schema-form --agent=codex --scope=project
yarn exec inject-agents-settings --package=@canard/schema-form --agent=codex --scope=user
```

`--agent=claude` writes assets under the selected scope's `.claude` location. Codex project scope uses `.agents/skills` and a managed marker block in `AGENTS.md`; Codex user scope uses `~/.codex/skills` and `~/.codex/AGENTS.md`. `--dry-run` previews changes without writing assets. Review divergent local assets before using `--force` to overwrite them.

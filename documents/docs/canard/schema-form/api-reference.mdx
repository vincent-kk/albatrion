# API Reference

Everything on this page is exported from `@canard/schema-form`, unless a type is
marked as shown for reference only.

## `<Form>`

Main schema-driven form component. It takes a JSON Schema, builds the node tree
from `jsonSchema` and `defaultValue`, and renders it. There is no `value` prop:
read values through `onChange`, the `children` function, or the imperative `ref`
API.

### Props

| Prop                     | Type                                                   | Default                  | Description                                                                                                                                   |
| ------------------------ | ------------------------------------------------------ | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `jsonSchema`             | `JSONSchema`                                           | —                        | **Required.** JSON Schema defining the form structure                                                                                         |
| `defaultValue`           | `Value`                                                | `undefined`              | Initial form value                                                                                                                            |
| `onChange`               | `(value: Value) => void`                               | —                        | Called when the form value changes                                                                                                            |
| `onSubmit`               | `(value: Value) => Promise<void> \| void`              | —                        | Called by `submit()` after validation passes                                                                                                  |
| `onValidate`             | `(errors: FieldNode['globalErrors']) => void`          | —                        | Called with the form error list when a validation result or the external error list changes it; a result equal to the previous one is skipped |
| `onStateChange`          | `(state: FieldNode['globalState']) => void`            | —                        | Called when the form's interaction flags (dirty, touched) change                                                                              |
| `onError`                | `(record: FormErrorRecord) => void`                    | —                        | Called with each error record of this form instance, including construction and render failures                                               |
| `onDiagnosticsChange`    | `(diagnostics: FieldNode['diagnostics']) => void`      | —                        | Called when the root diagnostics change after preparation                                                                                     |
| `showError`              | `boolean \| ShowError`                                 | `ShowError.DirtyTouched` | When to display validation errors                                                                                                             |
| `validationMode`         | `ValidationMode`                                       | `OnChange \| OnRequest`  | When validation runs                                                                                                                          |
| `validatorFactory`       | `ValidatorFactory`                                     | plugin validator         | Validator object (`compile` and `compileGuard`); Form prop, then `FormProvider`, then plugin                                                  |
| `readOnly`               | `boolean`                                              | `false`                  | Apply `readOnly` to all inputs                                                                                                                |
| `disabled`               | `boolean`                                              | `false`                  | Apply `disabled` to all inputs                                                                                                                |
| `unsetOnInactive`        | `boolean`                                              | —                        | Form default for `controls.unsetOnInactive`: drop a field's value when it leaves the shape (a node's own policy wins)                         |
| `disableAutomaticWrites` | `boolean`                                              | —                        | Suppress automatic writes without blocking imperative writes                                                                                  |
| `errors`                 | `FieldNode['globalErrors']`                            | `undefined`              | External validation errors; applied after mount and re-applied whenever the array reference changes or the form resets                        |
| `fieldInputDefinitions`  | `FieldInputDefinition[]`                               | —                        | Form-level input component definitions                                                                                                        |
| `fieldInputMap`          | `FieldInputMap`                                        | —                        | Path-based input component overrides                                                                                                          |
| `FieldRenderer`          | `ComponentType<FieldRendererProps>`                    | plugin renderer          | Group renderer used by every field and `Form.Field`                                                                                           |
| `FormLabelRenderer`      | `ComponentType<FieldRendererProps>`                    | plugin renderer          | Renderer used by `Form.Label`                                                                                                                 |
| `FormInputRenderer`      | `ComponentType<FieldRendererProps>`                    | plugin renderer          | Renderer used by `Form.Input`                                                                                                                 |
| `FormErrorRenderer`      | `ComponentType<FieldRendererProps>`                    | plugin renderer          | Renderer used by `Form.Error`                                                                                                                 |
| `formatError`            | `FormatError`                                          | plugin formatter         | Custom error message formatter                                                                                                                |
| `virtualization`         | `boolean \| VirtualizationOptions`                     | off                      | Render-level virtualization (deferred mount) for very large forms                                                                             |
| `context`                | `Dictionary`                                           | —                        | User-defined context, available in all input components; merged over the `FormProvider` context                                               |
| `children`               | `ReactNode \| (props: FormChildrenProps) => ReactNode` | —                        | Custom layout, or a function that receives `{ node, jsonSchema, defaultValue, value, errors }`                                                |
| `ref`                    | `Ref<FormHandle>`                                      | —                        | Imperative handle                                                                                                                             |

`FormErrorRecord` is shown for reference only; it is not exported. `Dictionary` (`Record<string, any>`) is not exported either.

### ShowError Values

```ts
import { ShowError } from '@canard/schema-form';

ShowError.Always; // always show (same as true)
ShowError.Never; // never show (same as false)
ShowError.Dirty; // show when node.state[FieldNodeState.Dirty] is true
ShowError.Touched; // show when node.state[FieldNodeState.Touched] is true
ShowError.DirtyTouched; // show when dirty AND touched (default)
// A node's own node.state[FieldNodeState.ErrorVisible] overrides this policy.
```

### ValidationMode Values

```ts
import { ValidationMode } from '@canard/schema-form';

ValidationMode.None; // disable validation
ValidationMode.OnChange; // validate when the value changes
ValidationMode.OnRequest; // validate only on request; validate() and submit() validate under every mode except None
// Combine with bitwise OR: ValidationMode.OnChange | ValidationMode.OnRequest
```

### Virtualization

Render-level virtualization for very large forms: the node tree is always fully
built (values, validation and submit are unaffected), but off-screen fields
mount as lightweight placeholders and are revealed when they approach the
viewport, on browser idle time, or on `focus`/`select` commands. Reveal is
one-way — a mounted field never returns to a placeholder. Opt-in: pass `true`
for defaults or a `VirtualizationOptions` object.

```tsx
import { Form, VirtualizationBackfill } from '@canard/schema-form';

<Form jsonSchema={largeSchema} virtualization />;
<Form
  jsonSchema={largeSchema}
  virtualization={{ threshold: 50, backfill: VirtualizationBackfill.None }}
/>;
```

| Option           | Type                                            | Default  | Description                                                                                                  |
| ---------------- | ----------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------ |
| `threshold`      | `number`                                        | `30`     | Gate a branch's children only when it has at least this many rendered children                               |
| `eagerCount`     | `number`                                        | `20`     | Leading children per gated branch mounted immediately (prevents a blank first frame)                         |
| `rootMargin`     | `VirtualizationRootMargin`                      | `'100%'` | Pre-mount distance around the viewport; only `px`/`%` units are valid (IntersectionObserver spec)            |
| `backfill`       | `VirtualizationBackfill`                        | `Idle`   | `Idle` progressively mounts the rest during browser idle time; `None` reveals only on visibility or commands |
| `estimateHeight` | `number \| (node: FieldNode) => number`         | `40`     | Placeholder height in px — approximates scroll geometry until reveal                                         |
| `Placeholder`    | `ComponentType<VirtualizationPlaceholderProps>` | —        | Optional component rendered inside placeholders (Suspense-fallback style); receives `{ node, height }`       |

**Placeholder DOM contract** — deferred fields render as
`<div data-path={path} data-deferred aria-hidden style={{ height }} />`: the
same `data-path` identity as mounted wrappers, with `data-deferred` marking the
state. Style skeletons with a plain CSS attribute selector
(`[data-deferred] { … }`) or the `Placeholder` component.

:::warning SSR / hydration
Requires `IntersectionObserver`; when unavailable the option is ignored (with a development-mode warning) and everything mounts eagerly. Do not enable it in SSR/hydration apps —
the server renders all fields while the client would gate them, causing a
hydration mismatch.
:::

See the [Virtualized Form example](./examples/virtualized-form) for a live demo.

## `FormHandle` (ref API)

Obtained via `useRef<FormHandle<typeof schema>>(null)` and passed to the `ref`
prop. Every member except `getAttachedFilesMap` and `showError` addresses the
form's current root node; when the form rebuilds its tree, the handle follows
the new root.

```ts
interface FormHandle<Schema, Value> {
  node?: InferFieldNode<Schema>; // current root node (undefined before the first mount)
  focus(path?: string): void; // focus the input at path (root when omitted)
  select(path?: string): void; // select the input's value at path (root when omitted)
  refresh(path?: string): void; // make the input at path re-read its committed value
  remount(path?: string): void; // remount the rendered subtree at path
  reset(
    option?:
      | typeof SetValueOption.DisableAutomaticWrites
      | typeof SetValueOption.EnableAutomaticWrites,
  ): void; // reload the committed defaults (re-reads jsonSchema and defaultValue)
  findNode(path: string): FieldNode | null;
  findNodes(path: string): readonly FieldNode[];
  getState(): FieldNode['globalState']; // flags true on at least one node
  setState(state: FieldNode['state']): void; // patch flags on every node
  clearState(): void; // clear flags on every node
  getValue(): Value; // current output value
  setValue(
    value: Value | ((prev: Value) => Value),
    options?: SetValueOption,
  ): void;
  getErrors(): FieldNode['globalErrors'];
  getAttachedFilesMap(): AttachedFilesMap; // Map<path, File[]>
  validate(): Promise<FieldNode['globalErrors']>;
  showError(visible?: boolean): void; // true (default) shows every error; false returns to the showError prop
  submit: TrackableHandlerFunction; // callable + subscribe(listener) + pending
}
```

- A `path` that matches no node makes `focus`, `select`, `refresh` and
  `remount` do nothing.
- Before the first mount, queries do not throw: `findNode` returns `null`,
  `findNodes`, `getErrors` and `validate` return an empty array, and
  `getState` returns an empty object.
- `reset()` also empties the attached-files map and drops a `showError(true)`
  override.
- `submit()` validates first and rejects with a `ValidationError` when
  validation fails; `onSubmit` runs only after validation passes. It also rejects with a `SchemaFormError` (`SUBMIT_WHILE_DEGRADED`) when the form's diagnostics are degraded.
- `AttachedFilesMap` and `TrackableHandlerFunction` are shown for reference
  only; they are not exported.

```ts
import { useRef } from 'react';

import type { FormHandle } from '@canard/schema-form';

const schema = {
  type: 'object',
  properties: {
    name: { type: 'string' },
    email: { type: 'string', format: 'email' },
  },
} as const;

const formRef = useRef<FormHandle<typeof schema>>(null);

async function save() {
  const errors = await formRef.current?.validate();
  if (errors?.length) formRef.current?.focus('/email');
}

formRef.current?.setValue({ name: 'Alice' });
formRef.current?.setValue((prev) => ({ ...prev, name: 'Bob' }));
formRef.current?.reset();
```

### SetValueOption

```ts
import { SetValueOption } from '@canard/schema-form';

// Bit flags
SetValueOption.Overwrite; // replace the addressed value (default)
SetValueOption.Merge; // keep omitted object keys, replace the supplied ones
SetValueOption.DisableAutomaticWrites; // suppress automatic writes caused by this call
SetValueOption.EnableAutomaticWrites; // allow automatic writes even when the form suppresses them
// Overwrite and Merge cannot be combined.
```

## Form Sub-Components

All `Form.*` sub-components require a `<Form>` ancestor and use its internal context.
For renderers, the `<Form>` prop wins over `FormProvider`, which wins over the
registered plugin.

### `Form.Field`

Renders a complete field group (label, input and error) through the group
renderer (`FieldRenderer`).

```ts
type FormFieldProps<Value> = {
  path?: string;
  FieldInput?: ComponentType<FieldInputProps<Value>>;
  FieldRenderer?: ComponentType<FieldRendererProps>;
  Wrapper?: ComponentType<PropsWithChildren<Dictionary>>;
} & ChildFieldProps;

type ChildFieldProps<Value> = {
  required?: boolean;
  readOnly?: boolean;
  disabled?: boolean;
  defaultValue?: Value;
  value?: Value;
  onChange?: (
    value: Value | ((prev: Value) => Value),
    options?: SetValueOption,
  ) => void;
  onFileAttach?: (file: File | File[] | undefined) => void;
  FieldRenderer?: ComponentType<FieldRendererProps>;
  className?: string;
  style?: CSSProperties;
  [alt: string]: any; // extra props forwarded to the input component
};
```

```tsx
<Form.Field path="/email" />
<Form.Field path="/birthDate" FieldInput={DatePicker} />
<Form.Field path="/address" Wrapper={({ children }) => <fieldset>{children}</fieldset>} />
```

### `Form.Label`

Renders only the label through `FormLabelRenderer`, inside
`<label htmlFor={path} id={'label:' + path}>`. Accepts `path`, `className` and
`style`.

```tsx
<Form.Label path="/email" className="required-label" />
```

### `Form.Input`

Renders only the input through `FormInputRenderer`. Accepts `path`,
`FieldInput` and the `ChildFieldProps` above; extra props are forwarded to the
input component.

```tsx
<Form.Input path="/email" placeholder="user@example.com" autoComplete="email" />
```

### `Form.Error`

Renders only the error message through `FormErrorRenderer`, inside a `<span>`.
Accepts `path`, `className` and `style`.

```tsx
<Form.Error path="/email" className="error-text" />
```

### `Form.Render`

Low-level slot for custom rendering. Its child is a function that receives the
field's `FieldRendererProps` and returns what to render. It also accepts
`path`, `FieldInput`, `Wrapper` and the `ChildFieldProps` above.

```tsx
<Form.Render path="/status">
  {(props) => (
    <div className={`status-field ${props.value}`}>
      <props.Input />
      {props.errorVisible && <span>{props.errorMessage}</span>}
    </div>
  )}
</Form.Render>
```

### `FormProvider`

Context provider for sharing configuration across a subtree without global
registration. Useful when forms in the same app need different configuration.
Props set on a `<Form>` take precedence over the provider.

| Prop                                                                           | Description                                                                                 |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| `fieldInputDefinitions`                                                        | Input definitions, ranked below the Form's own definitions and above the plugin definitions |
| `FieldRenderer`, `FormLabelRenderer`, `FormInputRenderer`, `FormErrorRenderer` | Renderers for every form in the subtree                                                     |
| `formatError`                                                                  | Error message formatter                                                                     |
| `showError`                                                                    | Error display condition                                                                     |
| `validationMode`                                                               | When validation runs                                                                        |
| `validatorFactory`                                                             | Validator object                                                                            |
| `context`                                                                      | Context merged under each Form's `context`                                                  |

```tsx
import { Form, FormProvider } from '@canard/schema-form';

<FormProvider
  fieldInputDefinitions={customDefinitions}
  FieldRenderer={MyRenderer}
  formatError={myFormatError}
>
  <Form jsonSchema={schema} />
</FormProvider>;
```

## Hooks

### `useFormSubmit`

```ts
const { submit, pending } = useFormSubmit(formRef);
// submit: () => Promise<void>
// pending: boolean | undefined
```

Synchronizes with the form's `submit` handler via `useSyncExternalStore`.
`pending` is `true` while the submission is in flight.

```tsx
import type { RefObject } from 'react';

import { type FormHandle, useFormSubmit } from '@canard/schema-form';

function SubmitButton({ formRef }: { formRef: RefObject<FormHandle | null> }) {
  const { submit, pending } = useFormSubmit(formRef);
  return (
    <button onClick={submit} disabled={pending}>
      {pending ? 'Submitting…' : 'Submit'}
    </button>
  );
}
```

### `useFieldNodeTracker`

```ts
const revision = useFieldNodeTracker(node, tracking?);
// node: FieldNode | null (null tracks nothing)
// tracking: FieldNodeEventType bitmask; default: all events
// Returns a revision number that changes with every matching event and re-renders the component.
```

```tsx
import {
  FieldNodeEventType,
  type NumberNode,
  useFieldNodeTracker,
} from '@canard/schema-form';

function PriceDisplay({ node }: { node: NumberNode }) {
  useFieldNodeTracker(node, FieldNodeEventType.UpdateValue);
  return <span>{node.value}</span>;
}
```

### `useFieldNodeSubscribe`

```ts
useFieldNodeSubscribe(
  node,
  (event) => {
    console.log(event.type, node.value);
  },
  { onSubscribe: (node) => console.log(node.value) }, // optional catch-up
);
// Raw event subscription — does NOT trigger re-render by itself.
```

The listener only sees events delivered after the subscription attaches at
commit. If it mirrors node state, pass `onSubscribe` to re-read the current
state at attach time, or use `useFieldNodeTracker` instead.

### `useChildFieldMap`

```ts
const fields = useChildFieldMap<Value>(ChildFields);
// Takes the ChildFields prop of a FieldInput and returns an object keyed by field name.
// A name with no child field returns a component that renders nothing.
```

```tsx
import { type FieldInputProps, useChildFieldMap } from '@canard/schema-form';

function AddressInput({ ChildFields }: FieldInputProps) {
  const fields = useChildFieldMap<{ street: string; city: string }>(
    ChildFields,
  );
  return (
    <div>
      <fields.street />
      <fields.city />
    </div>
  );
}
```

### `useChildFieldErrors`

```ts
const {
  errorMessage, // formattedError when showError is true, otherwise null
  showError, // the node itself or any direct child passes the showError policy
  formattedError, // first formatted error among the direct children
  showErrors, // showError policy result per direct child
  formattedErrors, // first error of each direct child, formatted with formatError
  errorMatrix, // errors of each direct child
} = useChildFieldErrors(node, disabled?);
```

Reads the errors of `node`'s direct children and re-renders when their
children, state, paths or errors change. With `disabled` set, every child's
error list is empty and every show flag is `false`.

## `registerPlugin`

```ts
registerPlugin(plugin: SchemaFormPlugin | null): void
```

Globally registers a plugin. A plugin whose content fingerprint is already
registered is skipped, so calling with the same plugin object twice is a no-op.
Later registrations override earlier renderers, validator and `formatError`;
their input definitions are ranked ahead of earlier ones.

Call `registerPlugin(null)` to reset all plugins to system defaults.

## `SchemaFormPlugin` Interface

```ts
interface SchemaFormPlugin {
  FieldRenderer?: ComponentType<FieldRendererProps>;
  FormLabelRenderer?: ComponentType<FieldRendererProps>;
  FormInputRenderer?: ComponentType<FieldRendererProps>;
  FormErrorRenderer?: ComponentType<FieldRendererProps>;
  fieldInputDefinitions?: FieldInputDefinition[];
  validator?: ValidatorPlugin;
  formatError?: FormatError;
}
```

## `ValidatorPlugin` Interface

```ts
interface ValidatorPlugin {
  bind?(instance: any): void; // never called by the core; call it yourself before registerPlugin
  compile(jsonSchema: JSONSchema): ValidateFunction;
  compileGuard(root: JSONSchema, pointer: string): (value: unknown) => boolean;
  release?(root: JSONSchema): void; // release a root's resources when its cache entry is evicted
  readonly dialect?: string;
}

type ValidateFunction = (
  data: unknown,
) =>
  | readonly ValidationIssue[]
  | null
  | Promise<readonly ValidationIssue[] | null>;

interface ValidationIssue {
  dataPath: string; // JSON Pointer of the rejected value ('' for the root)
  keyword?: string;
  message?: string;
  schemaPath?: string;
  rejectedKey?: string;
  details?: Record<string, unknown>;
  source?: unknown; // the validator's original issue
}
```

A validator returns `null` for valid data. Guards are synchronous; asynchronous
formats and keywords are not supported in guards.

## `FieldInputProps` Interface

All custom input components registered via `fieldInputDefinitions` receive these props.

```ts
interface FieldInputProps<Value, Context, WatchValues, Schema, Node> {
  jsonSchema: Schema;
  readOnly: boolean;
  disabled: boolean;
  required: boolean;
  node: Node;
  type: Node['type']; // node kind: 'string', 'number', 'object', 'array', 'virtual', 'union', ...
  schemaType: Node['schemaType']; // authored accepted kind(s), including 'integer'
  typeMismatch: Node['typeMismatch']; // stored value mismatches the accepted kinds
  name: Node['name'];
  path: Node['path'];
  nullable: Node['nullable'];
  errors: Node['errors'];
  errorVisible: boolean;
  watchValues: WatchValues; // values read from the controls.watch paths
  defaultValue: Value | undefined;
  value: Value | undefined;
  onChange: (
    value: Value | undefined | ((prev: Value | undefined) => Value | undefined),
    options?: SetValueOption,
  ) => void;
  onFileAttach: (file: File | File[] | undefined) => void;
  ChildFields: ChildField[];
  placeholder: string | undefined;
  className: string | undefined;
  style: CSSProperties | undefined;
  context: Context;
  [alt: string]: any; // extra props from Form.Field / Form.Input
}
```

`ChildField` is shown for reference only; it is not exported. It is a component type carrying `key`, `path` and `field`; type it as `FieldInputProps['ChildFields'][number]`.

## `FieldNode` Interface

`FieldNode` is the union of the node types (`StringNode`, `NumberNode`,
`BooleanNode`, `NullNode`, `ObjectNode`, `ArrayNode`, `VirtualNode`,
`UnionNode`). Every node type shares the members below (abridged).

```ts
interface FieldNode {
  // Identity
  readonly type:
    | 'string'
    | 'number'
    | 'boolean'
    | 'null'
    | 'object'
    | 'array'
    | 'virtual'
    | 'union';
  readonly strategy: 'branch' | 'terminal'; // branch nodes own child nodes
  readonly schemaType: string | readonly string[]; // authored kind(s), including 'integer'
  readonly jsonSchema: Readonly<Record<string, unknown>> | boolean;
  readonly required: boolean;
  readonly nullable: boolean;

  // Tree structure
  readonly depth: number;
  readonly isRoot: boolean;
  readonly rootNode: FieldNode;
  readonly parentNode: FieldNode | null;
  readonly name: string;
  readonly escapedName: string;
  readonly path: string;
  readonly children: readonly FieldNode[] | null; // null on terminal nodes

  // Value
  readonly value: unknown; // typed per node kind
  readonly outputValue: unknown; // emitted value (getValue()): '', [] and {} are omitted unless options.omitEmpty is false
  readonly defaultValue: unknown;
  setValue(value: unknown, option?: SetValueOption): void;
  resetSubtree(option?: SetValueOption): void;

  // Computed properties
  readonly active: boolean; // false while a condition excludes the field
  readonly visible: boolean;
  readonly enabled: boolean; // active and visible
  readonly readOnly: boolean;
  readonly disabled: boolean;
  readonly watchValues: readonly unknown[];
  readonly context: Readonly<Record<string, unknown>>;
  readonly typeMismatch: boolean;

  // State
  state: {
    [FieldNodeState.Dirty]?: boolean; // set on every user input write
    [FieldNodeState.Touched]?: boolean; // set on blur
    [FieldNodeState.ErrorVisible]?: boolean; // overrides the showError policy
    [key: string]: any; // your own flags
  };
  setState(state: FieldNode['state']): void;
  readonly globalState: Readonly<Record<string, boolean | undefined>>; // flags true on at least one node
  setSubtreeState(state: FieldNode['state']): void;
  clearSubtreeState(): void;

  // Errors and validation
  readonly errors: readonly ValidationIssue[]; // displayed validator and external issues
  readonly globalErrors: readonly ValidationIssue[]; // root external issues, then whole-tree validator issues
  setExternalErrors(errors: readonly ValidationIssue[]): void;
  clearExternalErrors(): void;
  validate(): Promise<readonly ValidationIssue[]>;

  // Navigation
  find(pointer?: string | readonly string[] | null): FieldNode | null;
  findNodes(pointer?: string | readonly string[] | null): readonly FieldNode[];

  // Events and requests
  subscribe(listener: (event: { type: number }) => void): () => void; // event.type holds FieldNodeEventType bits
  revision(mask?: FieldNodeEventType): number;
  request(kind: FieldNodeRequestType): void;
  batch(fn: () => void): void; // group synchronous writes into one delivery
}
```

Events and requests use separate enums: `subscribe` delivers
`FieldNodeEventType` bits, and `request` asks the renderer for one action.

```ts
import {
  FieldNodeEventType,
  FieldNodeRequestType,
  FieldNodeState,
} from '@canard/schema-form';

const unsubscribe = node.subscribe((event) => {
  if (event.type & FieldNodeEventType.UpdateValue) console.log(node.value);
});

node.request(FieldNodeRequestType.Focus); // also Select, Refresh, Remount
node.setState({ [FieldNodeState.ErrorVisible]: true });
unsubscribe();
```

## `ArrayNode` Methods

```ts
// ArrayNode = FieldNode members + these methods
interface ArrayNodeMethods<Item> {
  push(value?: Item): number; // append an item; returns the new length
  pop(): Item | undefined; // remove the last item; returns its value
  update(index: number, value: Item): Item | undefined; // replace one position
  remove(index: number): Item | undefined; // remove one position; returns its value
  clear(): void; // remove every item
}
```

`ArrayNodeMethods` is an illustrative name, not an export; use `ArrayNode`. `arrayNode.children` is the list of item nodes on a branch array and `null` on
an array rendered as a single input, so read the count as
`arrayNode.children?.length`. These methods do not enforce `minItems` or
`maxItems`; validation reports them.

## Node Type Guards

```ts
import {
  isArrayNode,
  isBooleanNode,
  isBranchNode,
  isFieldNode,
  isNumberNode,
  isObjectNode,
  isStringNode,
  isTerminalNode,
  isUnionNode,
  isVirtualNode,
} from '@canard/schema-form';

const items = formRef.current?.findNode('/items');
if (items && isArrayNode(items)) {
  items.push(); // TypeScript knows it's ArrayNode here
  items.children?.length;
}
```

`isFieldNode(value: unknown)` checks any value; the other guards take a
`FieldNode`.

## Error Guards

```ts
import {
  isJSONSchemaError,
  isSchemaFormError,
  isUnhandledError,
  isValidationError,
} from '@canard/schema-form';

try {
  await formRef.current?.submit();

  if (isValidationError(error)) console.log('validation failed');

```

## `FormatError` Function

```ts
type FormatError = (
  error: ValidationIssue, // plus an internal `key` for array items
  node: FieldNode,
  context: Dictionary,
) => ReactNode;
```

The default formatter reads `presentation.errorMessages` from the schema and
falls back to `error.message`.

```ts
import type { FormatError } from '@canard/schema-form';

const formatError: FormatError = (error, node) => {
  if (error.keyword === 'required') return `${node.name} is required`;
  if (error.keyword === 'minLength')
    return `Minimum ${error.details?.limit} characters required`;
  return error.message;
};
```

## `JSONPointer`

A constant object holding the path symbols used in node paths, `find()` and
`controls` expressions.

```ts
import { JSONPointer } from '@canard/schema-form';

JSONPointer.Root; // '' — the whole document
JSONPointer.Fragment; // '#'
JSONPointer.Separator; // '/'
JSONPointer.Parent; // '..' (extended syntax)
JSONPointer.Current; // '.' (extended syntax)
JSONPointer.Wildcard; // '*' (extended syntax; matches every child in findNodes())
JSONPointer.Context; // '@' (extended syntax)
```

Escape a key the RFC 6901 way: `~0` for `~` and `~1` for `/`, as in
`node.find('/field~1with~0special')`.

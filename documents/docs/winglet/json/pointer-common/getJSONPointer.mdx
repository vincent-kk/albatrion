# getJSONPointer

Generates a JSON Pointer path from the root object to the target object.
JSON Pointer is a string format according to RFC 6901 specification.

## Signature

```typescript
const getJSONPointer: <Root extends object, Target extends object>(root: Root, target: Target) => string | null
```

## Parameters

| Name | Type | Description |
|------|------|-------------|
| `root` | `-` | Root object to start the search from |
| `target` | `-` | Target object to find |

## Returns

JSON Pointer string to the target object or null if not found

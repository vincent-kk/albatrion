# KeywordDescriptor

A single entry in the traversal vocabulary: which keyword to descend into and how.

## Import

```typescript
import type { KeywordDescriptor } from '@winglet/json-schema/keyword';
import type { KeywordDescriptor } from '@winglet/json-schema/scanner';
import type { KeywordDescriptor } from '@winglet/json-schema/async-scanner';
import type { KeywordDescriptor } from '@winglet/json-schema';
```

## Signature

```typescript
interface KeywordDescriptor {
    keyword: string;
    kind: KeywordKind;
    /** Accepted schema-position dialects; omission accepts every supported dialect. */
    dialects?: readonly Dialect[];
}
```

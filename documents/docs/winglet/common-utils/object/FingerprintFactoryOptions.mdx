# FingerprintFactoryOptions

Sorting is configurable for safe mode; sorted mode always sorts its paths.

## Import

```typescript
import type { FingerprintFactoryOptions } from '@winglet/common-utils/object';
import type { FingerprintFactoryOptions } from '@winglet/common-utils';
```

## Signature

```typescript
export type FingerprintFactoryOptions = FactoryPolicy & ({
    mode?: 'safe';
    sort?: boolean;
} | {
    mode: 'fast' | 'sorted';
    sort?: never;
})
```

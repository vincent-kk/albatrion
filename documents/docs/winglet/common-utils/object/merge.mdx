# merge

Select a deep-merge policy once before entering its recursive implementation.

## Import

```typescript
import { merge } from '@winglet/common-utils/object';
import { merge } from '@winglet/common-utils';
```

## Signature

```typescript
const merge: <Target extends Record<PropertyKey, any>, Source extends Record<PropertyKey, any>>(target: Target, source: Source, options?: MergeOptions) => Target & Source
```

## Parameters

| Name | Type | Description |
|------|------|-------------|
| `target` | `-` | Earlier container; mutated unless options.immutable is true |
| `source` | `-` | Later container, never mutated; undefined does not erase values |
| `options` | `-` | Array, atomicity, reference and mutation policies; omission uses defaults |

## Returns

The mutated target by default, or copies/replacement values under options

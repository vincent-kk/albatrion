# createSafeFingerprint

Creates a sorted, cycle-safe key without constructing graph wire data.

## Import

```typescript
import { createSafeFingerprint } from '@winglet/common-utils/object';
import { createSafeFingerprint } from '@winglet/common-utils';
```

## Signature

```typescript
function createSafeFingerprint(value: unknown, options?: SafeFingerprintOptions): string
```

## Parameters

| Name | Type | Description |
|------|------|-------------|
| `value` | `-` | Data to inspect; opaque values use reference identity, ordinary getters may run. |
| `options` | `-` | Recursive exclusions, optional prefix, and sorting enabled by default. |

## Returns

A comparison key; shared/copy subtrees and array holes/undefined may compare equally.

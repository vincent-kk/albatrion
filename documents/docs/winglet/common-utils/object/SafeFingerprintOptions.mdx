# SafeFingerprintOptions

Cycle-safe key options; sorting can be skipped when insertion order is meaningful.

## Import

```typescript
import type { SafeFingerprintOptions } from '@winglet/common-utils/object';

```

## Signature

```typescript
interface SafeFingerprintOptions extends FingerprintOptions {
    /** Defaults to true; false preserves property insertion order. */
    sort?: boolean;
}
```

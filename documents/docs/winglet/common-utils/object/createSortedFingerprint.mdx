# createSortedFingerprint

Creates a sorted flattened-path key with cycle markers.

## Import

```typescript
import { createSortedFingerprint } from '@winglet/common-utils/object';
import { createSortedFingerprint } from '@winglet/common-utils';
```

## Signature

```typescript
function createSortedFingerprint(value: unknown, options?: FingerprintOptions): string
```

## Parameters

| Name | Type | Description |
|------|------|-------------|
| `value` | `-` | Enumerable data; cycles become markers and Map/Set contents are not traversed. |
| `options` | `-` | Recursive property exclusions and an optional prefix. |

## Returns

A string key retaining the legacy path/type ambiguities.

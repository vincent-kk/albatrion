# @slats

Developer tooling packages for coding-agent integration.

## Packages

| Package | Description |
|---------|-------------|
| [`@slats/agents-assets-sync`](./agents-assets-sync/) | CLI engine that injects a package's agent docs into Claude Code and Codex asset locations |
| [`@slats/claude-assets-sync`](./claude-assets-sync/) | CLI tool to sync Claude commands and skills from npm packages to your project's `.claude/` directory |

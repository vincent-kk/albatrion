# API Reference

Complete reference for all exported functions, components, hooks, and types.

---

## Core Functions

### `alert(options)`

Displays a notification modal. Returns a promise that resolves when the user closes the modal.

```ts
function alert<B = any>(options: AlertProps<B>): Promise<void>
```

**`AlertProps`**

| Property | Type | Default | Description |
|---|---|---|---|
| `title` | `ReactNode` | — | Modal title |
| `subtitle` | `ReactNode` | — | Modal subtitle |
| `content` | `ReactNode \| ComponentType<AlertContentProps>` | — | Modal body content |
| `subtype` | `'info' \| 'success' \| 'warning' \| 'error'` | — | Semantic type passed to components |
| `footer` | `AlertFooterRender \| { confirm?: ReactNode; hideConfirm?: boolean } \| false` | — | Footer config; `false` hides footer |
| `background` | `ModalBackground<B>` | — | Data passed to `BackgroundComponent` |
| `dimmed` | `boolean` | — | Whether to dim backdrop |
| `duration` | `` number \| `${number}ms` \| `${number}s` `` | — | Per-modal animation duration override (ms) |
| `manualDestroy` | `boolean` | `false` | If `true`, modal is not destroyed automatically after closing animation |
| `closeOnBackdropClick` | `boolean` | `true` | Close when backdrop is clicked |
| `group` | `string` | — | Group identifier for ordering |
| `closeOnEscape` | `boolean` | inherits `closeOnBackdropClick` | Escape cancels this modal when true |
| `trapFocus` | `boolean` | `true` | Keeps Tab inside a dimmed top modal |
| `lockScroll` | `boolean` | `true` | Locks body scrolling while a dimmed modal is visible |
| `signal` | `AbortSignal` | — | Aborting cancels the modal with its ordinary cancellation result |
| `ForegroundComponent` | `ComponentType<PropsWithChildren<ModalFrameProps>>` | — | Per-modal foreground override |
| `BackgroundComponent` | `ComponentType<ModalFrameProps>` | — | Per-modal background override |

```ts
await alert({
  title: 'Success',
  content: 'Item saved.',
  subtype: 'success',
  footer: { confirm: 'OK' },
});
```

### `confirm(options)`

Displays a confirmation modal. Returns a promise that resolves to `true` (confirmed) or `false` (cancelled).

```ts
function confirm<B = any>(options: ConfirmProps<B>): Promise<boolean>
```

**`ConfirmProps`** extends `AlertProps` with:

| Property | Type | Default | Description |
|---|---|---|---|
| `footer` | `ConfirmFooterRender \| FooterOptions \| false` | — | Footer config |

**`FooterOptions`**

```ts
interface FooterOptions {
  confirm?: ReactNode;
  hideConfirm?: boolean;
  cancel?: ReactNode;
  hideCancel?: boolean;
}
```

```ts
const confirmed = await confirm({
  title: 'Delete item',
  content: 'This cannot be undone.',
  footer: { confirm: 'Delete', cancel: 'Cancel' },
});
if (confirmed) await deleteItem();
```

---

### `prompt<T>(options)`

Displays an input modal. Returns a promise that resolves to the value entered by the user, or `null` if cancelled. Confirming without any input resolves `undefined`. With `returnOnCancel: true`, a cancel resolves the current value instead (the `defaultValue` before any input).

```ts
function prompt<T, B = any>(options: PromptProps<T, B>): Promise<T | undefined | null>
```

**`PromptProps<T>`** extends `AlertProps` with:

| Property | Type | Default | Description |
|---|---|---|---|
| `Input` | `(props: PromptInputProps<T>) => ReactNode` | **required** | Input component renderer |
| `defaultValue` | `T` | — | Initial value |
| `disabled` | `(value: T \| undefined) => boolean` | — | Disables confirm button when returns `true` |
| `returnOnCancel` | `boolean` | `false` | If `true`, cancellation resolves the current input value instead of `null` (the `defaultValue` before the modal renders) |
| `footer` | `PromptFooterRender<T> \| FooterOptions \| false` | — | Footer config |

**`PromptInputProps<T>`**

```ts
interface PromptInputProps<T, Context = object> {
  value?: T;
  defaultValue?: T;
  onChange: (value: T | undefined | ((current: T | undefined) => T | undefined)) => void;
  onConfirm: () => void;
  onCancel: () => void;
  context: Context;
}
```

```ts
const name = await prompt<string>({
  title: 'Enter name',
  defaultValue: '',
  Input: ({ value, onChange }) => (
    <input value={value ?? ''} onChange={e => onChange(e.target.value)} />
  ),
  disabled: value => !value || value.length < 2,
});
```

## Components

### `ModalProvider`

Must be mounted once at the app root. Initializes the modal service and provides configuration to all modal calls.

```ts
import { ModalProvider, type ModalProviderProps, type ModalProviderHandle } from '@lerx/promise-modal';
```

**Props (`ModalProviderProps`)**

| Prop | Type | Description |
|---|---|---|
| `ForegroundComponent` | `ComponentType<PropsWithChildren<ModalFrameProps>>` | Global modal container/card component |
| `BackgroundComponent` | `ComponentType<ModalFrameProps>` | Global backdrop component |
| `TitleComponent` | `ComponentType<WrapperComponentProps>` | Global title wrapper |
| `SubtitleComponent` | `ComponentType<WrapperComponentProps>` | Global subtitle wrapper |
| `ContentComponent` | `ComponentType<WrapperComponentProps>` | Global content wrapper |
| `FooterComponent` | `ComponentType<FooterComponentProps>` | Global footer component |
| `options` | `ModalOptions` | Global defaults for all modals |
| `context` | `Record<string, any>` | Arbitrary data passed to every component slot |
| `usePathname` | `() => { pathname: string }` | Router hook; a pending modal is hidden, not settled, while the pathname differs from the one it opened on. |
| `root` | `HTMLElement \| null` | Container for the modal portal: omit for `document.body`, pass an element for that container, or `null` to defer until `initialize(element)`. Changing it moves open modals without remounting them. |

**Handle (`ModalProviderHandle`)** — accessed via `ref`:

```ts
interface ModalProviderHandle {
  initialize: (element: HTMLElement) => void;
}
```

A ref does not defer initialization: modals mount into `document.body` unless `root` says otherwise. Pass `root={null}` to wait for `initialize(element)`; the last `root` change or `initialize` call wins, and moving the root keeps open modals, their input and focus.

```tsx
const ref = useRef<ModalProviderHandle>(null);

<ModalProvider ref={ref} root={null}>...</ModalProvider>

// Mount modals into a specific DOM node:
ref.current?.initialize(containerElement);
```

## Hooks

### `useModal(configuration?)`

Returns `alert`, `confirm`, and `prompt` handlers tied to the component's lifecycle. All modals opened through this hook are automatically closed when the component unmounts.

```ts
function useModal(configuration?: OverridableHandleProps): {
  alert: <B>(options: AlertProps<B>) => Promise<void>;
  confirm: <B>(options: ConfirmProps<B>) => Promise<boolean>;
  prompt: <T, B>(options: PromptProps<T, B>) => Promise<T | undefined | null>;
}
```

The optional `configuration` object provides default values merged into every call from this hook instance.

---

### `useInitializeModal(props?)`

Accepts the same props as `ModalProvider`, including `root`; `mode: 'manual'` defers only the initial root until `initialize(element)` or a later `root` change. Always render the returned `portal`.

```ts
function useInitializeModal(props?: ModalProviderProps & { mode?: 'auto' | 'manual' }): {
  initialize: (element: HTMLElement) => void;
  portal: ReactNode;
}
```

---

### `useActiveModalCount(validate?)`

Returns how many modals match `validate`, re-rendering when the store changes; works in any component, including outside `ModalProvider`. Without a predicate it counts visible modals; a custom predicate replaces that default and receives read-only `ModalNodeView` metadata, so include `node.visible` to count only visible matches. Server rendering returns `0`.

```ts
function useActiveModalCount(validate?: (node: ModalNodeView) => boolean | undefined): number
```

---

### `useModalOptions()`

Returns the normalized Provider options, not a modal's per-call overrides. Call it only inside a modal frame, content, input or footer component; elsewhere, including ordinary `ModalProvider` children, it throws.

```ts
function useModalOptions(): Required<Omit<ModalOptions, 'backdrop' | 'duration' | 'closeOnEscape'>> & { backdrop: CSSProperties; duration: `${number}ms`; closeOnEscape?: boolean }
```

---

### `useModalDuration(id?)`

Omit `id` for the Provider duration; pass a live modal id for that modal's own duration (a missing id falls back to the Provider). Modal tree only; throws elsewhere.

```ts
function useModalDuration(id?: number): { duration: `${number}ms`; milliseconds: number }
```

---

### `useModalBackdrop()`

Returns the Provider backdrop as CSS properties. Modal tree only; throws elsewhere.

```ts
function useModalBackdrop(): CSSProperties
```

---

### `useModalAnimation(visible, handlers)`

Fires callbacks when the modal's visibility state changes. Use inside custom `ForegroundComponent` implementations to drive CSS transitions.

```ts
function useModalAnimation(
  visible: boolean,
  handlers: {
    onVisible?: () => void;
    onHidden?: () => void;
  }
): void
```

---

### `useDestroyAfter(modalId, delay)`

Destroys a modal `delay` after it settles; use it in a custom `manualDestroy` frame to remove the frame after its exit animation. It never closes a pending modal, does not start while the modal is only hidden by route, and reschedules when `delay` changes. Modal tree only; throws elsewhere.

```ts
function useDestroyAfter(modalId: number, delay: number | `${number}ms` | `${number}s`): void
```

---

### `useSubscribeModal(id)`

Subscribes to the modal store and returns the publication version of the modal with this id, re-rendering on each change. Works in any component, including outside `ModalProvider`. Pass the `id` a custom frame receives; a missing or destroyed id returns `-1`, and server rendering returns `0`.

```ts
function useSubscribeModal(modalId: number): number
```

## Types

### `ModalFrameProps<Context, B>`

Props received by `ForegroundComponent` and `BackgroundComponent`.

```ts
interface ModalFrameProps<Context = object, B = any> {
  id: number;
  type: 'alert' | 'confirm' | 'prompt';
  subtype?: 'info' | 'success' | 'warning' | 'error';
  group?: string;
  settled: boolean;
  alive: boolean;
  visible: boolean;
  initiator: string;
  manualDestroy: boolean;
  closeOnBackdropClick: boolean;
  background?: ModalBackground<B>;
  onConfirm: () => void;
  onClose: () => void;
  onChange: (value: any) => void;
  onDestroy: () => void;
  onChangeOrder: () => void;
  context: Context;
}
```

### `FooterComponentProps<Context>`

Props received by `FooterComponent`.

```ts
interface FooterComponentProps<Context = object> {
  confirmLabel?: ReactNode;
  hideConfirm?: boolean;
  cancelLabel?: ReactNode;
  hideCancel?: boolean;
  disabled?: boolean;
  onConfirm: () => void;
  onCancel?: () => void;
  context: Context;
}
```

### `WrapperComponentProps<Context>`

Props received by `TitleComponent`, `SubtitleComponent`, `ContentComponent`.

```ts
type WrapperComponentProps<Context = object> = PropsWithChildren<{
  context: Context;
}>;
```

### `ModalBackground<B>`

```ts
interface ModalBackground<B> {
  data?: B;
}
```

### `ModalOptions`

```ts
interface ModalOptions {
  zIndex?: number;
  duration?: number | `${number}ms` | `${number}s`;
  backdrop?: Color | CSSProperties;
  manualDestroy?: boolean;
  closeOnBackdropClick?: boolean;
  /** Escape override; otherwise inherits the backdrop click setting. Escape closes the first accepting visible pending modal from the top. */
  closeOnEscape?: boolean;
  /** Traps Tab only when the top visible pending modal is dimmed; defaults to true. */
  trapFocus?: boolean;
  /** Locks body scrolling while a pending dimmed modal is visible; defaults to true. */
  lockScroll?: boolean;
}
```

### `AlertContentProps`, `ConfirmContentProps`, `PromptContentProps`

Props received by a `content` component when passed as a `ComponentType`.

```ts
// AlertContentProps
type AlertContentProps<Context = object> = {
  onConfirm: () => void;
  context: Context;
};

// ConfirmContentProps
type ConfirmContentProps<Context = object> = {
  onConfirm: () => void;
  onCancel: () => void;
  context: Context;
};

// PromptContentProps = ConfirmContentProps
```

### BaseModal fields (shared by alert/confirm/prompt)

```ts
interface BaseModal<T, B> {
  group?: string;
  subtype?: 'info' | 'success' | 'warning' | 'error';
  title?: ReactNode;
  subtitle?: ReactNode;
  background?: ModalBackground<B>;   // { data?: B }
  dimmed?: boolean;
  duration?: ModalOptions['duration'];
  manualDestroy?: boolean;
  closeOnBackdropClick?: boolean;
  closeOnEscape?: boolean;

  BackgroundComponent?: ComponentType<ModalFrameProps>;
}
```

### Key behavioral rules

- `alert` resolves `void` when any close action fires.
- `confirm` resolves `true` on confirm, `false` on cancel or backdrop click.
- `prompt` resolves the current input value on confirm, `null` on an ordinary cancel, and `undefined` when confirmed without input. With `returnOnCancel: true`, a cancel resolves the current value (the `defaultValue` before any input).
- `manualDestroy: true` keeps the modal node alive after `onClose`; the caller must call `onDestroy` to remove it from the DOM.
- Static `alert`/`confirm`/`prompt` are singletons that persist across component unmounts. `useModal` variants are closed on unmount.
- Custom `ForegroundComponent` receives `visible` (boolean) for driving enter/exit animations and `onDestroy` for deferred cleanup.

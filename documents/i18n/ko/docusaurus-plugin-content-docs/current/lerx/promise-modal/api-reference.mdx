# API 참조 {#api-reference}

내보낸 모든 함수, 컴포넌트, 훅, 타입에 대한 전체 레퍼런스입니다.

---

## 핵심 함수 {#core-functions}

### `alert(options)`

알림 모달을 표시합니다. 사용자가 모달을 닫으면 이행되는 프로미스를 반환합니다.

```ts
function alert<B = any>(options: AlertProps<B>): Promise<void>
```

**`AlertProps`**

| 속성 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `title` | `ReactNode` | — | 모달 제목 |
| `subtitle` | `ReactNode` | — | 모달 부제목 |
| `content` | `ReactNode \| ComponentType<AlertContentProps>` | — | 모달 본문 내용 |
| `subtype` | `'info' \| 'success' \| 'warning' \| 'error'` | — | 컴포넌트에 전달하는 의미적 타입 |
| `footer` | `AlertFooterRender \| { confirm?: ReactNode; hideConfirm?: boolean } \| false` | — | 푸터 설정이며, `false`이면 푸터를 숨깁니다. |
| `background` | `ModalBackground<B>` | — | `BackgroundComponent`에 전달하는 데이터 |
| `dimmed` | `boolean` | — | 백드롭을 어둡게 할지 여부 |
| `duration` | `number` | — | 모달별 애니메이션 지속 시간 재정의 (밀리초) |
| `manualDestroy` | `boolean` | `false` | `true`이면 닫기 애니메이션 후 모달을 자동으로 제거하지 않습니다. |
| `closeOnBackdropClick` | `boolean` | `true` | 백드롭을 클릭하면 닫습니다. |
| `group` | `string` | — | 순서 지정을 위한 그룹 식별자 |
| `handleResolve` | `(result: void \| null) => void` | — | 프로미스가 이행되면 호출합니다. |
| `ForegroundComponent` | `ComponentType<PropsWithChildren<ModalFrameProps>>` | — | 모달별 전경 재정의 |
| `BackgroundComponent` | `ComponentType<ModalFrameProps>` | — | 모달별 배경 재정의 |

```ts
await alert({
  title: 'Success',
  content: 'Item saved.',
  subtype: 'success',
  footer: { confirm: 'OK' },
});
```

### `confirm(options)`

확인 모달을 표시합니다. 확인 시 `true`, 취소 시 `false`로 이행되는 프로미스를 반환합니다.

```ts
function confirm<B = any>(options: ConfirmProps<B>): Promise<boolean>
```

**`ConfirmProps`**는 `AlertProps`를 확장하여 다음 속성을 추가합니다:

| 속성 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `footer` | `ConfirmFooterRender \| FooterOptions \| false` | — | 푸터 설정 |

**`FooterOptions`**

```ts
interface FooterOptions {
  confirm?: ReactNode;
  hideConfirm?: boolean;
  cancel?: ReactNode;
  hideCancel?: boolean;
}
```

```ts
const confirmed = await confirm({
  title: 'Delete item',
  content: 'This cannot be undone.',
  footer: { confirm: 'Delete', cancel: 'Cancel' },
});
if (confirmed) await deleteItem();
```

---

### `prompt<T>(options)`

입력 모달을 표시합니다. 사용자가 입력한 값으로 이행되거나, 취소 시 `undefined`를 반환합니다 (`returnOnCancel` 설정 시 기본값 반환).

```ts
function prompt<T, B = any>(options: PromptProps<T, B>): Promise<T | undefined>
```

**`PromptProps<T>`**는 `AlertProps`를 확장하여 다음 속성을 추가합니다:

| 속성 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `Input` | `(props: PromptInputProps<T>) => ReactNode` | **필수** | 입력 컴포넌트 렌더러 |
| `defaultValue` | `T` | — | 초기 값 |
| `disabled` | `(value: T \| undefined) => boolean` | — | `true`를 반환하면 확인 버튼을 비활성화합니다. |
| `returnOnCancel` | `boolean` | `false` | `true`이면 취소 시 `defaultValue`로 이행됩니다. |
| `footer` | `PromptFooterRender<T> \| FooterOptions \| false` | — | 푸터 설정 |

**`PromptInputProps<T>`**

```ts
interface PromptInputProps<T, Context = object> {
  value?: T;
  defaultValue?: T;
  onChange: (value: T | undefined) => void;
  onConfirm: () => void;
  onCancel: () => void;
  context: Context;
}
```

```ts
const name = await prompt<string>({
  title: 'Enter name',
  defaultValue: '',
  Input: ({ value, onChange }) => (
    <input value={value ?? ''} onChange={e => onChange(e.target.value)} />
  ),
  disabled: value => !value || value.length < 2,
});
```

## 컴포넌트 {#components}

### `ModalProvider`

앱 루트에 한 번만 마운트해야 합니다. 모달 서비스를 초기화하고 모든 모달 호출에 설정을 제공합니다.

```ts
import { ModalProvider, type ModalProviderProps, type ModalProviderHandle } from '@lerx/promise-modal';
```

**속성 (`ModalProviderProps`)**

| 속성 | 타입 | 설명 |
|---|---|---|
| `ForegroundComponent` | `ComponentType<PropsWithChildren<ModalFrameProps>>` | 전역 모달 컨테이너/카드 컴포넌트 |
| `BackgroundComponent` | `ComponentType<ModalFrameProps>` | 전역 백드롭 컴포넌트 |
| `TitleComponent` | `ComponentType<WrapperComponentProps>` | 전역 제목 래퍼 |
| `SubtitleComponent` | `ComponentType<WrapperComponentProps>` | 전역 부제목 래퍼 |
| `ContentComponent` | `ComponentType<WrapperComponentProps>` | 전역 콘텐츠 래퍼 |
| `FooterComponent` | `ComponentType<FooterComponentProps>` | 전역 푸터 컴포넌트 |
| `options` | `ModalOptions` | 모든 모달의 전역 기본값 |
| `context` | `Record<string, any>` | 모든 컴포넌트 슬롯에 전달하는 임의의 데이터 |
| `usePathname` | `() => { pathname: string }` | 경로를 인식하여 모달을 정리하는 사용자 정의 훅 |
| `root` | `HTMLElement \| null` | 모달을 마운트할 DOM 요소 |

**핸들 (`ModalProviderHandle`)** — `ref`로 접근합니다:

```ts
interface ModalProviderHandle {
  initialize: (element: HTMLElement) => void;
}
```

```tsx
const ref = useRef<ModalProviderHandle>(null);
// Mount modals into a specific DOM node:
ref.current?.initialize(containerElement);

<ModalProvider ref={ref}>...</ModalProvider>
```

## 훅 {#hooks}

### `useModal(configuration?)`

컴포넌트 라이프사이클에 연동된 `alert`, `confirm`, `prompt` 핸들러를 반환합니다. 이 훅을 통해 열린 모든 모달은 컴포넌트가 언마운트될 때 자동으로 닫힙니다.

```ts
function useModal(configuration?: OverridableHandleProps): {
  alert: <B>(options: AlertProps<B>) => Promise<void>;
  confirm: <B>(options: ConfirmProps<B>) => Promise<boolean>;
  prompt: <T, B>(options: PromptProps<T, B>) => Promise<T | undefined>;
}
```

선택 사항인 `configuration` 객체는 이 훅 인스턴스의 모든 호출에 병합되는 기본값을 제공합니다.

---

### `useInitializeModal(options?)`

모달 서비스 초기화를 수동으로 제어합니다. 특정 DOM 컨테이너에 모달을 마운트해야 할 때 유용합니다.

```ts
function useInitializeModal(options?: { mode?: 'auto' | 'manual' }): {
  initialize: (element: HTMLElement) => void;
  portal: ReactNode;
}
```

---

### `useActiveModalCount()`

현재 활성화된(열린) 모달의 수를 반환합니다.

```ts
function useActiveModalCount(): number
```

---

### `useModalOptions()`

현재 전역 모달 설정 옵션을 반환합니다.

```ts
function useModalOptions(): ConfigurationContextProps
```

---

### `useModalDuration()`

설정에서 모달 애니메이션 시간을 반환합니다.

```ts
function useModalDuration(): {
  duration: string;     // CSS duration string, e.g. '250ms'
  milliseconds: number; // numeric value, e.g. 250
}
```

---

### `useModalBackdrop()`

설정에서 모달 백드롭 CSS 값을 반환합니다.

```ts
function useModalBackdrop(): string | CSSProperties
```

---

### `useModalAnimation(visible, handlers)`

모달의 가시성 상태가 변경될 때 콜백을 실행합니다. CSS 트랜지션을 구동하기 위해 커스텀 `ForegroundComponent` 구현 내에서 사용하세요.

```ts
function useModalAnimation(
  visible: boolean,
  handlers: {
    onVisible?: () => void;
    onHidden?: () => void;
  }
): void
```

---

### `useDestroyAfter(modalId, delayMs)`

지정된 지연 시간 후 모달을 자동으로 제거합니다. 커스텀 전경 컴포넌트(예: 토스트 알림)에서 사용합니다.

```ts
function useDestroyAfter(modalId: number, delayMs: number): void
```

---

### `useSubscribeModal(modal)`

모달 노드의 상태 변경을 구독하고 현재 버전 번호를 반환합니다. 모달이 업데이트될 때 컴포넌트를 다시 렌더링합니다.

```ts
function useSubscribeModal(modal: ModalNode): number
```

## 타입 {#types}

### `ModalFrameProps<Context, B>`

`ForegroundComponent`와 `BackgroundComponent`가 받는 속성입니다.

```ts
interface ModalFrameProps<Context = object, B = any> {
  id: number;
  type: 'alert' | 'confirm' | 'prompt';
  alive: boolean;
  visible: boolean;
  initiator: string;
  manualDestroy: boolean;
  closeOnBackdropClick: boolean;
  background?: ModalBackground<B>;
  onConfirm: () => void;
  onClose: () => void;
  onChange: (value: any) => void;
  onDestroy: () => void;
  onChangeOrder: () => void;
  context: Context;
}
```

### `FooterComponentProps<Context>`

`FooterComponent`가 받는 속성입니다.

```ts
interface FooterComponentProps<Context = object> {
  confirmLabel?: ReactNode;
  hideConfirm?: boolean;
  cancelLabel?: ReactNode;
  hideCancel?: boolean;
  disabled?: boolean;
  onConfirm: () => void;
  onCancel?: () => void;
  context: Context;
}
```

### `WrapperComponentProps<Context>`

`TitleComponent`, `SubtitleComponent`, `ContentComponent`가 받는 속성입니다.

```ts
type WrapperComponentProps<Context = object> = PropsWithChildren<{
  context: Context;
}>;
```

### `ModalBackground<B>`

```ts
interface ModalBackground<B> {
  data?: B;
}
```

### `ModalOptions`

```ts
interface ModalOptions {
  zIndex?: number;
  duration?: number | string;
  backdrop?: string | CSSProperties;
  manualDestroy?: boolean;
  closeOnBackdropClick?: boolean;
}
```

### `AlertContentProps`, `ConfirmContentProps`, `PromptContentProps`

`content` 컴포넌트가 `ComponentType`으로 전달될 때 받는 속성입니다.

```ts
// AlertContentProps
type AlertContentProps<Context = object> = {
  onConfirm: () => void;
  context: Context;
};

// ConfirmContentProps
type ConfirmContentProps<Context = object> = {
  onConfirm: () => void;
  onCancel: () => void;
  context: Context;
};

// PromptContentProps = ConfirmContentProps
```

### BaseModal 필드 (alert/confirm/prompt 공통) {#basemodal-fields-shared-by-alertconfirmprompt}

```ts
interface BaseModal<T, B> {
  group?: string;
  title?: ReactNode;
  subtitle?: ReactNode;
  background?: ModalBackground<B>;   // { data?: B }
  dimmed?: boolean;
  duration?: number;
  manualDestroy?: boolean;
  closeOnBackdropClick?: boolean;
  handleResolve?: (result: T | null) => void;
  ForegroundComponent?: ComponentType<PropsWithChildren<ModalFrameProps>>;
  BackgroundComponent?: ComponentType<ModalFrameProps>;
}
```

### 주요 동작 규칙 {#key-behavioral-rules}

- `alert`는 어떤 닫기 동작이 발생하든 `void`로 이행됩니다.
- `confirm`은 확인 시 `true`, 취소 또는 백드롭 클릭 시 `false`로 이행됩니다.
- `prompt`는 확인 시 현재 입력 값으로, 취소 시 `undefined`로 이행됩니다 (`returnOnCancel: true`이면 `defaultValue`로 이행됩니다).
- `manualDestroy: true`는 `onClose` 이후에도 모달 노드를 유지합니다. DOM에서 제거하려면 호출자가 `onDestroy`를 호출해야 합니다.
- 정적 `alert`/`confirm`/`prompt`는 컴포넌트가 언마운트되어도 유지되는 싱글턴입니다. `useModal` 변형은 언마운트 시 닫힙니다.
- 사용자 정의 `ForegroundComponent`는 진입/퇴장 애니메이션을 구동하는 `visible`(불리언)과 지연 정리를 위한 `onDestroy`를 받습니다.

# API 참조 {#api-reference}

내보낸 모든 함수, 컴포넌트, 훅, 타입에 대한 전체 레퍼런스입니다.

---

## 핵심 함수 {#core-functions}

### `alert(options)`

알림 모달을 표시합니다. 사용자가 모달을 닫으면 이행되는 프로미스를 반환합니다.

```ts
function alert<B = any>(options: AlertProps<B>): Promise<void>
```

**`AlertProps`**

| 속성 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `title` | `ReactNode` | — | 모달 제목 |
| `subtitle` | `ReactNode` | — | 모달 부제목 |
| `content` | `ReactNode \| ComponentType<AlertContentProps>` | — | 모달 본문 내용 |
| `subtype` | `'info' \| 'success' \| 'warning' \| 'error'` | — | 컴포넌트에 전달하는 의미적 타입 |
| `footer` | `AlertFooterRender \| { confirm?: ReactNode; hideConfirm?: boolean } \| false` | — | 푸터 설정이며, `false`이면 푸터를 숨깁니다. |
| `background` | `ModalBackground<B>` | — | `BackgroundComponent`에 전달하는 데이터 |
| `dimmed` | `boolean` | — | 백드롭을 어둡게 할지 여부 |
| `duration` | `` number \| `${number}ms` \| `${number}s` `` | — | 모달별 애니메이션 지속 시간 재정의 (밀리초) |
| `manualDestroy` | `boolean` | `false` | `true`이면 닫기 애니메이션 후 모달을 자동으로 제거하지 않습니다. |
| `closeOnBackdropClick` | `boolean` | `true` | 백드롭을 클릭하면 닫습니다. |
| `group` | `string` | — | 순서 지정을 위한 그룹 식별자 |
| `closeOnEscape` | `boolean` | `closeOnBackdropClick` 상속 | true이면 Escape가 이 모달을 취소합니다. |
| `trapFocus` | `boolean` | `true` | dimmed 최상위 모달 안에 Tab을 가둡니다. |
| `lockScroll` | `boolean` | `true` | dimmed 모달이 보이는 동안 body 스크롤을 잠급니다. |
| `signal` | `AbortSignal` | — | 중단하면 일반 취소 결과로 모달을 취소합니다. |
| `ForegroundComponent` | `ComponentType<PropsWithChildren<ModalFrameProps>>` | — | 모달별 전경 재정의 |
| `BackgroundComponent` | `ComponentType<ModalFrameProps>` | — | 모달별 배경 재정의 |

```ts
await alert({
  title: 'Success',
  content: 'Item saved.',
  subtype: 'success',
  footer: { confirm: 'OK' },
});
```

---

### `confirm(options)`

확인 모달을 표시합니다. 확인 시 `true`, 취소 시 `false`로 이행되는 프로미스를 반환합니다.

```ts
function confirm<B = any>(options: ConfirmProps<B>): Promise<boolean>
```

**`ConfirmProps`**는 `AlertProps`를 확장하여 다음 속성을 추가합니다:

| 속성 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `footer` | `ConfirmFooterRender \| FooterOptions \| false` | — | 푸터 설정 |

**`FooterOptions`**

```ts
interface FooterOptions {
  confirm?: ReactNode;
  hideConfirm?: boolean;
  cancel?: ReactNode;
  hideCancel?: boolean;
}
```

```ts
const confirmed = await confirm({
  title: 'Delete item',
  content: 'This cannot be undone.',
  footer: { confirm: 'Delete', cancel: 'Cancel' },
});
if (confirmed) await deleteItem();
```

---

### `prompt<T>(options)`

입력 모달을 표시합니다. 사용자가 입력한 값으로 이행되거나, 취소 시 `null`로 이행됩니다. 입력 없이 확인하면 `undefined`로 이행됩니다. `returnOnCancel: true`이면 취소 시 현재 값(입력 전에는 `defaultValue`)으로 이행됩니다.

```ts
function prompt<T, B = any>(options: PromptProps<T, B>): Promise<T | undefined | null>
```

**`PromptProps<T>`**는 `AlertProps`를 확장하여 다음 속성을 추가합니다:

| 속성 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `Input` | `(props: PromptInputProps<T>) => ReactNode` | **필수** | 입력 컴포넌트 렌더러 |
| `defaultValue` | `T` | — | 초기 값 |
| `disabled` | `(value: T \| undefined) => boolean` | — | `true`를 반환하면 확인 버튼을 비활성화합니다. |
| `returnOnCancel` | `boolean` | `false` | `true`이면 취소 시 `null` 대신 현재 입력값으로 이행됩니다(렌더 전에는 `defaultValue`). |
| `footer` | `PromptFooterRender<T> \| FooterOptions \| false` | — | 푸터 설정 |

**`PromptInputProps<T>`**

```ts
interface PromptInputProps<T, Context = object> {
  value?: T;
  defaultValue?: T;
  onChange: (value: T | undefined | ((current: T | undefined) => T | undefined)) => void;
  onConfirm: () => void;
  onCancel: () => void;
  context: Context;
}
```

```ts
const name = await prompt<string>({
  title: 'Enter name',
  defaultValue: '',
  Input: ({ value, onChange }) => (
    <input value={value ?? ''} onChange={e => onChange(e.target.value)} />
  ),
  disabled: value => !value || value.length < 2,
});
```

## 컴포넌트 {#components}

### `ModalProvider`

앱 루트에 한 번만 마운트해야 합니다. 모달 서비스를 초기화하고 모든 모달 호출에 설정을 제공합니다.

```ts
import { ModalProvider, type ModalProviderProps, type ModalProviderHandle } from '@lerx/promise-modal';
```

**속성 (`ModalProviderProps`)**

| 속성 | 타입 | 설명 |
|---|---|---|
| `ForegroundComponent` | `ComponentType<PropsWithChildren<ModalFrameProps>>` | 전역 모달 컨테이너/카드 컴포넌트 |
| `BackgroundComponent` | `ComponentType<ModalFrameProps>` | 전역 백드롭 컴포넌트 |
| `TitleComponent` | `ComponentType<WrapperComponentProps>` | 전역 제목 래퍼 |
| `SubtitleComponent` | `ComponentType<WrapperComponentProps>` | 전역 부제목 래퍼 |
| `ContentComponent` | `ComponentType<WrapperComponentProps>` | 전역 콘텐츠 래퍼 |
| `FooterComponent` | `ComponentType<FooterComponentProps>` | 전역 푸터 컴포넌트 |
| `options` | `ModalOptions` | 모든 모달의 전역 기본값 |
| `context` | `Record<string, any>` | 모든 컴포넌트 슬롯에 전달하는 임의의 데이터 |
| `usePathname` | `() => { pathname: string }` | 라우터 훅입니다. 미확정 모달은 열린 pathname과 다른 동안 확정되지 않고 숨겨집니다. |
| `root` | `HTMLElement \| null` | 모달 포털의 컨테이너입니다. 생략하면 `document.body`, 요소를 주면 그 컨테이너, `null`이면 `initialize(element)`까지 초기화를 미룹니다. 바꾸면 열린 모달을 다시 마운트하지 않고 옮깁니다. |

**핸들 (`ModalProviderHandle`)** — `ref`로 접근합니다:

```ts
interface ModalProviderHandle {
  initialize: (element: HTMLElement) => void;
}
```

ref만으로는 초기화가 미뤄지지 않으며, `root`를 지정하지 않으면 모달은 `document.body`에 마운트됩니다. `initialize(element)`까지 기다리려면 `root={null}`을 전달합니다. 마지막 `root` 변경 또는 `initialize` 호출이 우선하며, root를 옮겨도 열린 모달과 입력, 포커스가 유지됩니다.

```tsx
const ref = useRef<ModalProviderHandle>(null);

<ModalProvider ref={ref} root={null}>...</ModalProvider>

// Mount modals into a specific DOM node:
ref.current?.initialize(containerElement);
```

## 훅 {#hooks}

### `useModal(configuration?)`

컴포넌트 라이프사이클에 연동된 `alert`, `confirm`, `prompt` 핸들러를 반환합니다. 이 훅을 통해 열린 모든 모달은 컴포넌트가 언마운트될 때 자동으로 닫힙니다.

```ts
function useModal(configuration?: OverridableHandleProps): {
  alert: <B>(options: AlertProps<B>) => Promise<void>;
  confirm: <B>(options: ConfirmProps<B>) => Promise<boolean>;
  prompt: <T, B>(options: PromptProps<T, B>) => Promise<T | undefined | null>;
}
```

선택 사항인 `configuration` 객체는 이 훅 인스턴스의 모든 호출에 병합되는 기본값을 제공합니다.

---

### `useInitializeModal(props?)`

`ModalProvider`와 같은 props(`root` 포함)를 받습니다. `mode: 'manual'`은 `initialize(element)` 또는 이후 `root` 변경까지 초기 root만 미룹니다. 반환된 `portal`은 항상 렌더링합니다.

```ts
function useInitializeModal(props?: ModalProviderProps & { mode?: 'auto' | 'manual' }): {
  initialize: (element: HTMLElement) => void;
  portal: ReactNode;
}
```

---

### `useActiveModalCount(validate?)`

`validate`와 일치하는 모달 수를 반환하고 저장소가 바뀌면 다시 렌더링합니다. `ModalProvider` 밖을 포함한 모든 컴포넌트에서 사용할 수 있습니다. 판별 함수가 없으면 보이는 모달을 세며, 사용자 판별 함수는 이 기본값을 대체하고 읽기 전용 `ModalNodeView`를 받으므로 보이는 모달만 세려면 `node.visible`을 포함합니다. 서버 렌더는 `0`을 반환합니다.

```ts
function useActiveModalCount(validate?: (node: ModalNodeView) => boolean | undefined): number
```

---

### `useModalOptions()`

모달별 호출 재정의가 아닌 정규화된 Provider 옵션을 반환합니다. 모달 프레임·내용·입력·푸터 컴포넌트 안에서만 호출하며, 일반 `ModalProvider` 자식을 포함한 그 밖에서는 예외를 던집니다.

```ts
function useModalOptions(): Required<Omit<ModalOptions, 'backdrop' | 'duration' | 'closeOnEscape'>> & { backdrop: CSSProperties; duration: `${number}ms`; closeOnEscape?: boolean }
```

---

### `useModalDuration(id?)`

`id`를 생략하면 Provider 지속시간, 살아 있는 모달 id를 주면 그 모달의 지속시간을 반환하며 없는 id는 Provider 값으로 대체합니다. 모달 트리 안에서만 사용할 수 있으며 그 밖에서는 예외를 던집니다.

```ts
function useModalDuration(id?: number): { duration: `${number}ms`; milliseconds: number }
```

---

### `useModalBackdrop()`

Provider 백드롭을 CSS 속성으로 반환합니다. 모달 트리 안에서만 사용할 수 있으며 그 밖에서는 예외를 던집니다.

```ts
function useModalBackdrop(): CSSProperties
```

---

### `useModalAnimation(visible, handlers)`

모달의 가시성 상태가 변경될 때 콜백을 실행합니다. CSS 트랜지션을 구동하기 위해 커스텀 `ForegroundComponent` 구현 내에서 사용하세요.

```ts
function useModalAnimation(
  visible: boolean,
  handlers: {
    onVisible?: () => void;
    onHidden?: () => void;
  }
): void
```

---

### `useDestroyAfter(modalId, delay)`

모달이 확정된 뒤 `delay`가 지나면 파괴합니다. 사용자 정의 `manualDestroy` 프레임에서 종료 애니메이션 뒤 프레임을 제거할 때 사용합니다. 미확정 모달을 닫지 않고 경로 숨김만으로 시작하지 않으며 `delay`가 바뀌면 다시 예약합니다. 모달 트리 안에서만 사용할 수 있으며 그 밖에서는 예외를 던집니다.

```ts
function useDestroyAfter(modalId: number, delay: number | `${number}ms` | `${number}s`): void
```

---

### `useSubscribeModal(id)`

모달 저장소를 구독하고 이 id를 가진 모달의 발행 버전을 반환하며 변경될 때마다 다시 렌더링합니다. `ModalProvider` 밖을 포함한 모든 컴포넌트에서 사용할 수 있습니다. 사용자 정의 프레임이 받는 `id`를 전달하며, 없거나 파괴된 id는 `-1`, 서버 렌더는 `0`을 반환합니다.

```ts
function useSubscribeModal(modalId: number): number
```

## 타입 {#types}

### `ModalFrameProps<Context, B>`

`ForegroundComponent`와 `BackgroundComponent`가 받는 속성입니다.

```ts
interface ModalFrameProps<Context = object, B = any> {
  id: number;
  type: 'alert' | 'confirm' | 'prompt';
  subtype?: 'info' | 'success' | 'warning' | 'error';
  group?: string;
  settled: boolean;
  alive: boolean;
  visible: boolean;
  initiator: string;
  manualDestroy: boolean;
  closeOnBackdropClick: boolean;
  background?: ModalBackground<B>;
  onConfirm: () => void;
  onClose: () => void;
  onChange: (value: any) => void;
  onDestroy: () => void;
  onChangeOrder: () => void;
  context: Context;
}
```

### `FooterComponentProps<Context>`

`FooterComponent`가 받는 속성입니다.

```ts
interface FooterComponentProps<Context = object> {
  confirmLabel?: ReactNode;
  hideConfirm?: boolean;
  cancelLabel?: ReactNode;
  hideCancel?: boolean;
  disabled?: boolean;
  onConfirm: () => void;
  onCancel?: () => void;
  context: Context;
}
```

### `WrapperComponentProps<Context>`

`TitleComponent`, `SubtitleComponent`, `ContentComponent`가 받는 속성입니다.

```ts
type WrapperComponentProps<Context = object> = PropsWithChildren<{
  context: Context;
}>;
```

### `ModalBackground<B>`

```ts
interface ModalBackground<B> {
  data?: B;
}
```

### `ModalOptions`

```ts
interface ModalOptions {
  zIndex?: number;
  duration?: number | `${number}ms` | `${number}s`;
  backdrop?: Color | CSSProperties;
  manualDestroy?: boolean;
  closeOnBackdropClick?: boolean;
  /** 이스케이프 재정의입니다. 지정하지 않으면 백드롭 클릭 설정을 따릅니다. 이스케이프는 위에서부터 처음으로 수락하는 표시 중인 대기 모달을 닫습니다. */
  closeOnEscape?: boolean;
  /** 맨 위에 표시된 대기 모달이 딤 처리된 경우에만 Tab 이동을 가둡니다. 기본값은 true입니다. */
  trapFocus?: boolean;
  /** 딤 처리된 대기 모달이 표시되는 동안 본문 스크롤을 잠급니다. 기본값은 true입니다. */
  lockScroll?: boolean;
}
```

### `AlertContentProps`, `ConfirmContentProps`, `PromptContentProps`

`content` 컴포넌트가 `ComponentType`으로 전달될 때 받는 속성입니다.

```ts
// AlertContentProps
type AlertContentProps<Context = object> = {
  onConfirm: () => void;
  context: Context;
};

// ConfirmContentProps
type ConfirmContentProps<Context = object> = {
  onConfirm: () => void;
  onCancel: () => void;
  context: Context;
};

// PromptContentProps = ConfirmContentProps
```

### 내보내기 {#exports}

```ts
export function alert<B = any>(options: AlertProps<B>): Promise<void>

export function useModalDuration(id?: number): { duration: `${number}ms`; milliseconds: number }
export function useModalBackdrop(): CSSProperties
export function useModalAnimation(visible: boolean, handlers: { onVisible?(); onHidden?() }): void
export function useDestroyAfter(modalId: number, delay: number | `${number}ms` | `${number}s`): void
```


### 주요 동작 규칙 {#key-behavioral-rules}

- `alert`는 어떤 닫기 동작이 발생하든 `void`로 이행됩니다.
- `confirm`은 확인 시 `true`, 취소 또는 백드롭 클릭 시 `false`로 이행됩니다.
- `prompt`는 확인 시 현재 입력 값으로, 일반적인 취소 시 `null`로, 입력 없이 확인하면 `undefined`로 이행됩니다. `returnOnCancel: true`이면 취소 시 현재 값(입력 전에는 `defaultValue`)으로 이행됩니다.
- `manualDestroy: true`는 `onClose` 이후에도 모달 노드를 유지합니다. DOM에서 제거하려면 호출자가 `onDestroy`를 호출해야 합니다.
- 정적 `alert`/`confirm`/`prompt`는 컴포넌트가 언마운트되어도 유지되는 싱글턴입니다. `useModal` 변형은 언마운트 시 닫힙니다.
- 사용자 정의 `ForegroundComponent`는 진입/퇴장 애니메이션을 구동하는 `visible`(불리언)과 지연 정리를 위한 `onDestroy`를 받습니다.

`@canard/schema-form`을 위한 Material UI v7 플러그인입니다.
`@mui/material ^7.0.0`과 MUI X 날짜/시간 선택기 기반의 15개 폼 입력 컴포넌트를 제공합니다.
MUI의 `size`, `variant`, `fullWidth` 컨텍스트 옵션을 지원합니다.

## 설치 {#installation}

```bash
yarn add @canard/schema-form-mui-plugin
```

### 피어 의존성 {#peer-dependencies}

```bash
yarn add @mui/material@>=7.0.0 @mui/x-date-pickers@>=8.0.0 \
         @mui/icons-material@>=7.0.0 \
         @emotion/react@>=11.0.0 @emotion/styled@>=11.0.0 \
         dayjs@>=1 react@>=18 react-dom@>=18
```

```ts
import { registerPlugin } from '@canard/schema-form';
import { plugin } from '@canard/schema-form-mui-plugin';

registerPlugin(plugin);
```

## 컴포넌트 매핑 {#component-mapping}

컴포넌트는 JSON Schema 속성에 따라 자동으로 선택됩니다. 우선순위는 아래 목록 순서와 같으며, 맨 위가 가장 높습니다.

| 컴포넌트 | type | format | inputType | enum | 참고 사항 |
|---|---|---|---|---|---|
| `FieldInputBooleanSwitch` | `boolean` | — | `"switch"` | — | MUI Switch |
| `FieldInputStringCheckbox` | `array` | — | `"checkbox"` | items.enum | MUI Checkbox 그룹이며, items는 문자열 스키마여야 합니다. |
| `FieldInputStringSwitch` | `string` | — | `"switch"` | 값 2개 | 두 enum 값 사이를 전환합니다. |
| `FieldInputUri` | `string` | `"uri"` 또는 inputType `"uri"` | — | — | 프로토콜 드롭다운이 있는 URI 입력 |
| `FieldInputMonth` | `string` | `"month"` | — | — | MUI X MonthPicker |
| `FieldInputDate` | `string` | `"date"` | — | — | MUI X DatePicker |
| `FieldInputTime` | `string` | `"time"` | — | — | MUI X TimePicker (HH:mm:00Z 형식) |
| `FieldInputRadioGroup` | `string` \| `number` \| `integer` | — | `"radio"` 또는 `"radiogroup"` | 필수 | MUI RadioGroup |
| `FieldInputStringEnum` | `string` | — | — | 필수 | MUI Select 드롭다운 |
| `FieldInputArray` | `array` | — | — | — | 추가/제거가 가능한 동적 목록 |
| `FieldInputSlider` | `number` \| `integer` | — | `"slider"` | — | MUI Slider |
| `FieldInputTextarea` | `string` | `"textarea"` 또는 inputType `"textarea"` | — | — | MUI TextField 여러 줄 입력 |
| `FieldInputString` | `string` | — | — | — | MUI TextField (`format:"password"`로 비밀번호 지원) |
| `FieldInputNumber` | `number` \| `integer` | — | — | — | MUI TextField의 type=number |
| `FieldInputBoolean` | `boolean` | — | — | — | `indeterminate` 상태를 지원하는 MUI Checkbox |

## 스키마 확장 속성 {#schema-extension-properties}

```ts
{
  inputType?: 'switch' | 'radio' | 'radiogroup' | 'checkbox' | 'slider' | 'textarea' | 'uri',
  format?:   'date' | 'time' | 'month' | 'password' | 'uri' | 'textarea',
}
```

## 사용 예제 {#usage-example}

```tsx
import { Form } from '@canard/schema-form';

const schema = {
  type: 'object',
  properties: {
    name:     { type: 'string' },
    age:      { type: 'integer' },
    active:   { type: 'boolean', presentation: { inputType: 'switch' } },
    role:     { type: 'string', enum: ['admin', 'user', 'guest'] },
    birthday: { type: 'string', format: 'date' },
    bio:      { type: 'string', format: 'textarea' },
    score:    { type: 'number', presentation: { inputType: 'slider' }, minimum: 0, maximum: 100 },
  },
};

<Form jsonSchema={schema} onChange={setValue} />
```

## MUI 컨텍스트 {#mui-context}

`<Form context={...}>`를 통해 MUI 스타일 옵션을 전달하십시오:

```ts
type MuiContext = {
  size?:      'small' | 'medium';
  variant?:   'outlined' | 'filled' | 'standard';
  fullWidth?: boolean;
};
```

```tsx
<Form
  jsonSchema={schema}
  context={{ size: 'small', variant: 'outlined', fullWidth: true }}
  onChange={setValue}
/>
```

## 날짜/시간 선택기 설정 {#datetime-picker-setup}

MUI X 날짜 선택기는 `LocalizationProvider`가 필요합니다. 앱을 다음과 같이 감싸십시오:

```tsx
import { LocalizationProvider } from '@mui/x-date-pickers';
import { AdapterDayjs } from '@mui/x-date-pickers/AdapterDayjs';

<LocalizationProvider dateAdapter={AdapterDayjs}>
  <Form jsonSchema={schema} onChange={setValue} />
</LocalizationProvider>
```

### 컴포넌트 매핑 (우선순위 높은 순) {#component-mapping-priority-order-high--low}
| 컴포넌트 | 선택 조건 |
|---|---|
| BooleanSwitch | `boolean` + `inputType: "switch"` |
| StringCheckbox | `array` + `inputType: "checkbox"` + items.enum |
| StringSwitch | `string` + `inputType: "switch"` + enum 값 2개 |
| Uri | `string` + `format: "uri"` |
| Month / Date / Time | `string` + `format: "month"/"date"/"time"` (MUI X 선택기) |
| RadioGroup | `string\|number` + `inputType: "radio"` + enum |
| StringEnum | `string` + enum (MUI Select) |
| Array | `array` (동적 목록) |
| Slider | `number` + `inputType: "slider"` |
| Textarea | `string` + `format: "textarea"` (여러 줄 TextField) |
| String | `string` (TextField, 비밀번호 지원: `format: "password"`) |
| Number | `number\|integer` (TextField의 type=number) |
| Boolean | `boolean` (`indeterminate` 상태를 지원하는 Checkbox) |

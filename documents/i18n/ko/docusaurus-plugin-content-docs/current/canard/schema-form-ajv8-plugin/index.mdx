`@canard/schema-form`을 위한 AJV 8.x 검증 플러그인으로, 권장 validator 플러그인입니다.
JSON Schema Draft-07, Draft 2019-09, Draft 2020-12를 지원합니다.
세 가지 서브패스 익스포트를 통해 필요한 Draft를 정확히 선택할 수 있습니다.

:::tip 공식 문서
- [AJV 8 문서](https://ajv.js.org/)
- [JSON Schema Draft 2020-12](https://json-schema.org/draft/2020-12/json-schema-core)
:::

## 설치 {#installation}

```bash
yarn add @canard/schema-form @canard/schema-form-ajv8-plugin
# ajv@^8 is bundled as a direct dependency
```

## 서브패스 내보내기 {#subpath-exports}

| 가져오기 경로 | 지원 Draft | AJV 내부 가져오기 |
|---|---|---|
| `@canard/schema-form-ajv8-plugin` | Draft-07 (기본값) | `ajv` |
| `@canard/schema-form-ajv8-plugin/2019` | Draft 2019-09 | `ajv/dist/2019` |
| `@canard/schema-form-ajv8-plugin/2020` | Draft 2020-12 | `ajv/dist/2020` |

## 빠른 설정 {#quick-setup}

```ts
import { registerPlugin } from '@canard/schema-form';
import { plugin } from '@canard/schema-form-ajv8-plugin';

registerPlugin(plugin);
```

```ts
// Draft 2019-09
import { plugin } from '@canard/schema-form-ajv8-plugin/2019';
registerPlugin(plugin);
```

```ts
// Draft 2020-12
import { plugin } from '@canard/schema-form-ajv8-plugin/2020';
registerPlugin(plugin);
```

## 기본 설정 {#default-configuration}

```ts
// Internal defaults applied when no custom AJV instance is bound
// Same across all three subpath exports
{
  allErrors: true,          // collect all errors, not just the first
  strict: false,            // disable all strict-mode checks
  validateFormats: false,   // format validation disabled for performance
  allowUnionTypes: true,    // accept type arrays without strict-type logging
  multipleOfPrecision: 9,   // accept decimal multiples such as 19.99 for multipleOf: 0.01
}
```

## 사용자 정의 AJV 인스턴스 {#custom-ajv-instance}

```ts
import Ajv from 'ajv';
import { plugin } from '@canard/schema-form-ajv8-plugin';

const ajv = new Ajv({ allErrors: true, strict: false });

plugin.validator.bind(ajv);
```

```ts
// Draft 2020-12 with format validation enabled
import Ajv2020 from 'ajv/dist/2020.js';
import addFormats from 'ajv-formats';
import { plugin } from '@canard/schema-form-ajv8-plugin/2020';

const ajv = new Ajv2020({ allErrors: true, strict: false });
addFormats(ajv);
plugin.validator.bind(ajv);
```

## 인스턴스 요구 사항 {#instance-requirements}

- `bind`, `createValidator`, `createValidatorFactory`는 `coerceTypes`, `useDefaults`, `removeAdditional` 중 하나가 켜진 인스턴스에 `ValidatorBindRefusedError`(`group: 'UNHANDLED_ERROR'`, `code: 'UNHANDLED_ERROR.VALIDATOR_BIND_REFUSED'`)를 던집니다. 나중에 이 옵션을 켜면 다음 검증 또는 가드 컴파일이 예외를 던집니다. 데이터를 수정해야 하는 코드에는 별도의 AJV 인스턴스를 사용하십시오.
- 플러그인은 폼 루트를 사적 컴파일러에서 컴파일하며 루트의 `$id`를 애플리케이션 인스턴스에 추가하지 않습니다. 애플리케이션 코드가 조회하거나 다른 루트가 참조하는 스키마는 `addSchema`로 등록하고, 비동기 검증이 필요하면 `$async: true`를 선언하십시오.
- 사용자 지정 AJV 하위 클래스는 생성자에서 스키마나 메타 스키마를 등록하지 않아야 합니다. 인스턴스를 생성한 뒤 등록하십시오.

## `createValidatorFactory` 직접 사용하기 {#using-createvalidatorfactory-directly}

```ts
import Ajv from 'ajv';
import { createValidatorFactory } from '@canard/schema-form-ajv8-plugin';

const ajv = new Ajv({ allErrors: true });
const validate = createValidatorFactory(ajv)(myJSONSchema);

const errors = await validate(formData); // null | ValidationIssue[]
```

## `createValidator`로 Form별 검증기 만들기 {#per-form-validator-with-createvalidator}

`createValidator(ajv, options?)`는 `plugin.validator`와 독립된 완전한 검증기 객체를 돌려주며 Form의 `validatorFactory`에 전달합니다. 새 객체는 Form이 트리를 다시 만들게 하므로 렌더 밖에서 한 번만 만드십시오.

```tsx
import { Form } from '@canard/schema-form';
import { createValidator } from '@canard/schema-form-ajv8-plugin';
import Ajv from 'ajv';

const validator = createValidator(new Ajv({ allErrors: true, strict: false }));
const schema = { type: 'object', properties: { name: { type: 'string' } } } as const;

export const NameForm = () => <Form jsonSchema={schema} validatorFactory={validator} />;
```

## 검증 플러그인 비교 {#validator-plugin-comparison}

| 기능 | ajv6-plugin | ajv7-plugin | ajv8-plugin |
|---|---|---|---|
| Draft-04 | 바인딩한 인스턴스에 Draft-04 메타 스키마와 `schemaId` 설정 필요 | 아니요 | 아니요 |
| Draft-06 | 바인딩한 인스턴스에 메타 스키마 필요 | 바인딩한 인스턴스에 메타 스키마 필요 | 기본 진입점 인스턴스에 메타 스키마 필요 |
| Draft-07 | 예 | 예 | 예 |
| Draft 2019-09 | 아니요 | `Ajv2019` 인스턴스 바인딩 필요 | 예 (`/2019`) |
| Draft 2020-12 | 아니요 | 아니요 | 예 (`/2020`) |
| 서브패스 내보내기 | 아니요 | 아니요 | 예 |
| 오류 경로 | 원래 JSON Pointer (`jsonPointers: true`) | 원래 JSON Pointer | 원래 JSON Pointer |
| 권장 대상 | 레거시 스키마 | 마이그레이션 단계 | **신규 프로젝트** |

## AI 참조 {#ai-reference}

**패키지**: `@canard/schema-form-ajv8-plugin`
**목적**: AJV 8.x 검증 플러그인으로, 신규 프로젝트에 권장합니다. Draft-07, 2019-09, 2020-12를 지원합니다.

### 내보내기 (3가지 서브패스 변형에서 동일한 API 제공) {#exports-3-subpath-variants-each-exports-the-same-api}
```ts
import { plugin, createValidator, createValidatorFactory } from '@canard/schema-form-ajv8-plugin';       // Draft-07
import { plugin, createValidator, createValidatorFactory } from '@canard/schema-form-ajv8-plugin/2019';  // Draft 2019-09
import { plugin, createValidator, createValidatorFactory } from '@canard/schema-form-ajv8-plugin/2020';  // Draft 2020-12
```

### 사용법 {#usage}
```ts
registerPlugin(plugin);                         // use default AJV config
plugin.validator.bind(new Ajv({ ... }));        // bind custom AJV instance
createValidatorFactory(ajv)(schema);            // standalone usage without plugin
createValidator(ajv);                            // per-Form validatorFactory object
```

### 기본 AJV 설정 (모든 서브패스) {#default-ajv-config-all-subpaths}
`{ allErrors: true, strict: false, validateFormats: false, allowUnionTypes: true, multipleOfPrecision: 9 }`

### Draft 선택 가이드 {#draft-selection-guide}
| 서브패스 | AJV 가져오기 | 사용 조건 |
|---|---|---|
| `/` (기본값) | `ajv` | Draft-07 스키마 (가장 일반적) |
| `/2019` | `ajv/dist/2019` | `$recursiveRef`, `unevaluatedProperties`가 필요한 경우 |
| `/2020` | `ajv/dist/2020` | `$dynamicRef`, `prefixItems`가 필요한 경우 |

# 빠른 시작



## 설치와 플러그인 선택 {#installation}

```bash
yarn add @canard/schema-form
# Optional validator and UI integration:
yarn add @canard/schema-form-ajv8-plugin @canard/schema-form-antd6-plugin
```

코어에는 기본 렌더러와 입력이 있어 UI 플러그인은 선택 사항입니다. 검증기를 선택하지 않으면 검증 요청은 판정 없이 경고를 내며, `if` gate에는 동기 검증기 guard가 필요합니다. 배포된 검증 플러그인을 선택하거나 완전한 `validatorFactory` 객체를 전달하십시오. [검증](./validation#validator-contract)을 참조하십시오.

Ant Design 5에는 `@canard/schema-form-antd5-plugin`, Ant Design 6에는 `@canard/schema-form-antd6-plugin`, Ant Design Mobile에는 `@canard/schema-form-antd-mobile-plugin`, MUI에는 `@canard/schema-form-mui-plugin`을 사용하십시오. MUI 패키지 이름은 `schema-form-mui-plugin`입니다. `@canard/schema-form-antd-plugin`은 `@canard/schema-form-antd5-plugin`으로 바꾸십시오.

## 선언된 실행 환경 요구사항 {#compatibility}

코어의 peer 범위는 `react >=18 <20`, `react-dom >=18 <20`입니다. 코어와 아래 플러그인은 `engines` 필드와 브라우저 최소 버전을 선언하지 않습니다. 문법 target만으로 특정 Node.js·브라우저가 모든 런타임 API와 UI 의존성을 지원한다고 보장할 수 없습니다.

| 패키지 | 선언된 peer와 직접 UI / 검증기 의존성 |
| --- | --- |
| AJV 6 / 7 / 8 플러그인 | 직접 의존성 `ajv ^6.0.0` / `^7.0.0` / `^8.0.0`; 코어 peer 선언 없음 |
| antd-mobile | React / React DOM `>=18 <20`, dayjs `>=1`; 직접 의존성 `antd-mobile ^5.0.0`, dayjs `^1.0.0` |
| antd5 | React / React DOM `>=18 <20`, antd `>=5.10.0`, dayjs `>=1`; 직접 의존성 antd `^5.10.0`, icons `^5.0.0` |
| antd6 | React / React DOM `>=18 <20`, antd `>=6.0.0`, dayjs `>=1`; 직접 의존성 antd `^6.0.0`, icons `^6.0.0` |
| MUI | React / React DOM `>=18 <20`, Material / icons `>=7.0.0`, X date pickers `>=8.0.0`, Emotion react / styled `>=11.0.0`, dayjs `>=1` |

MUI 플러그인의 직접 의존성은 MUI 7, MUI X 8, Emotion 11, dayjs 1 계열입니다. UI 라이브러리와 플러그인의 계열을 맞추십시오. Ant Design의 CSS variable 기본값과 theme 설정은 [Ant Design v6 이전 문서](https://ant.design/docs/react/migration-v6/)를 따르십시오. 이 안내는 해당 의존성의 기본값을 별도로 정하지 않습니다.

## 트랜스파일과 CSP {#transpilation-csp}

배포된 ES2020 문법을 해석하지 못하는 환경을 대상으로 하면 코어와 실제 사용하는 외부 `@winglet` 패키지를 트랜스파일에 포함하십시오. 대상은 `@winglet/common-utils`, `@winglet/json`, `@winglet/json-schema`, `@winglet/react-utils`입니다. UI 플러그인 번들도 같은 기준으로 확인하십시오. 트랜스파일만으로 누락된 API가 생기지는 않습니다. AJV 어댑터는 `WeakRef`, `FinalizationRegistry`를 사용합니다.

문자열 controls 표현식은 `new Function`으로 컴파일합니다. 동적 함수 컴파일을 금지하는 CSP에서는 해당 표현식을 그대로 실행할 수 없습니다. 표현식 기반 controls를 도입하기 전에 정책을 확인하십시오.

## 렌더링 전 등록 {#registration}

```tsx
import { Form, registerPlugin } from '@canard/schema-form';
import { plugin as validatorPlugin } from '@canard/schema-form-ajv8-plugin';
import { plugin as uiPlugin } from '@canard/schema-form-antd6-plugin';

registerPlugin(validatorPlugin);
registerPlugin(uiPlugin);

const schema = {
  type: 'object',
  properties: { text: { type: 'string' } },
} as const;

export function BasicForm() {
  return <Form jsonSchema={schema} onChange={console.log} />;
}
```

등록은 전역에 적용됩니다. 동일 내용의 플러그인은 hash로 중복을 제거하며 검증기와 UI 플러그인 사이의 고정 등록 순서는 없습니다. Form이 설정을 캡처하기 전에 등록을 마치십시오. 하위 트리의 기본 설정은 [FormProvider](./api-reference#plugins)를 사용하십시오.

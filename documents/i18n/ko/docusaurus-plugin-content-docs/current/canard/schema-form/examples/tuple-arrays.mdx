# tuple 배열

Draft 2020-12 tuple은 prefixItems로 위치별 schema를 지정합니다. 검증기는 해당 dialect를 지원해야 합니다. 코어 내장 배열 입력은 prefixItems를 읽지 않으므로 이 예제는 tuple UI를 별도로 제공합니다.

## dialect 선택 {#validator}

```ts
import { registerPlugin } from '@canard/schema-form';
import { plugin } from '@canard/schema-form-ajv8-plugin/2020';

registerPlugin(plugin);
```

2020 진입점 또는 해당 dialect를 지원하는 완전한 검증기를 사용하십시오. 패키지 선택과 기본값은 [검증](../validation#ajv-entries)에 있습니다.

## 출력 패널 읽기 {#reading-output}

행 세 개를 추가하고 비워 두면 JSON 표시는 다음과 같습니다.

| 경로 | 옵션 | JSON 표시 |
| --- | --- | --- |
| /tags | omitTrailing: true | 키 없음 |
| /notes | 기본값 | [null, null, null] |
| /aliases | omitTrailing: true, omitEmpty: false | [] |

JSON.stringify는 배열의 undefined 슬롯을 null로 표시하며 명시적 null 쓰기와는 다릅니다. 검증은 방출 출력을 읽으므로 채운 행 하나와 생략된 후행 빈 행은 길이 1로 검사합니다. branch 배열의 행 수는 node.children?.length로 세고 node.outputValue와 별도로 비교하십시오. terminal 배열에는 자식 노드가 없습니다.

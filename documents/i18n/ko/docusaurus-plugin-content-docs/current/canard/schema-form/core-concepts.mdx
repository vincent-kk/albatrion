# Core Concepts

## JSON Schema as the Single Source of Truth

폼 구조, 필드 타입, 검증 규칙, 조건부 로직은 모두 단일 JSON Schema 객체에 인코딩됩니다.
라이브러리는 마운트 시 이 스키마를 파싱하여 내부 **노드 트리**를 구성합니다 —
스키마 필드당 하나의 노드. 컴포넌트 코드에서 폼 필드나 검증 규칙을 수동으로 정의할 필요가 없습니다.

```ts
const schema = {
  type: 'object',
  properties: {
    title: { type: 'string', minLength: 1 },
    price: { type: 'number', minimum: 0 },
    inStock: { type: 'boolean' },
    tags: { type: 'array', items: { type: 'string' } },
  },
  required: ['title', 'price'],
};
// → ObjectNode
//     ├── StringNode  (title)
//     ├── NumberNode  (price)
//     ├── BooleanNode (inStock)
//     └── ArrayNode   (tags)
//           └── StringNode (items)
```

## Node Tree

각 노드는 자체 값, 검증 오류, `node.state`의 상호작용 플래그(`FieldNodeState`
키: `Dirty`, `Touched`, `ShowError`)를 소유하는 반응형 객체입니다. 변경 사항은 위로 전파됩니다: 리프 노드의 값이 변경되면
모든 상위 노드가 `UpdateValue` 이벤트를 받고 집계된 값을 업데이트합니다.

### Node State Flags

| Property       | Type                         | Description                                                                    |
| -------------- | ---------------------------- | ------------------------------------------------------------------------------ |
| `value`        | `any`                        | Current value                                                                  |
| `outputValue`  | `unknown`                    | Emitted value after output filters                                             |
| `defaultValue` | `unknown`                    | Value at initialization                                                        |
| `errors`       | `readonly ValidationIssue[]` | Validation issues for this node                                                |
| `state`        | `NodeStateFlags`             | Interaction flags keyed by `FieldNodeState` (`Dirty`, `Touched`, `ShowError`) |
| `visible`      | `boolean`                    | From `controls.visible`                                                        |
| `active`       | `boolean`                    | From `controls.active`                                                         |
| `readOnly`     | `boolean`                    | From `controls.readOnly`, the standard `readOnly`, or inherited                |
| `disabled`     | `boolean`                    | From `controls.disabled` or inherited                                          |
| `required`     | `boolean`                    | Field is required in parent schema                                             |
| `nullable`     | `boolean`                    | Schema type includes `"null"`                                                  |

### Node Navigation

```ts
// Absolute path from root (RFC 6901 JSONPointer)
const node = rootNode.find('/address/street');

// Relative path from current node
const sibling = node.find('./city');

// Find all matching nodes
const allItems = rootNode.findNodes('/items/*');
```

## Plugin Architecture

라이브러리는 두 개의 독립적인 플러그인 레이어로 분리되어 있습니다.
어떤 validator와 UI 라이브러리도 조합할 수 있습니다.

```
┌─────────────────────────────────────────────────────┐
│                  SchemaFormPlugin                    │
│                                                      │
│  FieldRenderer   FormLabelRenderer       │  ← UI layer
│  FormInputRenderer   FormErrorRenderer       │
│  fieldInputDefinitions                            │
├─────────────────────────────────────────────────────┤
│                  ValidatorPlugin                     │
│                                                      │
│  bind?(instance)                                     │  ← Validation layer
│  compile(jsonSchema) → ValidateFunction              │
│  compileGuard(root, pointer) → (value) => boolean    │
└─────────────────────────────────────────────────────┘
```

### Plugin Merge Behavior

When multiple plugins are registered, the merge rules are:

| Property                                                                                           | Merge strategy               |
| -------------------------------------------------------------------------------------------------- | ---------------------------- |
| `FieldRenderer`, `FormLabelRenderer`, `FormInputRenderer`, `FormErrorRenderer` | Last wins                    |
| `fieldInputDefinitions`                                                                         | Prepended (first match wins) |
| `validator`                                                                                        | Last wins                    |
| `formatError`                                                                                      | Last wins                    |

## FieldInput System

`FieldInputDefinition`은 **테스트 조건**과
**React 컴포넌트**를 쌍으로 연결합니다. 라이브러리는 등록된 모든 정의를
우선순위 순서로 평가하고, 첫 번째 매칭 컴포넌트를 사용하여 필드를 렌더링합니다.

```ts
// Object test — declarative
const definition: FieldInputDefinition = {
  test: { type: 'string', format: 'date' },  // matches date fields
  Component: DatePickerInput,
};

// Function test — imperative
const definition: FieldInputDefinition = {
  test: (hint) => hint.jsonSchema.widget === 'richtext',
  Component: RichTextEditor,
};

// Hint object available in test function:
type Hint = {
  type: JSONSchemaType;       // 'string' | 'number' | 'boolean' | ...
  path: string;               // JSONPointer path
  required: boolean;
  nullable: boolean;
  jsonSchema: JSONSchema;
  format?: string;
  inputType?: string;         // jsonSchema.presentation.inputType
};
```

inputType은 정의의 test가 해석하는 문자열 힌트이며 HTML input type과 같지 않습니다.

### FieldInputMap (path-based override)

```ts
// Map specific paths to specific components
const fieldInputMap: FieldInputMap = {
  '/user/avatar':     AvatarUploader,
  '/items/*/price':   CurrencyInput,   // * matches any segment
};

<Form jsonSchema={schema} fieldInputMap={fieldInputMap} />
```

## Controls

필드는 `controls` 키의 JSONPointer 표현식을 사용하여
형제 또는 부모 값에 반응할 수 있습니다. 의존성은 각 표현식의 경로에서 자동으로
추적되며, `watch`는 다른 값을 구독해 입력에 `watchValues` prop으로 전달합니다.

```ts
{
  type: 'object',
  properties: {
    isPremium: { type: 'boolean' },
    discount: {
      type: 'number',
      controls: {
        visible:  '../isPremium === true',   // show only for premium
        readOnly: '../isPremium === false',  // lock if not premium
        watch: ['../isPremium'],             // passed as watchValues (optional)
      },
    },
  },
}
```

자주 쓰는 `controls` 키: `active`, `visible`, `readOnly`, `disabled`, `derived`,
`watch`. 키 목록은 닫혀 있어서, 모르는 키가 있으면 스키마가 스키마 오류
`UNKNOWN_GROUP_KEY`로 실패합니다.

### JSONPointer Extensions (controls expressions)

| Syntax     | Meaning                                        |
| ---------- | ---------------------------------------------- |
| `../field` | Parent node's `field`                          |
| `./field`  | Current node's `field` (relative)              |
| `..`       | Navigate to parent                             |
| `*`        | Wildcard — any segment (FieldInputMap only) |

## Schema Composition

라이브러리는 모든 표준 JSON Schema 구성 키워드를 지원합니다.
`oneOf`와 `anyOf` 브랜치는 게이트를 통과하는 동안에만 참여합니다. 게이트는
브랜치의 `controls.active` 표현식이거나, 호스트의 `controls.discriminator`와
각 브랜치의 `const`/`enum` 태그입니다. 게이트가 없으면 모든 브랜치가 켜집니다.

```ts
// Standard if/then/else
{
  if:   { properties: { type: { enum: ['movie'] } } },
  then: { properties: { releaseDate: { type: 'string', format: 'date' } } },
  else: { properties: { version:     { type: 'string' } } },
}

// oneOf with controls.active (exclusive branches)
{
  oneOf: [
    { controls: { active: "./type === 'movie'" }, properties: { director: { type: 'string' } } },
    { controls: { active: "./type === 'game'" },  properties: { platform: { type: 'string' } } },
  ],
}

// anyOf with controls.active (non-exclusive, multiple can be active)
{
  anyOf: [
    { controls: { active: './flag1 === true' }, properties: { field1: { type: 'string' } } },
    { controls: { active: './flag2 === true' }, properties: { field2: { type: 'string' } } },
  ],
}

// allOf (always merged)
{
  allOf: [
    { properties: { firstName: { type: 'string' } } },
    { properties: { lastName:  { type: 'string' } } },
    { required: ['firstName', 'lastName'] },
  ],
}
```

### Conditional setValue Filtering

**부모 노드**가 `setValue()`를 호출하면, 활성 `oneOf`/`anyOf`
브랜치와 일치하지 않는 필드는 자동으로 값에서 제거됩니다. **자식 노드**가
`setValue()`를 호출하면 이 필터링이 우회됩니다 — 현재 브랜치 조건과
관계없이 값이 전파됩니다.

## Array Output Filters

배열 스키마는 `options` 아래에 출력 필터를 지정할 수 있습니다. 이 필터는
배열이 **내보내는 값** — 부모 전파, 루트 validation, 외부 표면(`onChange`,
`getValue()`, `submit`) — 만 정제하며, 자식 노드와 raw `node.value`는 모든
항목을 유지하므로 미리 노출한 빈 input이 그대로 렌더링됩니다.

```tsx
const jsonSchema = {
  type: 'array',
  minItems: 3, // 빈 input 3개가 먼저 렌더링됨
  items: { type: 'string' },
  options: { omitTrailing: true },
};
// 사용자가 첫 번째 input만 채우면:
// getValue() / onChange / validation 값은 ['first']
```

- **`omitTrailing`** (opt-in)은 **후행** 연속 `undefined` 항목만 제거합니다.
  선행·중간 `undefined`는 보존되어 error `dataPath`와 validation index
  정합이 유지됩니다.
- **`omitEmpty`** (기본 활성)는 빈 배열을 부모 전파 경로에서 `undefined`로
  변환합니다. 필터 순서는 `omitTrailing → omitEmpty`입니다.
- 정제된 출력은 `node.outputValue`로 노출되고 `node.value`는 raw를
  유지합니다. 커스텀 배열 `FieldInput`에서는 행 수를 `value.length`가
  아니라 `node.children` 기준으로 세야 합니다.

## Validation System

### ValidationMode

```ts
enum ValidationMode {
  None      = 0,   // No automatic validation
  OnChange  = 1,   // Validate after every setValue()
  OnRequest = 2,   // Validate only when validate() is called
}

// Default: OnChange | OnRequest (bitwise OR)
<Form validationMode={ValidationMode.OnChange | ValidationMode.OnRequest} />
```

### ShowError

```ts
enum ShowError {
  Always       = 1,   // always show
  Never        = 2,   // never show
  Dirty        = 4,   // show when the Dirty flag is set
  Touched      = 8,   // show when the Touched flag is set
  DirtyTouched = 16,  // show when both Dirty AND Touched are set (default)
}

<Form showError={ShowError.DirtyTouched} />  // default
<Form showError={true} />                    // same as ShowError.Always
<Form showError={false} />                   // same as ShowError.Never
```

### Error Structure

```ts
interface ValidationIssue {
  dataPath: string; // JSONPointer to the failing field ('' for the root)
  keyword?: string; // JSON Schema keyword (e.g., 'minLength', 'required')
  message?: string;
  schemaPath?: string; // authored schema location
  rejectedKey?: string; // rejected property key, when there is one
  details?: Record<string, unknown>; // keyword-specific details
  source?: unknown; // raw error from the validator library
}
```

## Event System

노드는 배치 이벤트 시스템을 통해 통신합니다. 동일한 동기 호출 스택에서 예약된 이벤트는
단일 배치로 병합되어 다음 마이크로태스크에서 디스패치됩니다. `UpdateValue`는
예외로, 초기화 완료 후 동기적으로 발생합니다(즉시 모드).

```ts
// Key event types (FieldNodeEventType enum)
UpdateValue; // value changed — synchronous after init
UpdateState; // interaction flags (node.state) changed
UpdateError; // validation errors changed
UpdateComputedProperties; // controls state or watched values changed
UpdateChildren; // array/object children added or removed
RequestRefresh; // internal: sync uncontrolled component
RequestRemount; // external: force full component remount
```

## AI Concept Glossary

| Term                                                     | Definition                                                                                                               |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `FieldNode`                                             | Base interface for all nodes — the public API surface                                                                    |
| `StringNode` / `NumberNode` / `BooleanNode` / `NullNode` | Terminal nodes — no children                                                                                             |
| `ObjectNode` / `ArrayNode`                               | Branch nodes — have children                                                                                             |
| `VirtualNode`                                            | Groups sibling fields declared in `options.virtual` into one input                                                       |
| `node.strategy`                                          | `'branch'` (has child nodes) or `'terminal'` (one input, `children: null`); narrowed by `BranchNode` / `TerminalNode`    |
| `FieldInputDefinition`                                | `{ test, Component }` pair — maps a schema pattern to a React component                                                  |
| `FieldInputMap`                                       | `{ [jsonPointerPath]: Component }` — path-based component override                                                       |
| `FieldInputProps`                                     | Props interface all custom input components must satisfy                                                                 |
| `FieldRendererProps`                                  | Props for the `FieldRenderer`/`FormLabelRenderer`/`FormInputRenderer`/`FormErrorRenderer` components |
| `SchemaFormPlugin`                                       | Plugin object with optional renderer components + `fieldInputDefinitions` + `validator` + `formatError`               |
| `ValidatorPlugin`                                        | `{ bind?(instance), compile(jsonSchema) → ValidateFunction, compileGuard(root, pointer) → guard, release?(root) }`       |
| `ValidateFunction`                                       | `(value) => ValidationIssue[] \| null \| Promise<...>`                                                                   |
| `controls`                                               | JSON Schema extension for reactive field properties (closed key list)                                                    |
| `controls.active` on a branch                            | Expression that activates a `oneOf`/`anyOf` branch                                                                       |
| `outputValue`                                            | Emitted value after output filters — what parents, validation, and `onChange` see                                        |
| `ShowError`                                              | Enum controlling when validation errors are displayed                                                                    |
| `ValidationMode`                                         | Enum controlling when validation runs                                                                                    |
| `FieldNodeEventType`                                    | Enum of all events nodes can emit                                                                                        |
| `SetValueOption`                                         | Bitwise options for `setValue()` — `Overwrite`, `Merge`, `DisableAutomaticWrites`, `EnableAutomaticWrites`               |
| `FormHandle`                                             | Ref interface for imperative form control                                                                                |
| `FormProvider`                                           | Context provider for sharing plugin config across a subtree                                                              |
| `JSONPointer`                                            | RFC 6901 path string (e.g., `/address/street`) — extended with `..`, `.`, `*`                                            |

## 코딩 에이전트 자산 {#agent-assets}

설치된 패키지는 `docs/agents`에 소비자 규칙, `schema-form-skill`, 관련 지식 문서를 포함합니다. schema-form 작업에서 스킬을 로드하거나 해당 호출을 지원하는 호스트에서 `/schema-form-skill`로 직접 호출할 수 있습니다.

프로젝트에 `@slats/agents-assets-sync`를 설치한 뒤 적용 전에 주입 결과를 확인하십시오.

```bash
yarn exec inject-agents-settings --package=@canard/schema-form --agent=claude --scope=project --dry-run
yarn exec inject-agents-settings --package=@canard/schema-form --agent=claude --scope=project
yarn exec inject-agents-settings --package=@canard/schema-form --agent=codex --scope=project
yarn exec inject-agents-settings --package=@canard/schema-form --agent=codex --scope=user
```

`--agent=claude`는 선택한 scope의 `.claude` 위치에 자산을 씁니다. Codex project scope는 `.agents/skills`와 `AGENTS.md`의 관리 마커 블록을 사용하고, user scope는 `~/.codex/skills`와 `~/.codex/AGENTS.md`를 사용합니다. `--dry-run`은 자산을 쓰지 않고 변경을 보여 줍니다. `--force`로 덮어쓰기 전에 로컬에서 달라진 자산을 검토하십시오.

`@canard/schema-form`을 위한 Ant Design v6 UI 플러그인입니다.
`antd ^6.0.0` 기반의 18개 폼 입력 컴포넌트를 제공합니다.
컴포넌트 구성과 API는 `@canard/schema-form-antd5-plugin`과 동일하며,
프로젝트에서 Ant Design v6를 사용할 때 이 패키지를 선택하세요.

## 컴포넌트 카탈로그

:::tip
이 플러그인은 antd5 플러그인과 동일한 API 및 컴포넌트를 제공합니다. 18개 컴포넌트의 인터랙티브 카탈로그는 [antd5-plugin 컴포넌트 카탈로그](../schema-form-antd5-plugin)를 참조하세요 — 유일한 차이점은 Ant Design 버전 의존성입니다.
:::

## 설치 {#installation}

```bash
yarn add @canard/schema-form-antd6-plugin
```

### 피어 의존성 {#peer-dependencies}

```bash
yarn add antd@>=6.0.0 dayjs@>=1 react@>=18 react-dom@>=18
```

## 빠른 설정 {#quick-setup}

```ts
import { registerPlugin } from '@canard/schema-form';
import { plugin } from '@canard/schema-form-antd6-plugin';

registerPlugin(plugin);
```

## 컴포넌트 매핑 {#component-mapping}

컴포넌트는 JSON Schema 속성에 따라 자동으로 선택됩니다. 우선순위는 아래 목록 순서와 같으며, 맨 위가 가장 높습니다.

| 컴포넌트 | type | format | inputType | enum | 참고 사항 |
|---|---|---|---|---|---|
| `FieldInputBooleanSwitch` | `boolean` | — | `"switch"` | — | 스위치 토글 |
| `FieldInputStringCheckbox` | `array` | — | `"checkbox"` | items.enum | 체크박스 그룹이며, items는 문자열 스키마여야 합니다. |
| `FieldInputStringSwitch` | `string` | — | `"switch"` | 값 2개 | 두 enum 값 사이를 전환합니다. |
| `FieldInputUri` | `string` | `"uri"` 또는 inputType `"uri"` | — | — | 프로토콜 선택기가 있는 URI 입력 |
| `FieldInputMonth` | `string` | `"month"` | — | — | 월 선택기 |
| `FieldInputDate` | `string` | `"date"` | — | — | 날짜 선택기 |
| `FieldInputTime` | `string` | `"time"` | — | — | 시간 선택기 |
| `FieldInputMonthRange` | `array` | `"month-range"` 또는 inputType `"monthRange"` | — | — | 월 범위 선택기이며, items는 문자열 스키마여야 합니다. |
| `FieldInputDateRange` | `array` | `"date-range"` 또는 inputType `"dateRange"` | — | — | 날짜 범위 선택기이며, items는 문자열 스키마여야 합니다. |
| `FieldInputTimeRange` | `array` | `"time-range"` 또는 inputType `"timeRange"` | — | — | 시간 범위 선택기이며, items는 문자열 스키마여야 합니다. |
| `FieldInputRadioGroup` | `string` \| `number` \| `integer` | — | `"radio"` 또는 `"radiogroup"` | 필수 | 라디오 버튼 그룹 |
| `FieldInputStringEnum` | `string` | — | — | 필수 | 선택 드롭다운이며, enum이 있는 문자열 항목 배열도 처리합니다. |
| `FieldInputArray` | `array` | — | — | — | 추가/제거가 가능한 동적 목록 |
| `FieldInputSlider` | `number` \| `integer` | — | `"slider"` | — | 슬라이더 입력 |
| `FieldInputTextarea` | `string` | `"textarea"` 또는 inputType `"textarea"` | — | — | 여러 줄 텍스트 영역 |
| `FieldInputString` | `string` | — | — | — | 기본 텍스트 입력 (`format: "password"`로 비밀번호 지원) |
| `FieldInputNumber` | `number` \| `integer` | — | — | — | 숫자 입력 |
| `FieldInputBoolean` | `boolean` | — | — | — | 체크박스 |

## 스키마 확장 속성 {#schema-extension-properties}

```ts
// Custom schema properties recognized by this plugin
{
  inputType?: 'switch' | 'radio' | 'radiogroup' | 'checkbox' | 'slider' |
             'textarea' | 'uri' | 'dateRange' | 'monthRange' | 'timeRange',
  // Standard JSON Schema properties also used for routing:
  format?: 'date' | 'time' | 'month' | 'password' | 'uri' |
           'textarea' | 'date-range' | 'month-range' | 'time-range',
}
```

## 사용 예제 {#usage-example}

```tsx
import { Form } from '@canard/schema-form';

const schema = {
  type: 'object',
  properties: {
    name:      { type: 'string' },
    age:       { type: 'integer' },
    active:    { type: 'boolean', presentation: { inputType: 'switch' } },
    role:      { type: 'string', enum: ['admin', 'user', 'guest'] },
    birthday:  { type: 'string', format: 'date' },
    bio:       { type: 'string', format: 'textarea' },
    score:     { type: 'number', presentation: { inputType: 'slider' }, minimum: 0, maximum: 100 },
  },
};

<Form jsonSchema={schema} onChange={setValue} />
```

## 컨텍스트 {#context}

플러그인은 크기 설정을 위해 `<Form context={...}>`에 전달된 `context`를 읽습니다:

```ts
type AntdContext = {
  size?: 'small' | 'middle' | 'large';
};
```

## v5와 v6 비교 {#v5-vs-v6}

antd5와 antd6 플러그인은 API가 동일합니다. 유일한 차이는 `antd` 피어 의존성 버전입니다. 가져오기와 피어 의존성을 교체하여 패키지를 전환하십시오:

```ts
// antd5
import { plugin } from '@canard/schema-form-antd5-plugin';
// antd6
import { plugin } from '@canard/schema-form-antd6-plugin';
```

npm 패키지 작성자가 Claude Code 커맨드와 스킬을 패키지와 함께 배포할 수 있도록 합니다.
사용자는 패키지 설치 후 `.claude/` 디렉토리로 에셋을 동기화하여 즉시 사용할 수 있습니다.

- 단일 명령으로 여러 패키지 동기화
- 버전 추적 — 버전이 동일하면 재동기화 생략
- 접두사 파일명을 사용하는 플랫 구조 (기본값)
- ink 기반 인터랙티브 터미널 UI
- npm 레지스트리 업데이트 확인이 포함된 상태 모니터링
- 변경 사항 미리보기를 위한 드라이런 모드
- 레거시 중첩 구조 지원 및 마이그레이션 도구

## 설치 {#installation}

```bash
# One-time use (recommended)
npx @slats/claude-assets-sync -p @canard/schema-form

# Global install
npm install -g @slats/claude-assets-sync
```

## 명령어 {#commands}

### sync (기본값) {#sync-default}

하나 이상의 npm 패키지에서 Claude 자산을 동기화합니다.

```bash
npx @slats/claude-assets-sync [options] -p <package>
```

| 옵션                 | 설명                                       |
| ---------------------- | ------------------------------------------------- |
| `-p, --package <name>` | 동기화할 패키지 (반복 지정 가능)                      |
| `-f, --force`          | 버전이 같아도 강제로 동기화합니다.                |
| `--dry-run`            | 파일을 쓰지 않고 변경 사항을 미리 봅니다.             |
| `-l, --local`          | node_modules 대신 로컬 워크스페이스에서 읽습니다. |
| `-r, --ref <ref>`      | 가져올 Git 참조 (브랜치, 태그, 커밋)       |
| `--no-flat`            | 레거시 중첩 디렉토리 구조를 사용합니다.             |

```bash
# Sync a single package
npx @slats/claude-assets-sync -p @canard/schema-form

# Sync multiple packages
npx @slats/claude-assets-sync -p @canard/schema-form -p @lerx/promise-modal

# Preview without writing
npx @slats/claude-assets-sync -p @canard/schema-form --dry-run

# Force re-sync
npx @slats/claude-assets-sync -p @canard/schema-form --force

# Sync from a specific branch
npx @slats/claude-assets-sync -p @canard/schema-form -r main
```

### add

대화형 파일 선택(TTY)으로 패키지를 추가합니다.

```bash
npx @slats/claude-assets-sync add -p <package> [options]
```

| 옵션                 | 설명               |
| ---------------------- | ------------------------- |
| `-p, --package <name>` | 추가할 패키지 (필수) |
| `-l, --local`          | 로컬 워크스페이스에서 읽습니다. |
| `-r, --ref <ref>`      | 가져올 Git 참조     |

**대화형 모드의 키보드 조작:**

| 키       | 동작                      |
| --------- | --------------------------- |
| `↑` / `↓` | 항목 간 이동              |
| `Space`   | 선택 전환            |
| `→` / `←` | 디렉토리 펼치기 / 접기 |
| `Enter`   | 확인 및 동기화            |
| `a`       | 모두 선택                  |
| `n`       | 모두 선택 해제                |
| `q`       | 취소                      |

```bash
npx @slats/claude-assets-sync add -p @lerx/promise-modal
```

## 디렉토리 구조 {#directory-structure}

### 플랫 구조 (기본값) {#flat-default}

```
your-project/
└── .claude/
    ├── commands/
    │   ├── @canard-schema-form-my-command.md
    │   └── @lerx-promise-modal-another-command.md
    └── skills/
        ├── @canard-schema-form-my-skill.md
        └── @lerx-promise-modal-another-skill.md
```

각 자산 디렉토리에서는 하나의 `.sync-meta.json`이 모든 패키지를 추적합니다.

### 중첩 구조 (레거시, `--no-flat`) {#nested-legacy---no-flat}

```
your-project/
└── .claude/
    ├── commands/
    │   └── @canard/schema-form/
    │       ├── my-command.md
    │       └── .sync-meta.json
    └── skills/
        └── @lerx/promise-modal/
            ├── my-skill.md
            └── .sync-meta.json
```

## .sync-meta.json

```json
{
  "version": "0.0.1",
  "syncedAt": "2025-02-05T10:30:00.000Z",
  "packages": {
    "@canard-schema-form": {
      "originalName": "@canard/schema-form",
      "version": "1.0.0",
      "files": {
        "commands": [
          {
            "original": "my-command.md",
            "transformed": "@canard-schema-form-my-command.md"
          }
        ],
        "skills": [
          {
            "original": "my-skill.md",
            "transformed": "@canard-schema-form-my-skill.md"
          }
        ]
      }
    }
  }
}
```

## 패키지 작성자를 위한 안내 {#for-package-authors}

`package.json`에 `claude` 필드를 추가하고 선언한 경로 아래에 자산을 배치하십시오:

```json
{
  "name": "@your-scope/your-package",
  "version": "1.0.0",
  "repository": {
    "type": "git",
    "url": "https://github.com/your-org/your-repo.git",
    "directory": "packages/your-package"
  },
  "claude": {
    "assetPath": "docs/claude"
  }
}
```

```
your-package/
└── docs/claude/
    ├── commands/
    │   └── your-command.md
    └── skills/
        └── your-skill.md
```

- 자산 파일은 Markdown(`.md`)이어야 합니다.
- `repository.type`과 `repository.url`은 필수입니다.
- `assetPath`는 패키지 루트에 대한 상대 경로입니다.

## 동기화 흐름 {#sync-flow}

```
1. node_modules (또는 로컬 워크스페이스)에서 package.json 읽기
2. claude.assetPath 추출
3. 저장소 URL 파싱 → GitHub owner/repo
4. .sync-meta.json과 버전 비교 (--force가 없고 변경되지 않았으면 생략)
5. GitHub API에서 파일 목록 가져오기 (assetPath 아래의 commands/ 및 skills/)
6. raw.githubusercontent.com에서 각 파일 다운로드
7. .claude/{type}/{prefixed-name}.md에 쓰기
8. .sync-meta.json 갱신
```

## 프로그래밍 API {#programmatic-api}

```ts
import { syncPackage, syncPackages } from '@slats/claude-assets-sync';
import type { CliOptions, SyncResult } from '@slats/claude-assets-sync';

// Sync a single package
const result: SyncResult = await syncPackage('@canard/schema-form', {
  force: false,
  dryRun: false,
  flat: true,
});

// Sync multiple packages
const results = await syncPackages(
  ['@canard/schema-form', '@lerx/promise-modal'],
  {
    force: true,
  },
);
```

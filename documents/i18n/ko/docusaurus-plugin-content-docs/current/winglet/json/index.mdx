안전한 JSON 데이터 조작을 위한 TypeScript 라이브러리입니다.
RFC 6901(JSON Pointer)과 RFC 6902(JSON Patch)를 구현하며,
프로토타입 오염 방지, 불변 연산, 서브패스 익스포트를 지원합니다.

## 설치 {#installation}

```bash
yarn add @winglet/json
```

## 서브패스 내보내기 {#sub-path-exports}

| 가져오기 경로 | 내용 |
|---|---|
| `@winglet/json` | 모든 내보내기 |
| `@winglet/json/pointer` | 전체 JSON Pointer API |
| `@winglet/json/pointer-manipulator` | `getValue`, `setValue`, `compilePointer` |
| `@winglet/json/pointer-patch` | JSON Patch 연산 |
| `@winglet/json/pointer-escape` | `escapePath`, `unescapePath` |
| `@winglet/json/path` | JSON Path 상수 |

## 주요 내보내기 {#key-exports}

### 포인터 조작 (`/pointer-manipulator`) {#pointer-manipulation-pointer-manipulator}

- `getValue(object, pointer, options?)`는 JSON Pointer 경로의 값을 읽습니다.
- `setValue(object, pointer, value, options?)`는 해당 경로에 값을 씁니다.
- `compilePointer(pointer)`는 포인터를 재사용 가능한 세그먼트로 컴파일합니다.

### JSON Patch (`/pointer-patch`)

- `compare(a, b, options?)`는 두 객체 간의 RFC 6902 패치를 생성합니다.
- `applyPatch(object, patches, options?)`는 패치 배열을 적용합니다.
- `difference(a, b)`는 RFC 7396 병합 패치를 생성합니다.
- `mergePatch(object, patch)`는 병합 패치를 적용합니다.

### 옵션 {#options}

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `immutable` | `true` | 원본을 변경하는 대신 새 객체를 반환합니다. |
| `protectPrototype` | `true` | `__proto__`, `constructor`, `prototype`을 차단합니다. |
| `strict` | `false` | 경로가 없으면 예외를 발생시킵니다. |

## 사용 예제 {#usage-examples}

```ts
import { getValue, setValue } from '@winglet/json/pointer-manipulator';

const data = { user: { name: 'Alice', roles: ['admin'] } };

getValue(data, '/user/name');              // 'Alice'
setValue(data, '/user/name', 'Bob');        // new object, original unchanged
```

```ts
import { compare, applyPatch } from '@winglet/json/pointer-patch';

const a = { x: 1, y: 2 };
const b = { x: 1, y: 3, z: 4 };

const patch = compare(a, b);
// [{ op: 'replace', path: '/y', value: 3 }, { op: 'add', path: '/z', value: 4 }]

applyPatch(a, patch); // { x: 1, y: 3, z: 4 }
```

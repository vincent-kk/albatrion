TypeScript 프로젝트를 위한 CSS 및 스타일 관리 유틸리티입니다.
Shadow DOM을 지원하는 스코프 스타일 주입, CSS 압축,
className 연결 헬퍼를 런타임 의존성 없이 제공합니다.

## 설치 {#installation}

```bash
yarn add @winglet/style-utils
```

## 서브패스 내보내기 {#sub-path-exports}

| 가져오기 경로 | 내용 |
|---|---|
| `@winglet/style-utils` | 모든 내보내기 |
| `@winglet/style-utils/style-manager` | `styleManagerFactory`, `destroyScope` |
| `@winglet/style-utils/util` | `cx`, `cxLite`, `compressCss` |

## 주요 내보내기 {#key-exports}

### 스타일 관리자 (`/style-manager`) {#style-manager-style-manager}

- `styleManagerFactory(scopeId, options?)`는 문서(또는 Shadow Root)에 CSS를 주입하는 스코프 지정 `addStyle` 함수를 반환합니다.
- `destroyScope(scopeId)`는 모든 스타일을 제거하고 스코프를 정리합니다.

최신 브라우저에서는 `adoptedStyleSheets`를 사용하며, 지원하지 않으면 `<style>` 요소 주입으로 폴백합니다. 업데이트는 `requestAnimationFrame`으로 일괄 처리합니다.

### 클래스 이름 유틸리티 (`/util`) {#class-name-utilities-util}

- `cx(...inputs)`는 클래스 이름을 연결하며 문자열, 객체, 배열을 받습니다.
- `cxLite(...inputs)`는 참으로 평가되는 문자열만 필터링하는 경량 변형입니다.
- `compressCss(css)`는 한 번의 순회로 CSS를 압축합니다.

## 사용 예제 {#usage-examples}

```ts
import { cx, cxLite } from '@winglet/style-utils/util';

cx('button', { 'button--active': isActive }, ['base']);
// → 'button button--active base'

cxLite('button', isActive && 'button--active');
// → 'button button--active'
```

```ts
import { styleManagerFactory, destroyScope } from '@winglet/style-utils/style-manager';
import { compressCss } from '@winglet/style-utils/util';

const addStyle = styleManagerFactory('my-widget');

const removeStyle = addStyle('theme', compressCss(`
  .container { display: flex; padding: 16px; }
  .title     { font-size: 1.25rem; }
`));

// Cleanup
removeStyle();               // remove one style block
destroyScope('my-widget');   // tear down entire scope
```

```ts
// Shadow DOM support
const addStyle = styleManagerFactory('shadow-scope', {
  shadowRoot: element.shadowRoot,
});
```

### 주요 내보내기 {#key-exports-1}
```
./style-manager → styleManagerFactory(scopeId, options?) → addStyle(key, css) → removeStyle()
                  destroyScope(scopeId)
./util          → cx(...inputs)          — className 연결 (문자열, 객체, 배열)
                  cxLite(...inputs)       — 경량 변형 (참으로 평가되는 문자열만)
                  compressCss(css)        — 한 번의 순회로 CSS 압축
```

### styleManagerFactory 옵션 {#stylemanagerfactory-options}
```ts
{ shadowRoot?: ShadowRoot }  // Enable Shadow DOM support
```

### 동작 {#behaviors}
- 최신 브라우저에서는 `adoptedStyleSheets`를 사용하며, 지원하지 않으면 `<style>` 주입으로 폴백합니다.
- 스타일 업데이트는 `requestAnimationFrame`으로 일괄 처리합니다.
- `destroyScope()`는 지정한 scopeId의 모든 스타일을 제거하고 스코프를 정리합니다.

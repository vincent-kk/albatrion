GraphQL DataLoader에서 영감을 받은 비동기 데이터 페칭용 배칭 및 캐싱 유틸리티입니다.
같은 틱 내의 개별 `load()` 호출을 자동으로 하나의 배치 요청으로 모아
N+1 쿼리 문제를 해소하며, 내장 Promise 캐시를 제공합니다.

## 설치 {#installation}

```bash
yarn add @winglet/data-loader
```

## API

### 생성자 {#constructor}

```ts
import { DataLoader } from '@winglet/data-loader';

const loader = new DataLoader<Key, Value>(batchLoader, options?);
```

`batchLoader`는 키 배열을 받으며, 같은 순서의 값(또는 `Error`)으로 이행되는 `Promise`를 반환해야 합니다.

### 인스턴스 메서드 {#instance-methods}

| 메서드 | 설명 |
|---|---|
| `load(key)` | 단일 키에 대한 `Promise<Value>`를 반환하며, 자동으로 배칭합니다. |
| `loadMany(keys)` | 여러 키에 대한 `Promise<(Value \| Error)[]>`를 반환합니다. |
| `clear(key)` | 캐시에서 단일 키를 제거합니다. |
| `clearAll()` | 전체 캐시를 비웁니다. |
| `prime(key, value)` | 캐시를 미리 채웁니다. |

### 옵션 {#options}

| 옵션 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `batch` | `boolean` | `true` | 요청 배칭을 활성화합니다. |
| `maxBatchSize` | `number` | `Infinity` | 배치당 최대 키 수 |
| `cache` | `boolean` | `true` | 프로미스 캐싱을 활성화합니다. |
| `cacheKeyFn` | `(key) => CacheKey` | 항등 함수 | 키를 캐시 키에 매핑합니다. |
| `cacheMap` | `MapLike` | `new Map()` | 사용자 정의 캐시 구현 |
| `scheduler` | `(fn) => void` | `process.nextTick` | 배칭 시점을 제어합니다. |

## 사용 예제 {#usage-examples}

```ts
import { DataLoader } from '@winglet/data-loader';

const userLoader = new DataLoader<number, User>(async (ids) => {
  const users = await fetchUsersByIds(ids);
  return ids.map(id => users.find(u => u.id === id) ?? new Error(`Not found: ${id}`));
});

// These three calls batch into a single fetchUsersByIds([1, 2, 3])
const [alice, bob, carol] = await Promise.all([
  userLoader.load(1),
  userLoader.load(2),
  userLoader.load(3),
]);
```

```ts
// Cache management
userLoader.prime(4, { id: 4, name: 'Dave' });
userLoader.clear(1);
userLoader.clearAll();
```

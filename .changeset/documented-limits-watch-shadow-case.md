The documentation now states three limits. `watchValues` compares watched values with `Object.is`, so mutating a watched array or object in place is not detected. A modal root inside a closed shadow root is not supported, because focus there resolves to the shadow host. On a case-insensitive volume a release that only changes a file name's case can leave the installed file under its previous spelling, and command files that a later release removes are not deleted by `--force`.

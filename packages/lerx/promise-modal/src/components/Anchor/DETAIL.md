# Anchor

## Requirements

id 목록과 표시 개수는 외부 저장소를 구독하여 경로 숨김과 파괴를 즉시 반영합니다.

## API Contracts

스타일 등록은 이 컴포넌트 내부가 소유하고 역할 구획에 둡니다. 로드 시 등록 효과와 클래스 정체성을 유지하며 스타일을 독립 공개 계약으로 내보내지 않습니다.

- 전환 CSS 변수는 단위가 붙은 정규화된 ms 문자열을 사용합니다. root가 바뀌어도 포털 컨테이너 정체는 유지합니다.
- 최외곽 오류 경계는 살아 있는 노드를 거부·파괴하고 다음 노드 등록에서만 초기 상태로 돌아가 이후 모달을 렌더합니다. 오류 직후 복구는 Anchor 자체 오류의 반복 렌더를 유발하므로 금지합니다. DOM 배치는 매니저만 수행합니다.

## Acceptance Criteria

### anchor-contract — 관찰 가능한 동작

- 경로 숨김은 뒤 배경의 어두움을 제거하고 공유 렌더 오류 뒤 다음 등록에서 복구합니다.

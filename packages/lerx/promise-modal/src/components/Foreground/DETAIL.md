# Foreground

## Requirements

모달 종류와 사용자 컴포넌트에 맞춰 내용을 조합하며 노드 변경은 조작 인터페이스를 거칩니다.

## API Contracts

스타일 등록은 이 컴포넌트 내부가 소유하고 역할 구획에 둡니다. 로드 시 등록 효과와 클래스 정체성을 유지하며 스타일을 독립 공개 계약으로 내보내지 않습니다.

- 바깥 전경 래퍼는 tabIndex -1과 안정된 ref 콜백으로 매니저에 등록되어 사용자 프레임에도 포커스 기본선을 제공합니다. 전역 DOM 처리는 매니저가 수행합니다.

- 전경 프레임에 group·subtype·settled를 전달하고 alert 내용에 context를 전달합니다.
- prompt 함수형 변경은 최신 값에서 순서대로 누적되고 확인은 동기적으로 노드의 현재 값을 확정합니다. Input 오류는 모달 단위 오류 경계로 전달합니다.

## Acceptance Criteria

### foreground-contract — 관찰 가능한 동작

- 한 이벤트 안의 함수형 입력 변경과 확인은 누적된 최신 값을 반환합니다.

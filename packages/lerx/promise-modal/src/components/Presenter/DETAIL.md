# Presenter

## Requirements

노드 하나의 구독으로 배경과 전경을 갱신합니다. 다른 모달 등록은 이 프레임의 재렌더를 유발하지 않습니다.

## API Contracts

스타일 등록은 이 컴포넌트 내부가 소유하고 역할 구획에 둡니다. 로드 시 등록 효과와 클래스 정체성을 유지하며 스타일을 독립 공개 계약으로 내보내지 않습니다.

- 오류 경계는 해당 모달만 거부·파괴하도록 Context 조작 함수를 호출하고 빈 화면을 렌더합니다. z-index는 현재 설정과 노드 순서의 합을 매 렌더에서 계산합니다.

## Acceptance Criteria

### presenter-contract — 관찰 가능한 동작

- 새 모달 열기는 기존 프레임을 재렌더하지 않으며 한 프레임의 오류가 다른 프레임을 제거하지 않습니다.

## Last Updated

결과 확정, 자원 소유권 또는 표시 계약이 바뀔 때 갱신합니다.

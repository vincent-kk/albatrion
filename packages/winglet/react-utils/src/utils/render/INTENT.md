# render — 다형 컴포넌트/엘리먼트 렌더 정규화

## Purpose

ReactNode·컴포넌트 타입·이미 생성된 엘리먼트 중 무엇이 들어오든 렌더 가능한 형태로 정규화하는 단일 유닛을 소유한다. 엘리먼트·컴포넌트 판별 로직은 소유하지 않는다 — filter 형제 fractal의 엔트리 포인트를 경유해 재사용한다.

## Conventions

- falsy 값과, 엘리먼트도 컴포넌트도 아닌 truthy 값(문자열·숫자 등)은 모두 `null`로 수렴한다 — 텍스트를 그대로 렌더하는 경로는 의도적으로 없다. 이를 버그로 보고 문자열·숫자를 그대로 렌더하도록 바꾸지 않는다.

## Boundaries

### Always do

- 엘리먼트·컴포넌트 판별은 filter 형제 fractal의 엔트리 포인트만 재사용한다
- filter가 인식하는 컴포넌트 종류가 늘어나면 이 fractal은 별도 수정 없이 그 확장을 그대로 반영해야 한다(판별 위임 위에서 동작)
- 렌더 결과 형태(엘리먼트 그대로 반환 vs 새로 생성)를 바꾸는 변경은 DETAIL.md를 먼저 갱신한다

### Ask first

- 두 번째 인자(props) 전달 방식이나 시그니처 확장
- falsy·텍스트 값 처리 방침(현재는 전부 `null`) 변경

### Never do

- 엘리먼트 판별 없이 값을 컴포넌트 타입으로 간주해 무조건 `createElement`를 호출하는 경로 추가
- 문자열·숫자 등 텍스트 값을 그대로 반환하는 경로 추가

# compressCss — 바이트 단위 CSS 압축

## Purpose

CSS 문자열에서 불필요한 공백·주석·중복 세미콜론을 제거해 압축하는 단일 함수를 소유한다. 완벽한 압축보다 속도를 우선하며, 일부 위치(미디어 쿼리 등)에 후행 공백이 남는 것을 허용하는 대신 바이트 단위 단일 패스로 처리한다.

## Conventions

- 선택자 결합자 공백 규칙: 자식 결합자(`>`)와 인접 형제 결합자(`+`)는 공백을 제거하지만, 하위(descendant) 결합자의 공백은 셀렉터 의미가 바뀌므로 보존한다.
- 식별자 뒤에 오는 함수형 괄호 앞의 공백(예: 미디어 쿼리 키워드와 조건식 사이)은 병합해 토큰이 붙어버리는 것을 방지한다.

## Boundaries

### Always do

- 셀렉터 의미가 바뀌는 공백(하위 결합자, 식별자 뒤 괄호 앞)은 지우지 않고 정확히 하나만 남긴다
- 압축 실패보다 원문 의미 보존을 우선한다 — 애매한 경우 공백을 지우기보다 남긴다

### Ask first

- 압축 알고리즘을 바이트 단위 단일 패스에서 파서 기반 접근으로 바꾸는 변경
- 후행 공백 등 "완벽하지 않은 압축"을 허용하는 현재 성능·정확도 트레이드오프 변경

### Never do

- 주석이나 세미콜론 제거 로직이 선언 값 내부의 실제 콘텐츠를 손상시키는 변경
- 압축 결과가 원본과 다른 CSS 규칙 집합으로 파싱되게 만드는 변경

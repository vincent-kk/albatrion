# compressCss contract

## Requirements

- `compressCss(css)`는 빈 문자열 입력에 빈 문자열을 반환한다.
- 연속된 공백·탭·개행은 하나의 공백 또는 무공백으로 축약되고, 단일·다중 라인 주석은 완전히 제거된다.
- 중복되거나 블록 끝 직전에 오는 세미콜론은 제거된다.
- `@media`, `@keyframes` 등 중첩 규칙은 바깥 블록과 안쪽 블록 모두 압축되어 올바른 중첩 구조를 유지한다.

## API Contracts

- `compressCss(css: string): string` — 바이트(UTF-8) 단위로 한 번 순회하며 처리한다. 공백 병합 시 직전·다음 바이트가 여는 중괄호·닫는 중괄호·세미콜론·콜론·쉼표·부등호·플러스·물결표·괄호류 구두점이면 공백을 생략하고, 식별자 문자 바로 뒤에 여는 괄호가 오는 경우(예: 미디어 쿼리 키워드와 조건식 사이)는 공백을 보존한다.
- 출력 끝의 공백은 모두 제거된다.

## Acceptance Criteria

### whitespace-comment-normalization — 공백·주석 정규화

- 빈 문자열은 빈 문자열로 압축된다.
- 규칙 안팎의 여러 공백·개행이 축약되어 최소 형태(`.class{color:red;background:blue}`)로 압축된다.
- 단일 라인 주석과 여러 줄에 걸친 주석 모두 결과에서 완전히 제거된다.

### syntax-punctuation-rules — 세미콜론·결합자·중첩 규칙 압축

- 중복 세미콜론과 블록 종료 직전의 세미콜론은 제거된다.
- 하위 결합자(공백)의 공백은 보존되고, 자식·인접 형제 결합자 주변 공백은 제거된다.
- `@media`, `@keyframes` 중첩 규칙이 중첩 구조를 유지한 채 압축되며, 조건식 앞에 필요한 공백은 보존된다.

# convertJsonPathToPointer contract

## Requirements

- AJV dataPath 형식(점·대괄호 표기) 문자열을 RFC 6901 JSON Pointer 문자열로 변환한다.
- 이미 포인터 형식인 입력은 변환 없이 그대로 반환한다(멱등).
- 빈 문자열 입력은 루트 포인터를 반환한다.

## API Contracts

- `convertJsonPathToPointer(dataPath)`:
  - 입력이 이미 포인터 형식(포인터 구분자로 시작하거나 URI 프래그먼트 다음에 포인터 구분자가 오는 형식)이면 그대로 반환한다.
  - `.`는 세그먼트 경계로 처리되어 포인터 구분자로 치환된다.
  - `[n]`은 포인터 구분자와 `n`으로, 빈 대괄호는 포인터 구분자와 `-`로 치환된다.
  - 변환 결과가 비면 루트 포인터 하나만 반환한다.

## Acceptance Criteria

### data-path-conversion — 점·대괄호 표기 변환

- 단순·중첩 프로퍼티 경로와 배열 인덱스, 혼합 경로를 세그먼트 단위 구분자 치환으로 변환한다.
- 빈 배열 인덱스는 `-`로, 빈 문자열 입력은 루트 포인터로 변환된다.
- 매우 긴 경로와 많은 배열 인덱스를 포함한 경로도 동일 규칙으로 변환한다.

### pointer-format-passthrough — 포인터 형식 입력 멱등성

- 이미 포인터 형식인 입력은 반복 적용해도 항상 같은 값을 반환한다.
- 특수 문자(하이픈, 언더스코어, `$`, 세그먼트 내 마침표 등)가 포함된 포인터 입력도 변형 없이 통과한다.

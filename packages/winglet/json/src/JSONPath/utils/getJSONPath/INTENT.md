# getJSONPath — 참조 동일성 기반 경로 탐색

## Purpose

`getJSONPath(root, target)` 하나의 함수를 소유한다. 루트 객체에서 특정 값(참조 동일성 `===` 기준)까지의 경로를 DFS 스택 탐색으로 찾아 `$`로 시작하는 JSONPath 문자열로 반환하거나, 찾지 못하면 null을 반환한다.

## Boundaries

### Always do

- 이미 방문한 노드를 추적해 순환 참조가 있는 입력에서도 재방문 없이 종료되게 유지한다
- 배열 인덱스는 `[i]`, 마침표를 포함한 키는 `['key']`, 그 외 키는 `.key`로 세그먼트를 구성하는 규칙을 유지한다

### Ask first

- 탐색 순서(DFS, 후입선출 스택)를 BFS 등 다른 순서로 바꾸는 변경 — 동일 값이 여러 위치에 있을 때 반환 경로가 달라진다
- own이 아닌 상속 열거 속성까지 순회 대상에 포함하는 변경

### Never do

- `===` 참조 동일성 비교를 값 동등성(깊은 비교)으로 바꾸는 변경
- 방문 여부 추적 없이 순회 구조를 바꿔 순환 참조 입력에서 무한 루프를 유발하는 변경

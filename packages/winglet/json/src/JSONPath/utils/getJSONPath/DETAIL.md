# getJSONPath contract

## Requirements

- 대상 값이 루트와 동일 참조이면 `$`를 반환한다.
- 루트에서 대상까지 내려가며 만나는 경로를 JSONPath 문자열로 반환하고, 찾지 못하면 null을 반환한다.
- 순환 참조가 있는 구조에 대해서도 무한 루프 없이 종료한다.

## API Contracts

- `getJSONPath(root, target)`:
  - 객체 키는 `.key` 점 표기로, 마침표를 포함한 키는 `['key']` 대괄호·따옴표 표기로 세그먼트를 만든다.
  - 배열 인덱스는 `[i]` 형식으로 세그먼트를 만든다.
  - own enumerable 속성만 순회 대상이며, 상속 속성은 방문하지 않는다.
  - 동일한 값이 여러 경로에 있으면 순회 중 먼저 만나는 경로 하나를 반환한다.

## Acceptance Criteria

### root-identity-and-not-found — 루트/미발견 처리

- 타겟이 루트와 동일 참조이면 `$`를 반환하며, 빈 객체를 루트로 해도 동일하다.
- 존재하지 않는 타겟에는 null을 반환한다.

### path-segment-notation — 세그먼트 표기 규칙

- 일반 키는 `.key`, 마침표를 포함한 키는 `['key']`, 배열 인덱스는 `[i]`로 표기하며 객체·배열이 혼재된 구조에서도 규칙이 유지된다.
- 숫자 문자열 키를 가진 일반 객체는 배열이 아니므로 점 표기(예: `.0`)로 처리된다.

### cyclic-and-shared-reference — 순환·공유 참조 처리

- 자기 참조를 포함한 순환 구조에서도 무한 루프 없이 대상을 찾아 정확한 경로를 반환하거나, 대상이 없으면 null을 반환한다.
- 동일 객체 참조가 여러 위치에서 도달 가능해도 먼저 만나는 경로 하나를 반환한다.

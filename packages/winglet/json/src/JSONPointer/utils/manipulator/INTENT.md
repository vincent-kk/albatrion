# manipulator — 포인터 기반 값 읽기/쓰기

## Purpose

JSON Pointer로 지정된 위치의 값 조회(`getValue`)와 설정(`setValue`), 그리고 포인터 문자열의 세그먼트 컴파일을 소유한다.

패치 문서 해석(RFC 6902·7396)은 소유하지 않는다 — patch fractal의 책임이며, 이 모듈은 그 기반이 되는 단일 값 연산만 제공한다.

## Conventions

- 쓰기 경로의 예약 멤버 세그먼트는 소유 fractal(JSONPointer)이 공유하는 `isForbiddenKey`로 판별하고, 발견 즉시 예외 없이 원본 참조를 반환한다 — 그 세그먼트와 이후 경로는 기록하지 않는다.
- 배열 컨텍스트의 `-` 세그먼트는 RFC 6901의 append 별칭으로 해석되어 배열 길이 인덱스로 치환된다.
- 존재하지 않는 중간 경로를 자동 생성할 때 다음 세그먼트가 배열 인덱스 형태면 배열을, 아니면 객체를 만든다.

## Boundaries

### Always do

- 새 쓰기 변형(overwrite, preserveNull 등)을 추가할 때 예약 멤버 검사를 세그먼트 순회의 최전단에 유지한다

### Ask first

- 예약 멤버 발견 시 동작(무시하고 원본 반환)을 예외 발생으로 바꾸는 변경
- 자동 생성되는 중간 컨테이너의 타입 결정 규칙 변경

### Never do

- 예약 멤버 세그먼트를 통과시키는 쓰기 경로 추가

# manipulator — 포인터 기반 값 읽기/쓰기

## Purpose

JSON Pointer로 지정된 위치의 값 조회(`getValue`)와 설정(`setValue`), 그리고 포인터 문자열의 세그먼트 컴파일을 소유한다.

패치 문서 해석(RFC 6902·7396)은 소유하지 않는다 — patch fractal의 책임이며, 이 모듈은 그 기반이 되는 단일 값 연산만 제공한다.

## Conventions

- 예약 멤버 세그먼트(`__proto__`, `constructor`, `prototype`)는 불투명한 문자열로 취급한다: 읽기·쓰기·삭제 모두 소유 fractal(JSONPointer)이 공유하는 `@winglet/common-utils` 데이터 속성 프리미티브를 경유해 own 데이터 속성으로만 접근하고, 프로토타입 체인과 접촉하지 않는다.
- 배열 컨텍스트의 `-` 세그먼트는 RFC 6901의 append 별칭으로 해석되어 배열 길이 인덱스로 치환된다.
- 존재하지 않는 중간 경로를 자동 생성할 때 다음 세그먼트가 배열 인덱스 형태면 배열을, 아니면 객체를 만든다.

## Boundaries

### Always do

- 새 쓰기 변형(overwrite, preserveNull 등)을 추가할 때 세그먼트 순회의 모든 읽기·쓰기·삭제를 데이터 속성 프리미티브로 유지한다

### Ask first

- 예약 멤버 세그먼트 취급 의미론(own 데이터 기록)을 무시나 예외 발생으로 바꾸는 변경
- 자동 생성되는 중간 컨테이너의 타입 결정 규칙 변경

### Never do

- 예약 멤버 세그먼트를 프리미티브 우회 직접 대입으로 기록하는 쓰기 경로 추가
- 예약 멤버 세그먼트 읽기가 프로토타입 체인으로 넘어가는 경로 추가

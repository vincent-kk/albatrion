# convertJsonPointerToPath contract

## Requirements

- 빈 문자열 또는 루트 포인터(단독 슬래시)를 입력하면 점 하나를 반환한다.
- 슬래시로 구분된 각 세그먼트를 순회하며 점 표기로 연결하되, 숫자로만 이루어진 세그먼트는 대괄호 인덱스 표기로 변환한다.
- RFC 6901의 끝 추가 표시 세그먼트(`-`)는 빈 대괄호로 변환된다.
- 세그먼트 문자열에 점이 포함되어 있으면 그 세그먼트는 대괄호로 감싸 이스케이프된다.
- 점을 제외한 특수문자(하이픈·언더스코어·달러 기호 등)가 포함된 세그먼트는 이스케이프 없이 점 표기를 그대로 유지한다.
- 입력이 이미 점, `$`+점, `@`+점 중 하나로 시작하면 변환 없이 그대로 반환한다 — 여러 번 연속 적용해도 결과가 바뀌지 않는다.

## API Contracts

- `convertJsonPointerToPath(jsonPointer)` → JSON Pointer 문자열을 받아 dataPath 문자열을 반환한다. 빈 문자열과 루트 포인터는 점 하나로, 각 세그먼트는 숫자 여부·끝 추가 표시 여부·점 포함 여부에 따라 점 표기 또는 대괄호 표기로 변환된다. 입력이 이미 변환된 표기로 시작하면 그대로 반환한다.

## Acceptance Criteria

### root-and-basic — 루트·기본 프로퍼티 경로 변환

- 빈 문자열과 루트 포인터는 점 하나로 변환된다.
- 단일·다중 중첩 프로퍼티 경로는 점으로 연결된 dataPath로 변환된다.
- 하이픈·언더스코어·달러 기호 등 점이 아닌 특수문자를 포함한 프로퍼티 이름은 이스케이프 없이 점 표기를 그대로 유지한다.

### array-and-special-segments — 배열 인덱스와 특수 세그먼트 표기

- 숫자 세그먼트는 대괄호 인덱스로 변환되고, 배열 인덱스로 시작하는 경로는 대괄호로 시작하는 dataPath로 변환된다.
- 끝 추가 표시 세그먼트는 빈 대괄호로, 점을 포함한 세그먼트는 대괄호 이스케이프로 변환된다.

### idempotency — 이미 변환된 표기의 반복 적용 안정성

- 점, `$`+점, `@`+점으로 시작하는 입력은 재해석 없이 그대로 반환되며, 반복 적용해도 동일한 결과를 유지한다.
- 배열 인덱스·빈 대괄호 표기·점 이스케이프가 섞인 복잡한 dataPath 표기도 반복 적용에서 값이 유지된다.

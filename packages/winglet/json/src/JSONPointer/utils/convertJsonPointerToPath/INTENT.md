# convertJsonPointerToPath — JSON Pointer의 dataPath 변환

## Purpose

RFC 6901 JSON Pointer 문자열을 AJV dataPath류의 점·대괄호 표기로 변환하는 단일 함수를 소유한다. 숫자 세그먼트는 배열 인덱스 대괄호로, RFC 6901의 끝 추가 표시(`-`)는 빈 대괄호로, 점을 포함한 세그먼트는 대괄호로 감싸 표기한다.

RFC 6901 이스케이프 시퀀스(`~0`, `~1`)의 해석은 소유하지 않는다 — 입력에 있어도 일반 세그먼트 문자로 그대로 취급한다. JSONPath 질의 문법(와일드카드·필터)의 파싱도 소유하지 않는다.

## Conventions

- 입력이 이미 변환된 표기(점, `$`+점, `@`+점으로 시작)면 재해석 없이 그대로 반환한다 — 결과에 함수를 다시 적용해도 같은 값을 낸다.

## Boundaries

### Always do

- 새 세그먼트 표기 규칙을 추가할 때 기존 변환 결과에 대한 반복 적용 안정성을 회귀 없이 유지한다
- 이미 변환된 표기를 감지하는 조건을 바꿀 때 세 접두 형태 모두에 동일하게 적용한다

### Ask first

- 배열 인덱스 판별 기준 교체 또는 숫자 세그먼트 표기 형식 변경
- 끝 추가 표시(`-`) 세그먼트의 빈 대괄호 변환 의미론 변경

### Never do

- RFC 6901 이스케이프 시퀀스를 해석해 문자로 치환하는 로직 추가 — 이 fractal의 계약 밖이다
- 이미 변환된 입력을 다시 파싱해 원래와 다른 결과를 내는 경로 추가

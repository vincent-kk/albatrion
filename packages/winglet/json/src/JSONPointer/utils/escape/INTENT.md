# escape — JSON Pointer 참조 토큰 이스케이프

## Purpose

RFC 6901 참조 토큰의 틸드·슬래시 이스케이프·언이스케이프 규칙을 소유한다. 세그먼트 하나를 변환하는 단위 연산과, 전체 경로를 세그먼트로 나누어 같은 규칙을 적용한 뒤 재결합하는 경로 단위 연산을 함께 제공한다.

포인터 순회, 값 조작, 패치 적용은 소유하지 않는다 — 형제 연산 fractal의 책임이며, 이 fractal은 그 연산들이 재사용하는 저수준 이스케이프 프리미티브만 제공한다.

## Conventions

- `unescapePath`와 별칭 `unescapeSegment`는 동일 구현이다 — 경로 문자열과 단일 세그먼트 문자열 모두 같은 언이스케이프 규칙을 따르므로 별도 구현을 두지 않는다.
- `escapePath`는 세그먼트마다 `escapeSegment`를 적용해 재결합한다 — 세그먼트 내용만 이스케이프 대상이고, 재결합에 쓰는 구조적 구분자 자체는 대상이 아니다.

## Boundaries

### Always do

- 이스케이프·언이스케이프 규칙을 바꿀 때 두 방향의 정합(왕복 시 원문 보존)을 회귀 없이 유지한다
- 특수문자 유무를 먼저 검사해 조기 반환하는 최적화가 있는 함수는 그 최적화를 보존한 채 수정한다

### Ask first

- 이스케이프 대상 특수문자 집합 확장 또는 이스케이프 시퀀스 형식 변경
- `unescapeSegment` 별칭 제거 또는 `unescapePath`와의 구현 분리

### Never do

- 유효하지 않은 이스케이프 시퀀스(`~2` 등)를 에러 없이 다른 문자로 치환하는 경로 추가
- `escapePath`가 세그먼트 재결합에 쓰는 구조적 구분자까지 이스케이프하는 변경 추가

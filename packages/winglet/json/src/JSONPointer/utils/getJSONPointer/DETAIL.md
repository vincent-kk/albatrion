# getJSONPointer contract

## Requirements

- 루트와 대상이 동일 참조이면 RFC 6901 루트 포인터인 빈 문자열을 반환한다.
- 루트 하위를 깊이 우선 탐색해 대상과 참조가 동일한 노드를 찾으면, 슬래시로 시작하는 이스케이프된 JSON Pointer 문자열을 반환한다.
- 대상을 찾지 못하면 `null`을 반환한다.
- 배열 인덱스와 객체 키를 포함한 각 경로 세그먼트는 이스케이프되어 반환된다.
- 자기 참조를 포함한 순환 구조에서도 무한 루프 없이 종료하며, 순환 경로 위에 있는 대상도 정상적으로 찾는다.
- 객체 순회는 own enumerable 프로퍼티만 대상으로 하고 상속 프로퍼티는 건너뛴다.

## API Contracts

- `getJSONPointer(root, target)` → `root`와 `target`이 동일 참조이면 빈 문자열을 반환한다. 아니면 `root`부터 깊이 우선 탐색해 `target`과 참조가 동일한 노드를 찾아 이스케이프된 포인터 문자열을 반환하고, 찾지 못하면 `null`을 반환한다.
- 매칭은 값의 구조적 동일성이 아닌 참조 동일성이다 — 내용이 같아도 참조가 다른 객체는 매치되지 않는다.

## Acceptance Criteria

### root-identity — 루트 자기 참조 처리

- 루트와 대상이 동일 참조인 경우(빈 객체 포함) 빈 문자열을 반환한다.

### path-construction — 중첩 경로 생성과 이스케이프

- 직속 자식, 중첩 객체, 배열 원소, 중첩 배열 안의 객체까지 정확한 경로를 구성한다.
- 키에 틸드나 슬래시가 포함되면 이스케이프되어 경로에 반영된다.

### not-found-and-cycles — 미발견과 순환 참조 종결

- 대상을 찾지 못하면 `null`을 반환한다.
- 자기 참조를 포함한 순환 구조에서도 종료하며, 순환 경로에 놓인 대상도 정상적으로 찾는다.

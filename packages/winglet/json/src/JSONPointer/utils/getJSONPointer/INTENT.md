# getJSONPointer — 객체 참조로부터 JSON Pointer 역산출

## Purpose

루트 객체 아래에서 대상 값과 참조가 동일한 노드를 깊이 우선 탐색으로 찾아, 그 위치를 가리키는 RFC 6901 JSON Pointer 문자열을 반환하는 단일 함수를 소유한다. 값을 미리 알 때 그 값에 도달하는 포인터를 역으로 구하는 용도다.

포인터 문자열로 값을 읽거나 쓰는 정방향 연산은 소유하지 않는다 — 형제 연산 fractal의 책임이다. 경로 세그먼트 이스케이프는 형제 escape fractal의 `escapeSegment`를 그대로 재사용하며 별도 규칙을 두지 않는다.

## Conventions

- 탐색은 참조 동일성으로 대상을 판별한다 — 구조적으로 값이 같아도 참조가 다른 객체는 매치되지 않는다.
- 이미 방문한 노드는 재방문하지 않는다 — 순환 참조를 포함한 구조에서도 항상 종료한다.

## Boundaries

### Always do

- 순회 대상 노드 종류를 늘릴 때도 방문 처리를 유지해 순환 참조에서의 종료를 보장한다
- 경로 세그먼트 생성 방식을 바꿀 때 형제 escape fractal의 이스케이프 규칙과 어긋나지 않게 한다

### Ask first

- 매칭 기준을 참조 동일성에서 구조적 동일성으로 바꾸는 변경
- 반환 타입(문자열 또는 `null`) 계약 변경

### Never do

- 상속된 프로퍼티를 순회 대상에 포함시키는 변경
- 방문 여부 확인 없이 순회 경로를 추가해 순환 참조에서 무한 루프를 일으키는 변경

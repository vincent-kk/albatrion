# keyword — 스캐너에 의존하지 않는 스키마 선언

## Purpose

지원하는 JSON Schema 방언과 기본 키워드 어휘, 키워드 서술 형을 소유합니다. 선언만 필요한 소비자가 스캐너 없이 `keyword` 하위 경로에서 가져올 수 있게 합니다.

## Conventions

- 선언은 값과 형만 담고, 모듈을 불러올 때 계산을 실행하지 않습니다.
- 스캐너가 쓰는 비트 표현과 컴파일된 키워드 표는 스캐너 모듈이 소유합니다.

## Boundaries

### Always do

- 다른 경로가 선언을 내보낼 때는 이 모듈의 객체를 그대로 다시 내보내게 해 값의 정체성을 하나로 유지합니다.

### Ask first

- 기본 키워드의 순서·종류·방언 또는 `Dialect` 항목을 바꾸는 변경
- 이 하위 경로에 새 공개 이름을 추가하는 변경

### Never do

- 스캐너·해소기 코드를 가져오는 변경
- 모듈을 불러올 때 실행되는 계산을 추가하는 변경

# resolveReference — 내부 $ref 인라인 해석

## Purpose

JSON Schema 내부의 참조를 수집하고, 수집한 정의를 동기 스캐너로 인라인하는 과정을 소유합니다. 첫 순회에서 참조 경로와 정의를 연결하고 다음 순회에서 해석 콜백으로 공급합니다. 순회와 순환 참조 처리는 형제 스캐너 모듈의 계약에 위임하며, 원격 참조를 가져오거나 무한히 펼치는 해석은 수행하지 않습니다.

## Conventions

- 참조 수집과 인라인 해석을 분리한 두 단계 동기 순회를 유지합니다.
- 스캐너의 참조 해석 콜백에 수집한 정의를 제공하며, 이 모듈에서 별도의 트리 순회나 입력 객체 변경을 구현하지 않습니다.

## Boundaries

### Always do

- 참조 수집과 인라인 두 단계 모두 동기 `JSONSchemaScanner`의 엔트리 포인트를 통해서만 사용한다
- 동작을 바꾸는 변경은 DETAIL.md를 먼저 갱신한다

### Ask first

- 비동기 버전 제공, 또는 원격 등 외부 참조 해석 지원 추가
- 순환 참조를 1레벨을 넘어 더 깊이 인라인하도록 확장

### Never do

- 스캐너를 거치지 않고 직접 스키마 트리를 순회·치환하는 로직 추가
- 인자로 받은 원본 스키마 객체를 직접 변경하는 코드 추가

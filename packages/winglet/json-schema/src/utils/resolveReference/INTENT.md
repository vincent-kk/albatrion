# resolveReference — 내장 해소기를 이용한 일괄 참조 해석

## Purpose

내장 참조 해소기를 구성하고 동기 스캐너의 한 번의 순회로 결과를 만드는 편의 함수를 소유합니다. 주소와 템플릿 판단은 해소기에, 순회와 순환·상한 처리는 스캐너에 위임합니다.

## Conventions

- 해소기 구성과 한 번의 동기 순회를 연결합니다.
- 별도의 트리 순회나 입력 객체 변경을 구현하지 않습니다.

## Boundaries

### Always do

- 해소기와 동기 스캐너는 각자의 엔트리 포인트를 통해서만 사용한다
- 동작을 바꾸는 변경은 DETAIL.md를 먼저 갱신한다

### Ask first

- 자동 I/O 또는 별도의 비동기 편의 함수 추가
- 해소기와 스캐너가 정한 한계·보존 이유를 우회하는 변경

### Never do

- 스캐너를 거치지 않고 직접 스키마 트리를 순회·치환하는 로직 추가
- 인자로 받은 원본 스키마 객체를 직접 변경하는 코드 추가

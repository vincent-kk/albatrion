# resolveURI — 모든 기준 URI에서의 RFC 3986 참조 해석

## Purpose

써 있는 참조나 식별자를 RFC 3986 5.2절대로 기준 URI에 대해 해석하고, 값이 스킴으로 시작하는 절대 URI인지 판별합니다. 기준은 `https:` 같은 계층 URI, `urn:`·`tag:` 같은 계층 없는 URI, 상대 경로, 알 수 없는 기본 기준(빈 문자열) 중 무엇이든 됩니다. JSON Schema의 방언·식별자·자원은 알지 못하며, 그 판단은 부모 해소기가 소유합니다.

## Conventions

- 해석 결과의 규칙과 이유는 부모 해소기 `DETAIL.md`의 addresses 항목이 정합니다. 이 단위는 그 항목을 구현할 뿐 규칙을 따로 적지 않아, 같은 규칙이 두 문서에서 갈라지지 않습니다.

## Boundaries

### Always do

- 해석 규칙을 바꿀 때는 부모 해소기 `DETAIL.md`의 addresses 항목을 먼저 고칩니다.

### Ask first

- 계층 URI 기준의 결과가 바뀌는 변경(출력 주소와 등록 문서 조회 키가 함께 바뀜)
- 진입점에 이름을 더하는 변경

### Never do

- 네트워크·파일 접근이나 JSON Schema 개념(방언, 키워드, 식별자 키워드)에 기대는 코드 추가. 그 판단은 부모 해소기가 하므로, 여기에 섞으면 같은 판단이 두 곳에 생겨 갈라집니다.
- 진입점 밖의 코드가 내부 단계(인코딩, 상대 해석, 점 구간 제거)를 직접 가져오게 하는 공개. 그러면 해석 규칙을 바꿀 때 영향 범위를 진입점으로 가늠할 수 없습니다.

# createReferenceResolverAsync — 호출자의 load로 문서를 채우는 비동기 해소기

## Purpose

공유 저장소 앞에 비동기 읽기를 더한 해소기를 만듭니다. 참조가 가리키는 문서가 저장소에 없을 때만 호출자의 `load`로 읽어 저장소에 넣고, 답은 저장소가 만듭니다.

## Conventions

- 읽는 조건, 요청 공유, 예외 전파의 규칙과 이유는 부모 해소기 `DETAIL.md`의 비동기 문단이 정합니다.

## Boundaries

### Always do

- 읽은 문서는 저장소의 `add`로 넣은 뒤 같은 참조를 저장소의 `resolve`로 답합니다. 읽은 결과로 직접 답하면 그 문서가 동기 해소기와 같은 규칙으로 색인되지 않습니다.

### Ask first

- `load`를 부르는 조건이나 요청을 공유하는 범위를 바꾸는 변경

### Never do

- `load`를 Promise 체인 밖에서 직접 부르는 코드. 동기 예외가 공유 요청에 담기지 않아, 진행 중인 같은 문서 요청이 하나의 실패를 공유하지 못합니다.

# createReferenceResolver — 문맥을 보존하는 참조 해소

## Purpose

문서·내장 자원의 주소를 색인하고, 호스트 위치에서 의미를 유지하는 참조 대상을 제공합니다. 안전을 보장할 수 없는 이동은 이유를 남겨 보존하며 네트워크나 파일을 스스로 읽지 않습니다.

## Conventions

- 순회는 동기 스캐너의 공개 진입점을 사용하고 사본은 공통 반복 복제를 사용합니다.
- 출력 방문 제한과 무관하게 옮길 대상 전체를 조사합니다.

## Boundaries

### Always do

- 자원 방언과 기준 URI, 앵커와 정규 위치를 구분해 주소를 해석합니다.
- 서로 다른 위치의 식별자 충돌은 두 위치를 포함한 오류로 처리합니다.
- 비동기 로드는 호출자가 준 함수로만 수행하고 같은 문서의 진행 중 요청을 합칩니다.

### Ask first

- 지원 방언과 이동 가능 조건을 넓히는 변경
- 자동 I/O 또는 참조 그래프의 공개 API 추가

### Never do

- 원본 문서나 반환한 템플릿을 스캐너가 수정하도록 허용
- 별도의 스키마 트리 워커 또는 드라이버 내부를 직접 가져오는 코드 추가

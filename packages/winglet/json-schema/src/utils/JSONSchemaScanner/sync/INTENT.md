# sync — 동기 순회 드라이버

## Purpose

공통 순회 엔진을 기다림 없이 구동하는 동기 스캐너를 소유합니다. 순회·어휘·출력은 상위 organ의 계약을 따르며 주소 색인이나 사본의 이동 가능성을 직접 판단하지 않습니다.

## Conventions

- 콜백은 직접 호출하며 반환값의 then 속성을 읽지 않습니다.
- 해소기 결과는 동기 프로토콜로 검증해 Promise를 스키마로 인라인하지 않게 합니다.

## Boundaries

### Always do

- 실패한 스캔의 출력 상태를 비워 부분 결과가 다음 호출로 섞이지 않게 합니다.
- 공통 엔진의 같은 entry를 enter와 exit에 전달하는 계약을 유지합니다.

### Ask first

- 콜백 대기 또는 공개 반환 타입 변경
- 스캔 중 재진입·출력 접근 허용

### Never do

- 비동기 대기를 동기 드라이버 안에 추가
- 참조 해소나 자식 순회를 별도 구현해 비동기 드라이버와 결과를 갈라놓는 변경

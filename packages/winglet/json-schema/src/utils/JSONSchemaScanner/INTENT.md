# JSONSchemaScanner — 스캔 구현과 그 파생 해소기

## Purpose

동기·비동기 스캐너와 두 드라이버가 공유하는 순회 엔진·출력·방언 판별·어휘 컴파일·복제·오류를 소유하고, 스캐너의 해소기 프로토콜을 구현하는 내장 해소기를 하위 모듈로 둡니다. 이 진입점은 패키지 안의 다른 모듈을 위한 계약이며, 패키지 루트와 공개 하위 경로는 그 일부를 골라 내보냅니다.

## Conventions

- 공개 하위 경로(`scanner`, `async-scanner`)는 이 진입점과 같지 않습니다. 각 하위 경로의 표면은 해당 하위 모듈의 진입점이 정합니다.
- 방언과 기본 키워드 같은 스키마 선언은 keyword 모듈의 진입점에서 가져옵니다.

## Boundaries

### Always do

- 두 드라이버와 해소기가 함께 쓰는 구현은 이 모듈의 organ에 두어 의미가 갈라지지 않게 합니다.
- 패키지 안의 다른 모듈에는 이 진입점으로만 스캐너와 해소기를 제공합니다.

### Ask first

- 해소기를 이 모듈 밖으로 옮기거나 다른 해소기 구현을 하위 모듈로 추가하는 변경
- 이 진입점에 구현 헬퍼를 추가하는 변경

### Never do

- 스키마 선언을 이 모듈 안에 다시 정의하는 변경
- organ이 하위 모듈(sync, async, createReferenceResolver)을 가져다 쓰는 변경

# async — 순차 대기하는 순회 드라이버

## Purpose

공통 순회 엔진의 중단 지점을 기다리고 같은 지점에서 재개하는 비동기 스캐너를 소유합니다. 순회·어휘·출력 규칙을 복제하지 않고 대기 정책만 담당합니다.

## Conventions

- thenable 결과만 순차적으로 기다립니다. 형제 방문을 먼저 시작하지 않습니다.
- 동기 드라이버와 동일한 입력·변환은 동일한 결과를 만듭니다.

## Boundaries

### Always do

- 대기 전 콜백을 다시 호출하지 않고 완료값을 원래 프레임에 전달합니다.
- 대기 중에도 실행 가드를 유지해 같은 인스턴스의 상태가 섞이지 않게 합니다.

### Ask first

- 병렬 콜백 실행이나 자동 문서 로드 추가
- 동기 드라이버와 다른 순회·보존 규칙 도입

### Never do

- 동기 클래스를 상속해 대기 정책과 순회 규칙을 결합
- 실패 뒤 부분 출력이나 미완료 연산을 남기는 변경

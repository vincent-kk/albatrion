# array — 배열 변환·비교·순회 유틸리티

## Purpose

원소 접근·변환(단일 함수)과 순회(콜백 기반, 조기 종료 지원), 비교(차집합·교집합·중복 제거의 네 접미사 계열), 그룹화, 병합·정렬 연산을 소유한다. 모든 함수는 인자로 받은 배열을 변형하지 않고 새 배열이나 스칼라·불리언·프로토타입 없는 객체를 반환하는 순수 함수다.

## Conventions

- 비교 계열은 접미사로 알고리즘·동등성 계약을 구분한다: 접미사 없음은 Set 기반 SameValueZero, `By`는 매퍼 결과를 Set에 담아 비교, `With`는 커스텀 비교자로 중첩 순회, `Lite`는 indexOf 기반 강한 동등을 쓰는 소배열 특화판이다 — 넷은 이름이 비슷해도 동등성 의미론이 서로 다르다.
- 타입 검증(예: `chunk`의 size)은 filter 형제 fractal의 판별자를 그대로 가져와 재사용하고, 이 fractal에서 다시 구현하지 않는다.
- 잘못된 입력에 예외를 던지지 않고 안전한 대체값으로 응답한다(예: 유효하지 않은 청크 크기는 원본 전체를 담은 배열 하나로 대체).

## Boundaries

### Always do

- `Lite` 접미사 함수의 동등성 의미론(강한 동등, indexOf 기반)을 접미사 없는 버전(SameValueZero, Set 기반)과 다르게 유지한다 — 통합하면 소배열 최적화 함수가 존재할 이유가 없어진다
- 알고리즘 선택 임계값이나 Big-O 계약을 바꾸는 변경은 DETAIL.md를 먼저 갱신하고 벤치마크로 무회귀를 증명한다

### Ask first

- 비교·순회 계열의 동등성 알고리즘(Set/SameValueZero ↔ indexOf/강한 동등) 교체
- `groupBy` 반환 객체의 프로토타입 계약(`Object.create(null)`) 변경
- 외부에 널리 소비되는 함수(`map` 등)의 시그니처 확장

### Never do

- source/target/array 등 입력 배열을 제자리에서 변형하는 코드 추가
- filter가 이미 제공하는 타입 판별을 이 fractal에서 재구현

# equals — 객체 비교 정책 경계

## Purpose

값의 재귀적 동등성을 판단하는 일반 비교와 안정 비교의 계약을 소유한다. 두 정책이 함께 쓰는 내장 객체 상태 비교와 제외 키의 처리 기준도 이 경계에서 결정한다.

비교 키 생성이나 그래프 저장·복원은 소유하지 않는다. 패키지 밖 소비자는 빠른 일반 비교와 순환·확장 키를 다루는 안정 비교 중 필요한 관찰 범위를 선택한다.

## Conventions

- 일반 비교는 열거 가능한 문자열 키와 배열 인덱스 값을 빠르게 순회한다. 순환 추적과 배열 hole 구분이 필요하면 안정 비교를 선택한다.
- 안정 비교는 방문한 객체 쌍을 기록하고 배열 인덱스의 존재 여부와 심볼을 포함한 own 키를 관찰한다. 깊은 비순환 입력에는 재귀 스택 한도가 남는다.
- 제외 키를 사용할 때는 양쪽에서 제외한 뒤 남은 키를 비교한다. 제외 전 전체 키 수로 먼저 거절하면 부분 비교 계약을 깨뜨린다.
- Date·RegExp·Map·Set은 빈 키 목록으로 같다고 판단하지 않고 실제 상태를 비교한다. Set 구성원과 Map 키의 객체는 참조 동일성으로 일치시킨다.

## Boundaries

### Always do

- 두 공개 비교 정책이 공유하는 내장 상태 규칙에 선택한 정책의 재귀 비교를 전달한다.
- 새 비교 대상의 키 관찰 범위와 순환·희소 배열 의미를 어느 정책에 적용할지 명시한다.

### Ask first

- 일반 비교에 순환 추적이나 심볼 키 관찰을 추가해 비용과 동등성 기준을 바꾸는 변경
- 안정 비교의 순환 쌍 판정이나 Map·Set의 객체 키·구성원 일치 기준을 바꾸는 변경

### Never do

- 내장 객체의 열거 키가 비어 있다는 이유만으로 서로 다른 상태를 같다고 판정하지 않는다.
- 내부 비교 helper를 독립 공개 API로 노출하지 않는다.

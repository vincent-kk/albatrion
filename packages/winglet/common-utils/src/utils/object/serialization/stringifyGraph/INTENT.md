# stringifyGraph

## Purpose

지원 값의 그래프를 버전 있는 JSON 문자열로 만드는 경계를 소유합니다. 복원과 비교 키 정규화는 소유하지 않습니다.

## Conventions

인코딩은 상위 직렬화 계약의 지원 값·참조·omit 의미론을 따릅니다. 생성한 JSON에도 같은 문자열 크기 한도를 적용하여 저장과 읽기의 한도가 어긋나지 않게 합니다.

## Boundaries

### Always do

- 순환·공유 참조를 보존하는 graph 표현을 문자열로 만듭니다.
- 비지원 값·자원 한도 위반을 조용히 손실시키지 않고 실패를 전달합니다.

### Ask first

- wire 버전·문자열 한도 또는 omit의 의미를 바꾸는 경우

### Never do

- 속성 순서가 다른 입력에 동일한 비교 키를 보장하지 않습니다.
- 사용자 accessor나 toJSON을 변환 수단으로 실행하지 않습니다.

# src — common-utils 진입 배럴

## Purpose

`@winglet/common-utils`의 루트 공개 경계를 소유한다. 소비자가 소유 모듈의 심볼을 같은 이름으로 가져오게 하고, 공개 이름의 의미가 루트와 하위 진입점 사이에서 달라지지 않게 한다.

개별 유틸리티의 동작·계약과 로컬 구현은 소유하지 않는다. 이 경계는 런타임 의존성 없이 유지되며, 하위 공개 경로로 필요한 모듈만 선택할 수 있게 한다.

## Conventions

- 별칭은 같은 유틸리티에 두 공개 이름을 만들므로 사용하지 않는다. 이름을 바꿔야 한다면 소유 모듈의 계약과 소비자 영향을 먼저 판단한다.
- 루트 공개 표면을 넓힐 때는 소유 모듈이 이미 그 심볼을 계약으로 제공하는지 확인하고, 하위 공개 경로와 의미가 일치하는지 판단한다. 동작의 결정은 소유 모듈에 남긴다.
- 값과 타입 전용 재수출을 구분하되 둘 다 이름을 명시한다. 와일드카드는 하위 구현의 새 export를 루트 계약에 묵시적으로 추가하기 때문이다.

## Boundaries

### Always do

- 새 공개 심볼은 원본 이름 그대로 값 또는 타입 전용 이름 재수출로 추가한다.
- 재수출 대상 모듈이 추가되거나 이름이 바뀌면 루트 경계와 패키지 공개 경로의 정합성을 함께 확인한다.

### Ask first

- 재수출이 아닌 로컬 구현을 루트에 추가하는 변경
- 재수출 심볼에 별칭을 붙이거나 기존 공개 이름을 바꾸는 변경

### Never do

- `export *` 와일드카드 재수출 추가
- 런타임 의존성(dependencies) 추가

# 공유 TypeScript 선언

## Purpose

워크스페이스가 공유하는 함수·객체·선택 값·표현 단위의 수기 타입 계약을 소유합니다. 빌드 도구 설정이나 런타임 구현을 소유하지 않습니다.

## Conventions

선언 전용 index가 이 모듈의 실제 진입점입니다. 일반 구현 index와 확장자가 달라도 같은 공개 경계이므로 adapter entry override로 명시합니다. 카테고리별 선언은 역할을 보이는 평면 구조로 유지합니다.

## Boundaries

### Always do

- 외부 소비자는 기존 선언 주소에서 이름을 명시한 타입을 읽습니다.
- 타입을 재표현할 때 매개변수·반환값·선택 값의 의미와 이름을 보존합니다.

### Ask first

- 공개 타입 이름·기본 제네릭 또는 할당 가능성의 계약을 바꾸는 경우

### Never do

- 런타임 값이나 초기화 부수 효과를 추가하지 않습니다.
- 소비자 패키지의 구현 타입을 가져와 공통 선언의 의존 방향을 뒤집지 않습니다.

# Scale Feature Scenarios

## Purpose

기능 카탈로그의 규모와 가상화(G10) 그룹이 새로 쓰는 공유 장면과 사례 상수를 소유합니다.
가상화의 지연 마운트와 노출, 천 개 항목 배열의 편집, 계산 표현식이 많은 폼을 다룹니다.

규모 장면은 같은 동작의 보존을 검증하며 속도를 약속하지 않습니다.
기계별 시간 차이를 기능 회귀로 오인하지 않게 합니다.

화면 노출은 실제 뷰포트가 있는 소비자에서만 관찰합니다.
비활성 관찰자 대역의 성공을 실제 가상화 노출의 증거로 삼지 않습니다.

## Conventions

- 장면 모듈은 데이터 전용으로 두며, 실행은 어댑터가 소유합니다(TEST-010).
- 장면 이름은 `scale.` 접두사로 식별하고 모든 최상위 단계에 기대값을 둡니다.
- 장면 형식에 없는 Form 속성과 소비자 전용 상호작용은 사례 상수로 두고, 엔진 열거형 대신 이름으로 적어 소비자가 바꿉니다.

## Boundaries

이 부류는 새 장면의 입력과 관찰 가능한 기대값을 소유합니다.
소비자는 엔진 실행·렌더링·검증기 등록·단언 런타임을 소유합니다.

## Always do

- 사례 상수의 기대값은 현재 소유 계약의 안정 ID로 식별하고 장면 설명에 남깁니다.
- 시간이나 처리량 수치는 단언하지 않고, 큰 규모에서도 동작이 같은지만 적습니다.
- 가상화 옵션은 평범한 데이터로 적고, 소비자가 엔진의 열거형 값으로 바꿉니다.

## Ask first

- 부류의 책임을 규모와 가상화 밖으로 넓히기 전에 확인합니다.
- 장면 형식(`FormScenario`)에 새 단계나 기대 키를 더하기 전에 확인합니다.

## Never do

- 엔진의 형과 열거형을 포함해 폼 엔진이나 테스트 러너를 장면 데이터에 가져오지 않습니다.
- 지금 엔진의 결함 동작을 기대값으로 고정하지 않습니다(결함이나 미결 질문이면 발견 장면으로 따로 둡니다).

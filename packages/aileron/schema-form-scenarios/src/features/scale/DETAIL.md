# Scale Feature Scenarios contract

## Requirements

큰 배열·많은 식·지연 마운트에서 동작이 보존되는 장면을 소유합니다. 시간과 처리량을 기대값으로 두지 않아 실행 기계의 차이가 기능 판정을 바꾸지 않게 합니다.

## API Contracts

가상화 옵션은 평범한 데이터로 공유하고 소비자가 실제 열거형으로 해석합니다. jsdom e2e는 관찰자를 비활성 대역으로 바꾸므로 노출 경로는 focus 명령으로 확인하며 스크롤 노출의 증거로 삼지 않습니다.

실제 뷰포트 노출과 큰 배열의 마지막 항목 사용자 입력은 브라우저 스토리가 확인합니다. 핸들 쓰기만으로 미룬 입력의 편집 가능성을 검증했다고 판단하지 않습니다.

## Acceptance Criteria

### scale-scene-data — 공유 장면 경계

- 공유 형식의 수용 기준은 [패키지의 scenario-data 계약](../../../DETAIL.md)에 둡니다.

### scale-scene-coverage — 관찰을 보존하는 기준

- 크기가 커져도 같은 값·형상·동사 결과를 관찰하며 소요 시간으로 기능 성공을 결정하지 않습니다.
- 실제 노출과 명령에 의한 마운트의 증거를 구별하여 관찰자 대역이 노출 결함을 가리지 않게 합니다.

# Derivation Feature Scenarios

## Purpose

기능 카탈로그의 파생·주입·감시(G4) 그룹이 새로 쓰는 공유 장면과 사례 상수를 소유합니다.
visible과 active의 대비, watch 의존성, resetInteraction, 맥락(`@`) 참조를 다루고, 나머지는 controls·exit·derive·union 부류에서 가져옵니다.

## Conventions

- 장면 모듈은 데이터 전용으로 두며, 실행은 어댑터가 소유합니다(TEST-010).
- 장면 이름은 `derivation.` 접두사로 식별하고 모든 최상위 단계에 기대값을 둡니다.
- 장면 형식에 없는 Form 속성과 소비자 전용 상호작용은 사례 상수로 두고, 엔진 열거형 대신 이름으로 적어 소비자가 바꿉니다.

## Boundaries

이 부류는 새 장면의 입력과 관찰 가능한 기대값을 소유합니다.
소비자는 엔진 실행·렌더링·검증기 등록·단언 런타임을 소유합니다.

## Always do

- 사례 상수의 기대값은 원장 항목으로 근거를 대고, 장면 설명에 그 항목을 적습니다.
- controls·exit·derive 부류에 같은 동작의 장면이 있으면 소비자가 거기서 가져오고 여기로 복사하지 않습니다.

## Ask first

- 부류의 책임을 파생·주입·감시 밖으로 넓히기 전에 확인합니다.
- 장면 형식(`FormScenario`)에 새 단계나 기대 키를 더하기 전에 확인합니다.

## Never do

- 엔진의 형과 열거형을 포함해 폼 엔진이나 테스트 러너를 장면 데이터에 가져오지 않습니다.
- 지금 엔진의 결함 동작을 기대값으로 고정하지 않습니다(결함이나 미결 질문이면 발견 장면으로 따로 둡니다).

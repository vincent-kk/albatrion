# Values Feature Scenarios contract

## Requirements

기본 입력·리터럴·채움 층·재귀의 기능 장면을 소유합니다. value·fill의 기존 장면은 원래 부류에서 소비하여 동일 동작의 기대값을 복제하지 않습니다.

## API Contracts

오류 기대값은 부분 필드와 개수·순서를 함께 대조하며 렌더 소비자가 검증기를 주입합니다.

제한 입력의 집합 밖 값은 노드 값과 실제 입력 요소를 함께 관찰합니다. `valuesFindingScenarios`라는 이름은 실패 예상 시험을 뜻하지 않으며, enum 밖 값의 표시와 잘못된 날짜의 편집 가능성은 보통 e2e·브라우저 사례로 검증합니다.

이 관찰은 형 어긋남 처리만으로 대신할 수 없습니다. 집합 밖 enum이나 날짜도 문자열 형에는 맞을 수 있고 기본 입력의 일반 계약은 enum·format의 표시 방식을 정하지 않으므로, 제한 입력이 값을 숨기는 간극을 따로 검증합니다(REACT-027·033).

## Acceptance Criteria

### values-scene-data — 공유 장면 경계

- 공유 형식의 수용 기준은 [패키지의 scenario-data 계약](../../../DETAIL.md)에 둡니다.

### values-scene-coverage — 관찰을 보존하는 기준

- 채움 계기의 구분을 유지하고 재귀 장면은 깊은 경로의 관찰을 생략하지 않습니다.
- 제한 입력은 출력 비교만으로 성공시키지 않고 실제 입력 표시를 확인하여 보유 값과 화면의 간극을 검출합니다.

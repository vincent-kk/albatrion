# Values Feature Scenarios

## Purpose

기능 카탈로그의 값과 기본 입력(G1) 그룹이 새로 쓰는 공유 장면을 소유합니다.
원시 다섯 종류의 기본 입력, 리터럴·형식, 채움 원천과 시점, 재귀 참조를 다룹니다.

## Conventions

- 장면 모듈은 데이터 전용으로 두며, 실행은 어댑터가 소유합니다(TEST-010).
- 장면 이름은 `values.` 접두사로 식별하고 모든 최상위 단계에 기대값을 둡니다.
- value·fill 부류에 같은 동작의 장면이 있으면 소비자가 거기서 가져오고, 이 부류는 입력 종류·채움 층·재귀만 더합니다.

## Boundaries

이 부류는 새 장면의 입력과 관찰 가능한 기대값을 소유합니다.
소비자는 엔진 실행·렌더링·검증기 등록·단언 런타임을 소유합니다.

## Always do

- 원장이 정하지 않은 화면과 노드 값의 어긋남은 소유자 질문 장면으로 따로 둡니다.
- 오류 기대값은 keyword 같은 부분 계약으로 적고, 개수와 순서를 함께 고정합니다.

## Ask first

- 부류의 책임을 값과 기본 입력 밖으로 넓히기 전에 확인합니다.
- value·fill 부류의 장면을 이 부류로 옮기기 전에 확인합니다.

## Never do

- 엔진의 형을 포함해 폼 엔진이나 테스트 러너를 장면 데이터에 가져오지 않습니다.
- 지금 엔진의 결함 동작을 기대값으로 고정하지 않습니다(결함이나 미결 질문이면 발견 장면으로 따로 둡니다).

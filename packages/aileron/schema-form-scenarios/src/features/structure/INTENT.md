# Structure Feature Scenarios

## Purpose

기능 카탈로그의 객체와 배열 구조(G2) 그룹이 새로 쓰는 공유 장면을 소유합니다.
선언 프로퍼티와 잔여 키, 중첩 배열 동사, 배열 제약의 오류 귀속, batch 안 배열 동사의 위치 동일성을 다룹니다.

## Conventions

- 장면 모듈은 데이터 전용으로 두며, 실행은 어댑터가 소유합니다(TEST-010).
- 장면 이름은 `structure.` 접두사로 식별하고 모든 최상위 단계에 기대값을 둡니다.
- 배열 동사 하나짜리 장면은 array 부류에 있으므로 소비자가 거기서 가져오고, 이 부류는 중첩·조합·오류 귀속만 더합니다.

## Boundaries

이 부류는 새 장면의 입력과 관찰 가능한 기대값을 소유합니다.
소비자는 엔진 실행·렌더링·검증기 등록·단언 런타임을 소유합니다.

## Always do

- 동사 뒤의 노드 동일성은 `identity` 기대값으로 고정합니다.
- 오류 기대값은 keyword 같은 부분 계약으로 적고, 개수와 순서를 함께 고정합니다.

## Ask first

- 부류의 책임을 객체와 배열 구조 밖으로 넓히기 전에 확인합니다.
- array 부류의 장면을 이 부류로 옮기기 전에 확인합니다.

## Never do

- 엔진의 형을 포함해 폼 엔진이나 테스트 러너를 장면 데이터에 가져오지 않습니다.
- 지금 엔진의 결함 동작을 기대값으로 고정하지 않습니다(결함이면 발견 장면으로 따로 둡니다).

# Notify Scenarios contract

## Requirements

통지 순서·콜백 수·경고 기록을 관찰하는 공유 장면을 소유합니다. 최종 값만 비교하면 중복 배달과 불필요한 검증 요청이 숨습니다.

## API Contracts

동일 값 재쓰기와 숫자 입력으로 표현할 수 없는 잘못된 형 쓰기는 `batch`로 명령형 진입을 명시합니다. 화면 타이핑의 중간 쓰기나 브라우저의 초안 거부가 통지·경고 계기를 바꾸지 않게 합니다.

배달 순서·onChange·검증 요청·오류 기록은 관찰 어댑터가 계측하며 단순한 값 어댑터로 대체하지 않습니다.

## Acceptance Criteria

### notify-scene-data — 공유 장면 경계

- 공유 형식의 수용 기준은 [패키지의 scenario-data 계약](../../DETAIL.md)에 둡니다.

### notify-scene-coverage — 관찰을 보존하는 기준

- 값이 같은 쓰기도 관찰하여 무통지와 실제 변경 통지를 구별합니다.
- 검증 요청 횟수는 명시적 판정 확인 전에 계측하여 단언이 만든 요청을 동작의 일부로 세지 않습니다.

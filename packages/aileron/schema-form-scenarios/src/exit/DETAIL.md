# Exit Scenarios contract

## Requirements

나감의 값 보존과 비움을 구별하는 왕복 장면을 소유합니다. 나간 직후의 출력만 비교하면 잠복 값이 잘못 지워진 결함을 발견하지 못합니다.

## API Contracts

존재를 읽는 형제 게이트는 읽히는 필드와 함께 양방향 전환을 관찰합니다. 잠복 source의 유지와 방출상 존재는 다른 계기이므로, 한쪽 값의 관찰로 다른 쪽 게이트를 대신하지 않습니다.

## Acceptance Criteria

### exit-scene-data — 공유 장면 경계

- 공유 형식의 수용 기준은 [패키지의 scenario-data 계약](../../DETAIL.md)에 둡니다.

### exit-scene-coverage — 관찰을 보존하는 기준

- 왕복 뒤의 값과 비활성 경로 탐색을 함께 관찰하여 보존과 비움을 구별합니다.
- 존재 의존 장면은 양방향 전환 직후의 형상·방출을 확인하여 후속 입력이 누락된 재평가를 가리지 않게 합니다.

## Last Updated

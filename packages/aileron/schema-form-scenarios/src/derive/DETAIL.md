# Derive Scenarios contract

## Requirements

파생 에지·주입·로드 범위의 차이를 드러내는 공유 장면을 소유합니다. 수동 편집을 먼저 관찰해야 무관한 쓰기에 의한 재계산이 올바른 파생처럼 보이지 않습니다.

## API Contracts

수동 편집의 보존을 확인한 다음 무관한 에지와 의존 에지를 차례로 바꿉니다. null 조상 아래 자동 쓰기는 자식 값과 조상 출력을 따로 관찰하여 자동 승격을 놓치지 않습니다.

주입의 로드 범위·undefined 후보·예산 초과는 소비자 어댑터로 실행하며 실행 코드를 데이터에 넣지 않습니다.

## Acceptance Criteria

### derive-scene-data — 공유 장면 경계

- 공유 형식의 수용 기준은 [패키지의 scenario-data 계약](../../DETAIL.md)에 둡니다.

### derive-scene-coverage — 관찰을 보존하는 기준

- 의존하지 않는 에지 변경 전에 편집 값을 확인하여 준비 단계의 실패를 구별합니다.
- 하위 트리 로드의 원천 범위와 범위 밖 주입 대상을 함께 두어 과도한 발화를 검출합니다.

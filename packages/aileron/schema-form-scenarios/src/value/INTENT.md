# Value Scenarios

## Purpose

해석된 source 값과 객체 방출 투영을 다루는 공유 장면을 소유합니다.
주입된 실행 계층이 소비하는 이름 있는 장면 목록이 이 부류의 계약입니다.

값 장면은 source·방출·화면 초안의 관찰을 구별합니다.
하나의 값만 맞춰 서로 다른 투영의 회귀를 놓치는 일을 막습니다.

빈 입력 조작과 호출자의 빈 문자열 쓰기는 별도 계기로 유지합니다.
화면 어댑터의 입력 처리를 엔진 쓰기의 의미로 오인하지 않게 합니다.

## Conventions

- 장면 모듈은 데이터 전용으로 두며, 실행은 어댑터가 소유합니다(TEST-010).
- 스키마·순서 있는 단계·기대값을 구조적 계약으로 기술합니다.

## Boundaries

이 부류는 시나리오 입력과 관찰 가능한 기대값을 소유합니다.
소비자는 엔진 실행·렌더링·단언 런타임을 소유합니다.

## Always do

- 코어·렌더·스토리 소비자가 공유 장면을 재사용할 수 있게 유지합니다.
- `index.ts`의 이름 있는 장면 목록 경계를 보존합니다.

## Ask first

- 부류의 책임을 value 동작 범위 밖으로 넓히기 전에 확인합니다.
- 특정 소비자의 요구에 맞춰 공유 동작 어휘를 바꾸기 전에 확인합니다.

## Never do

- 엔진의 형을 포함해 폼 엔진이나 테스트 러너를 장면 데이터에 가져오지 않습니다.
- 부류를 가져올 때 시나리오 동작이나 단언을 실행하지 않습니다.

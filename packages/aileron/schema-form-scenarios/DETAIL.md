# Schema Form Scenarios contract

## Requirements

공유 시나리오는 코어·렌더 e2e·Storybook이 같은 스키마·계기·기대를 소비하는 단일 정본입니다. 실행 계층마다 데이터를 복제하면 서로 다른 동작을 시험하면서 같은 계약을 검증했다고 판단하게 됩니다.

이 비공개 패키지는 타입 전용으로도 `@canard/schema-form`을 가져오지 않습니다. schema-form의 시험이 이 패키지를 소비하므로 역방향 의존은 순환을 만듭니다. 폼·핸들·스키마는 구조적으로 기술하고 구현은 소비자가 주입합니다.

## API Contracts

동작과 기대값의 형은 [구조적 선언](src/types.ts)이 정합니다. 어휘 확장은 모든 실행기의 해석을 함께 검토하며, 기대값에 명시한 `undefined`와 생략한 관찰을 구별합니다. 선언에 없는 Form props·컴포넌트·브라우저 계측은 가족별 사례 데이터와 소비자 실행으로 두어 코어 러너가 렌더 환경에 결합되지 않게 합니다. 장면·description·소비자 제목의 안정 ID는 관찰 대상의 꼬리표이며 파일 경로나 외부 실행 입력으로 해석하지 않습니다.

`playScenario(scenario, element)`는 등록된 어댑터의 실행·정착·단언을 순서대로 기다립니다. 배치 내부의 해석과 화면 입력·핸들 진입의 선택은 소비자 어댑터가 맡습니다. 패키지는 엔진이나 위젯의 뜻을 추측하지 않으며 실패를 조용히 건너뛰지 않습니다.

핸들을 별도 실행 인자로 넘기지 않고 DOM 범위에 등록합니다. Storybook의 렌더와 play가 별도 문맥에서 실행되어도 같은 호출 모양으로 연결하기 위해서입니다. 자기 요소의 등록을 우선하고, 없을 때만 유일한 자손 등록을 사용하며, 이전 등록의 cleanup은 새 등록을 제거하지 않습니다.

## Acceptance Criteria

### scenario-data — TEST-008: 순수 공유 기술

- 장면 모듈은 실행·React·테스트 러너·엔진 의존을 넣지 않아 import만으로 폼이나 시험이 실행되지 않게 합니다.
- 공유 가족은 이름과 최상위 단계마다 실제 관찰을 유지합니다. 빈 목록이나 기대값 없는 뼈대는 엔진 동작 검증을 뜻하지 않습니다.

### TEST-009 — 코어 관찰의 소유자

- 노드 트리 해석·내부 계측·생성된 시험 수 검증은 소비자 코어 러너가 소유합니다. 엔진 의존의 역류를 막으며 가족 하나·러너 하나라는 배치나 데이터 파일 수만으로 파일당 사례 상한을 충족했다고 판단하지 않습니다.

### scenario-screen — TEST-010: 주입된 화면 해석

- user event·필드 탐색·핸들 전용 진입은 주입한 어댑터가 소유합니다. 같은 데이터의 공유가 환경별 입력 구현까지 같다는 뜻은 아닙니다.
- 코어 관찰의 성공만으로 DOM 입력·포커스·실제 뷰포트의 동작을 검증했다고 주장하지 않습니다.

### scenario-screen-order — 순서 있는 화면 실행

- 등록된 화면 어댑터는 각 단계를 순서대로 한 번씩 받고 완료까지 기다린다.
- 완료 후 기대값을 어댑터에 위임하며 실패를 전파한다.

### scenario-registration — TEST-011: 범위가 있는 DOM 전달

- 렌더러가 DOM에 등록하고 실행기는 범위 안에서 찾습니다. 자기 등록이 없을 때 자손 후보가 없거나 여럿이면 실패하여 다른 폼의 핸들을 잘못 선택하지 않습니다.
- 단계 어휘는 선언의 닫힌 합집합을 따릅니다. 빈 입력과 호출자의 빈 문자열 쓰기, 배열 clear와 잎의 undefined 쓰기를 소비자 해석에서 구별합니다.

### TEST-022 — 스토리와 e2e의 공유 관찰

- 스토리의 play와 e2e는 같은 장면 데이터를 소비하며 스키마·단계를 다시 쓰지 않습니다. 환경별 실행의 차이가 서로 다른 기대값으로 굳어지는 일을 막습니다.

### TEST-023 — 공유 데이터 밖의 단언

- spy·StrictMode·보고기·브라우저 전용 관찰은 소비자가 더합니다. 데이터 재사용을 이유로 실행 환경에서만 확인할 수 있는 단언을 제거하지 않습니다.

## Last Updated

공유 어휘·DOM 전달·실행 계층의 책임이나 데이터 재사용 경계가 바뀔 때 갱신합니다.

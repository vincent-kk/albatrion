# UI 입력 연결 계약

## Requirements

- 필드 배치 렌더러는 입력에 읽기 전용·비활성 상태를 전달합니다. 배치와 입력은 각자 받은 클래스와 스타일을 기존 표시 요소에 적용합니다. 배열 입력은 코어의 형식 불일치 상태를 기존 그룹에 전달합니다.

입력은 폼이 전달한 저장 값과 상태를 표시하며, 폼이 받은 입력의 유효성은 스키마 검증에서 판단합니다.

## API Contracts

코어가 공급한 inputId와 labelId는 Ant Design이 받는 id 및 ARIA 속성에 연결합니다. 복합 입력의 별도 주소는 getInputId(key)로 받습니다. path는 JSON Pointer로 사용합니다.

루트와 분기 렌더러는 코어가 제공한 오류 메시지가 있을 때 기존 오류 부품을 표시합니다. 날짜·월·시간 기간은 완결된 선택을 저장하고 clear를 빈 값으로 전달합니다. 피커와 선택기의 잠금은 Ant Design의 disabled 속성에 전달합니다. 텍스트 영역의 행 범위는 presentation 입력 설정을 우선 적용합니다.

Select는 표시한 태그의 선택을 저장합니다. 다중 Select 검색은 표시 레이블과 원래 enum 값을 대소문자 및 유니코드 정규화 형식의 차이 없이 찾습니다. Checkbox 그룹은 표시하지 않는 기존 값을 유지합니다. 별칭은 제공된 객체의 자체 속성에서 읽습니다.

Slider는 코어의 focusRef를 공개 Slider ref에 연결합니다. 읽기 전용과 비활성에는 같은 잠금 상태를 적용하고 포커스 핸들을 해제합니다. Slider의 숫자 범위는 스키마의 포함·제외 경계와 배수 조건을 따르며 허용되는 값이 없으면 비활성화합니다. 읽기 전용 Slider는 배수 제약이 없는 number 스키마에서 범위 안의 소수를 표시합니다. integer 스키마의 표시값은 정수 격자를 따르며 읽기 전용 표시 때문에 저장값을 변경하지 않습니다.

## Acceptance Criteria

### control-bindings — 컨트롤 연결

- 폼 간 식별자를 구별하며 지원되는 컨트롤 속성으로 연결합니다.
- 미설정, 읽기 전용 및 저장 시점은 폼과 라이브러리의 공개 입력 계약을 따릅니다.

## Last Updated

입력 바인딩·식별자 또는 부품 소유권의 경계가 바뀔 때 갱신합니다.

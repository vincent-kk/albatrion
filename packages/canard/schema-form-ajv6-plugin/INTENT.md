# AJV6 검증 플러그인

## Purpose

애플리케이션의 AJV 프로필을 폼 검증·가드·명시적 해제 계약에 연결합니다. 애플리케이션의 스키마 소유권과 폼의 수명을 구별합니다.

## Conventions

발행 manifest의 공개 진입점이 소비자 경계이며 검증 구현과 네이티브 레지스트리는 패키지가 소유합니다.

## Boundaries

### Always do

- 주입한 인스턴스의 옵션과 확장 의미를 유지합니다.
- 실행 실패는 검증 issue와 구별하며 호출자에게 같은 예외를 전달합니다.
- 폼의 해제가 애플리케이션 소유 등록을 변경하지 않게 합니다.

### Ask first

- 공개 검증 의미·설정 또는 등록 수명의 경계를 바꾸는 경우

### Never do

- 입력 데이터를 바꾸는 설정으로 폼의 값 해석을 대신하지 않습니다.
- 다른 인스턴스의 스키마나 생성 코드 소유권을 추정해서 제거하지 않습니다.

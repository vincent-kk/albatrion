# MUI 플러그인

## Purpose

MUI 입력과 표시 부품을 schema-form의 플러그인 계약에 연결합니다. MUI의 상호작용과 폼 노드의 상태 소유권을 합치지 않습니다.

## Conventions

폼의 입력 Hint로 부품을 선택하며, 플러그인 context는 MUI 표시 설정만 제공합니다. 검증이나 노드 값의 정규화는 이 모듈의 책임이 아닙니다.

## Boundaries

### Always do

- 폼의 값·잠금·읽기 전용 상태를 선택한 MUI 입력에 전달합니다.
- 선택지 identity와 표시 문자열을 구별하여 JSON 스칼라를 보존합니다.

### Ask first

- 입력 선택 우선순위·공개 context 또는 부품 등록 경계를 바꾸는 경우

### Never do

- 입력을 렌더하면서 스키마나 노드 값을 묵시적으로 고치지 않습니다.
- 검증기나 폼 실행 상태를 플러그인 전역에 보관하지 않습니다.

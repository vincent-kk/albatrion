# AJV8 검증 플러그인 패키지

## Purpose

발행 manifest가 선언한 세 방언 진입점과 이들이 함께 사용하는 검증 구현의 소유 경계입니다. 방언별 전역 선택과 폼별 검증 객체의 수명을 구별합니다.

## Conventions

manifest가 공개 주소를 선언합니다. 단일 src 진입점을 가진 형제 플러그인과 달리 방언별 자식이 각각 공개 진입점을 소유하므로, 공통 validator 구획은 이 패키지가 소유합니다. 소비자 없는 대표 index를 만들지 않습니다.

## Boundaries

### Always do

- 외부 소비자는 발행된 방언 진입점으로 접근하고 공통 구현은 패키지 안에 둡니다.
- 각 방언의 설정과 스키마 등록을 격리하면서 같은 검증기 계약을 지킵니다.
- 자식은 조상의 공통 구획을 구체 파일로 읽어 부모 배럴의 재수출 순환을 피합니다.

### Ask first

- 공개 방언 주소·검증 의미·설정 또는 등록 수명의 경계를 바꾸는 경우

### Never do

- 소유권을 표시하기 위해 공개 이름이나 독립 실행 상태를 추가하지 않습니다.
- 검증 입력의 값을 수정하는 설정으로 폼의 입력 해석을 대신하지 않습니다.

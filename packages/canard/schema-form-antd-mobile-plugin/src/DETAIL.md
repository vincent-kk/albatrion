# UI 입력 연결 계약

## Requirements

- 필드 배치 렌더러는 입력에 읽기 전용·비활성 상태를 전달합니다. 배치와 입력은 각자 받은 클래스와 스타일을 기존 표시 요소에 적용합니다. 배열 입력은 코어의 형식 불일치 상태를 기존 그룹에 전달합니다.

입력은 폼의 값과 상태를 라이브러리의 공개 prop으로 전달합니다. 입력의 유효성은 폼의 스키마 검증이 판단합니다.

## API Contracts

라이브러리가 지원하는 식별자 prop에 코어의 inputId와 labelId를 전달합니다. 보조 요소의 주소는 getInputId(key)에서 받습니다.

Slider의 숫자 또는 배열 형태와 범위는 스키마의 포함·제외 경계와 배수 조건으로 정하며 허용되는 값이 없으면 비활성화합니다. 범위 Slider는 숫자 항목의 제약을 우선 적용하고 빠진 제약은 배열 스키마에서 읽습니다. 라이브러리가 표시를 위해 thumb를 정렬할 때 폼의 저장 배열 순서는 유지됩니다. Switch와 Slider의 포인터 및 키보드 상호작용은 Ant Design Mobile이 제공합니다. Checkbox 그룹에 나타나지 않는 기존 배열 값은 유지하며, 텍스트 영역의 표시 설정을 스키마 확장보다 먼저 적용합니다. 루트와 분기에서 코어가 제공한 오류 내용을 표시합니다.

## Acceptance Criteria

### control-bindings — 폼 상태 전달

- 저장된 값과 사용자 변경을 라이브러리의 공개 prop과 콜백으로 연결합니다.

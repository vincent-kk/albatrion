# UI 입력 연결 계약

## Requirements

- 필드 배치 렌더러는 입력에 읽기 전용·비활성 상태를 전달합니다. 배치와 입력은 각자 받은 클래스와 스타일을 기존 표시 요소에 적용합니다. 배열 입력은 코어의 형식 불일치 상태를 기존 그룹에 전달합니다.
- 루트가 아닌 분기 필드(중첩 객체와 배열이며, 하나의 컨트롤로 그리는 Checkbox 그룹과 범위 Slider도 배열이라 분기입니다)와 배열 항목인 단말 필드는 보이는 제목과 필수 표시 없이 입력과 오류 메시지만 그립니다. 보이는 제목이 없는 루트가 아닌 필드는 모두 `hidden` 속성을 가진 제목 요소에 labelId와 필드 이름(배열 항목은 인덱스)을 담고, 입력의 `aria-labelledby`가 이 요소로 접근성 이름을 얻습니다. 이 요소가 없으면 배열 항목의 입력과 그룹이 존재하지 않는 요소를 가리킵니다. 단말의 숨긴 제목은 보이는 `Label`이 놓일 자리에 같은 감싸는 요소 안에 그려 `Space` 항목 수와 간격을 바꾸지 않습니다. 제목을 보이지 않게 두는 이유는 둘입니다. 공개된 0.x 버전이 분기와 배열 항목에 제목을 그리지 않았으므로 보이는 제목은 소비자의 화면 배치를 바꿉니다. 분기에는 `for`가 가리킬 단일 컨트롤이 없어 보이는 `label`을 두면 중첩 객체의 `for`가 존재하지 않는 요소를 가리킵니다. 숨긴 제목은 보조 기술이 제목을 `aria-labelledby`로 한 번만 만나게 합니다.

입력은 폼의 값과 상태를 라이브러리의 공개 prop으로 전달합니다. 입력의 유효성은 폼의 스키마 검증이 판단합니다. 읽기 전용 불리언 Checkbox는 활성 상태를 유지하고 폼이 값 변경을 막습니다.

## API Contracts

라이브러리가 지원하는 식별자 prop에 코어의 inputId와 labelId를 전달합니다. 보조 요소의 주소는 getInputId(key)에서 받습니다.

Slider의 숫자 또는 배열 형태와 범위는 스키마의 포함·제외 경계와 배수 조건으로 정하며 허용되는 값이 없으면 비활성화합니다. 범위 Slider는 숫자 항목의 제약을 우선 적용하고 빠진 제약은 배열 스키마에서 읽습니다. 라이브러리가 표시를 위해 thumb를 정렬할 때 폼의 저장 배열 순서는 유지됩니다. Switch와 Slider의 포인터 상호작용은 Ant Design Mobile이 제공하며, 키보드 상호작용은 라이브러리에 맡기고 플러그인은 이를 보장하지 않습니다. Checkbox 그룹에 나타나지 않는 기존 배열 값은 유지하며, 텍스트 영역의 표시 설정을 스키마 확장보다 먼저 적용합니다. 루트와 분기에서 코어가 제공한 오류 내용을 표시합니다.

## Acceptance Criteria

### control-bindings — 폼 상태 전달

- 저장된 값과 사용자 변경을 라이브러리의 공개 prop과 콜백으로 연결합니다.

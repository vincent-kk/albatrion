파생 방식
  문서화된 수동 사본이 아니라 정확 문자열 치환 스크립트 방식입니다.
  각 치환 대상은 정확히 한 번 나타나야 합니다. 구간 치환도 경계로 얻은 원문을
  동일한 유일 일치 검사로 치환합니다. 마지막에 runtime-v5.inc.txt를 붙입니다.
  regress/run.mjs는 실행 전 파일과 재생성 파일의 바이트 일치를 단언합니다.
  정본은 make-v5.mjs와 runtime-v5.inc.txt입니다. loop-v5.mjs 직접 수정은 없습니다.

스위치 (LV5:19)
| 스위치 | 기본값 | 비교값 |
| DERIVE_ORDER | ['derived','injectTo','clearValue'] | 세 단계의 다른 순서 |
| WRITE_CONFLICT | last | first |
| CONTROL_COMBINE | and-or | nearest |
| NODE_GATE_UNIT | shape | raw (정정 전 노드 게이트의 채움 동작) |

  v4e 회귀를 비교하기 위한 FINAL_SHAPE, AUTO_SCOPE, EDGE_REF, INJECT_TO_EDGE,
  LOAD_EDGE, ORDER_HINT, DERIVED_MODE, EDGE_COMPARE, EXTRAS_ORDER도 남아 있습니다.
  OLD_SWITCHES는 과거 쓰기 모드의 비교값입니다. selection 및 v4e의 default 철회를
  복원하지 않으므로 old 출력이 과거 모델 전체와 동일하다는 뜻은 아닙니다.

예약 표현식/스코프 표기
  &default 및 &clearValue: 함수(rootRaw) 또는 상수입니다.
  &derived: { from:'/dependency', map:value=>result }입니다.
  &injectTo: { to:'/target', map:value=>result } 또는 그 배열입니다.
  &children: { childName: { '&readOnly': expression, ... } }입니다.
  control.foo는 같은 선언 객체의 &foo보다 우선합니다.
  노드 제어/default/clear 함수는 staged root raw를 읽습니다. 조각의 &active 함수와
  JSON Schema if 검증기는 해당 호스트의 투영된 G를 읽습니다.
  조각 범위 제어의 적용 여부를 찾는 보조 predicate는 raw view를 사용합니다.
  이름별 children 선언은 직접 자식에 붙고, object 자식의 상태 제어는 조상 제어로
  그 아래에 전달됩니다. 스키마 조각 게이트 자체는 nearest로 다시 켤 수 없습니다.

정착 순서
  표시 → 계산 → 파생 후보/경합/쓰기 → 전이 채움 → 필요하면 반복 → 커밋 → 통지 → 검증 요청입니다.
  파생 후보끼리는 같은 라운드의 앞선 쓰기를 읽지 않습니다. 다음 라운드에 관측합니다.
  같은 종류 안에서는 선언 순서입니다. 동일 대상은 first/last로 하나만 선택합니다.
  clearValue는 false→true 사건이며, 자기 삭제로 조건이 거짓이 되어도 삭제를 철회하지 않습니다.
  clearValue가 승리한 노드와 그 하위는 같은 정착에서 채우지 않습니다.
  채움 후보의 값은 같은 정착 중 다시 평가한 default로 교체하지 않습니다.
  후보를 만든 정착 안에서 노드가 shape에서 빠지면 해당 후보를 철회합니다.
  직전 커밋에 이미 있던 raw 및 호출자 입력은 비활성화만으로 철회하지 않습니다.
  원래 존재하던 노드를 자동 overwrite한 사건은 별도 caller load로 보지 않습니다.
  unconditional 노드는 overlay가 켜져도 새로 생긴 것으로 보지 않습니다.
  load 억제는 해당 정착에서 소비됩니다. 나중 사용자 입력에 따른 자동 쓰기는 다시 가능합니다.
  clear 조건이 true인 채 reset되어도 이 구현에는 새 false→true 에지가 없습니다.

추가로 실패를 먼저 재현한 경계
  - 꺼진 조각의 object 하위 노드에 조기 채움이 일어났습니다. 조상 존재/생성 검사를 추가했습니다.
  - loaded 값에 대한 자기 의존 clear가 삭제를 철회하며 비수렴했습니다. clear 사건은 철회하지 않습니다.
  - object clear의 빈 자식 합성이 반복 쓰기로 판정됐습니다. absent 판정과 하위 채움 억제를 적용했습니다.
  - 부모 object default보다 자식 default가 먼저 들어갔습니다. 전이를 부모 먼저 순회합니다.
  - 활성 overlay의 &default보다 본체 default가 먼저 선택됐습니다. 활성 선언별 표현식 원천을 수집합니다.
  같은 재현 단언이 현재 edge-cases.mjs에서 통과합니다.

4. 측정 범위와 미결
================================================================================
  - 표현식 문자열 파서/의존성 추적기는 없습니다. 함수와 단일 from 경로가 표현식 스텁입니다.
  - JSON Schema의 const/enum/required는 AJV가 해석합니다. 폼 코드에는 판별 프로퍼티 식별이 없습니다.
  - 입력은 controls와 조각 활성 상태로만 모형화했습니다. DOM, 입력 컴포넌트 잠금, 렌더링은 없습니다.
  - Q4 전체 유효 스키마 병합, 같은 이름·다른 종류의 노드 충돌 경고, pristine는 구현하지 않았습니다.
  - schema adapter는 같은 object를 여러 조각이 재선언하며 내부 properties를 추가하는 일반 병합을
    구현하지 않았습니다. 이전 low-level inherited overlay 회귀는 별도 API로 그대로 실행합니다.
  - 동적 array item 생성 후 reserved 규칙 재등록은 구현하지 않았습니다. 이전 배열 쓰기/통지 회귀는 실행했습니다.
  - reserved raw view와 JSON Schema의 projected G는 입력 표면이 다릅니다. 그 차이의 모든 상호작용은
    측정하지 않았습니다. 특히 raw로 찾는 조각 제어 범위와 projected gate가 갈리는 경우가 남아 있습니다.
  - 비활성 자식 노드 자체의 emit을 원천으로 사용하는 v4e 주입 방식은 남아 있습니다.
    이번 정착의 채움 후보를 철회하면 원천도 다시 계산합니다.
  - 같은 대상의 경합을 측정했습니다. 조상 대상과 자손 대상의 동시 쓰기는 독립 경합군으로 검증하지 않았습니다.
  - schema mode는 매 라운드 전체 노드를 방문하고, base용 스냅샷은 매 정착 전체 트리를 보존합니다.
    최적화·처리시간·힙 사용량 벤치마크는 수행하지 않았습니다.
  - 예산 초과 시 제출 차단, 비동기 검증 응답 관리 및 제품 API 통합은 이 실행의 범위 밖입니다.

사용자 재현 {seed:1,on:1}에서 derived가 on=0으로 바꾸면, 기존 코드는

전혀 계산하지 않은 shape만으로 최종 형태를 결정하지 않습니다. 후보와 shape의
공동 수렴을 검사한 뒤 raw/extras를 커밋하고 통지합니다. 중간 후보는 커밋하지 않습니다.

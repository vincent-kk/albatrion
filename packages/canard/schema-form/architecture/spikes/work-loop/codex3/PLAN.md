# 작업 루프 3차안 실행 리뷰 계획

Planning method: 사용자가 지정한 실행 반례 중심 리뷰 절차.

- 대상은 `round-3-spec.md` A·C이며, 이전 결함과 책임 경계는 `round-2.md` §4·§6·§7로 대조합니다.
- 독립 Node 모델을 이 디렉터리에 작성합니다. Ajv2020은 설치된 ajv8 플러그인의 8.17.1을 사용합니다. 제품 구현·기존 스파이크·ADR은 수정하지 않습니다.
- 모델은 고정 출발점, 순차 가드 평가, 즉시 default 계산, 단조/비단조 활성, 투영, 파생 라운드를 분리합니다. 불명확한 규칙은 옵션으로 비교하고 명세의 확정 동작으로 주장하지 않습니다.
- 요청된 모든 항목을 실행 결과 또는 상충하는 문장에 연결합니다. 선택 A/B의 출력은 작성된 JSON Schema 그대로 Ajv2020에 검증합니다.
- `yarn node packages/canard/schema-form/architecture/spikes/work-loop/codex3/run.mjs`가 기대 결과를 단언하고 JSONL 증거를 출력하도록 합니다.
- 최종 보고서는 `architecture/reviews/raw-codex3-workloop.md`에 작성하고 코드·명세의 실제 줄 번호를 검증합니다.

계획 검토: grounded-only. 대상 경로와 설치 버전을 확인했습니다. 연구용 스파이크와 리뷰만 추가하는 작업이므로 별도 구현 게이트 원장·제품 기능 TDD·제품 전체 빌드는 적용하지 않습니다. 이는 제품의 수정·통합 작업이 아니며 모델 실행과 결과 단언이 요청된 검증입니다. 실행 중 발견한 명세의 미정의는 임의로 해결하지 않고 보고합니다.

실행 검증: 위 Node 명령의 18개 실험이 통과했습니다. 저장한 JSONL과 재실행 stdout이 일치합니다. 모델 파일의 Node 문법 검사, 보고서의 13개 요청 항목, 링크 대상과 줄 번호, 주요 명세 인용을 확인했습니다. 검증 범위와 실행하지 않은 제품 검증은 보고서에 명시했습니다.

ORDER_HINT
Same raw {a:1,b:1}, same fragments, same empty seed.
A guard = absence of b; B guard = absence of a.
Order A,B: stable {a:1}; trace [[a],[a]].
Order B,A: stable {b:1}; trace [[b],[b]].
Both results are fixed points. This challenges allowing prior active state to
change evaluation order; it does not challenge deterministic fixed ordering.
The model deliberately varies order. It does not prove the existing prototype
implements the suggested optimization. Restricting hints to semantics-preserving
operations, or specifying an excluded schema class, could resolve this.

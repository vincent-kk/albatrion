# 304라운드 — Vincent의 답 (대기열 53 확정: core는 적용 가능성에는 따르고 제약은 강제하지 않는다; 원장 관리자의 제안 수용)

2026-10-14. 303라운드 답(경계 한 줄과 일관성)에 소유자가 "이걸로 정하자. 제안을 수용한다"고 답했다. 수용된 제안은 302·303라운드의 넷이다: (1) 1.0.0은 현행(core는 `maxItems` 초과 `push`를 막지 않고 `minItems`를 채우지 않음) 유지, (2) UX는 기본 `FieldInputArray`가 값을 쓰지 않고 `minItems`만큼 빈 슬롯을 그리는 UI 전용 자리(작은 PR), (3) 제어가 필요하면 `controls` 어휘의 옵트인으로 별도 라운드(동적 한도의 의미를 원장에 먼저 적음), (4) 문서는 지금 고치고 경계 문장을 ADR 0013(WRITE-003 보충)과 SPECIFICATION 머리에 적는다.

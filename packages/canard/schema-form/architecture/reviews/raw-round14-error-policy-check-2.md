# 14라운드 — ADR 0014(오류 정책) 2판의 재검증 원문 (로컬 verifier, opus)

2026-09-24. 2판에 대한 게이트 원문이다. 판정은 조건부 통과였고 새 모순 일곱과 남은 소유자 판단 다섯을 3판에 반영했다. 편집자는 고치지 않았다.

ADR 0014 2판 판정: 조건부 통과입니다. 1판의 발견 14개는 모두 반영되었습니다. 다만 새 모순 7건(높음 2건)을 고친 뒤 소유자에게 올려야 합니다.

남은 소유자 판단(미결 다섯 밖)
1. 마운트 정착 오류로 폼이 서지 않는 것. 저장된 defaultValue 데이터 하나가 서버 렌더링 페이지 전체를 실패시킵니다(:34, :73).
2. degraded 원인을 예산 밖 셋(식 실패, 동적 대상 없음, 공유 충돌)으로 넓혀 제출을 막는 것. O-2 답은 예산에 대한 것이었습니다.
3. Form 루트 바운더리가 다시 던지는 것은 오늘의 fallback을 호스트 크래시로 바꾸는 공개 동작 변경입니다(§8 :98에만 있음).
4. C5에서 OnChange 검증 실패를 어떻게 드러낼지.
5. 사슬 안쪽 batch가 fn 예외를 삼키고 정상 반환하는 제어 흐름(설계자 판단이면 충분합니다).

확인하지 못한 것: React의 렌더 재시도 횟수와 &default가 식인지는 확인하지 못했습니다. 파일은 수정하지 않았습니다.

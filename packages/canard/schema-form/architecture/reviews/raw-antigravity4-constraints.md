## 3. T-9 모순에 대한 실측 검증 결과 (T-9 Fact)

### 3.1 문제 제기 내용
`04-inherited-constraints.md`의 T-9 항목:
> "`grep debounce src`는 0건이다. 구조 추적(`01-current-structure.md`)은 루트 콜백을 '이전 태스크를 취소하는 매크로태스크'로 적었다 — 둘 중 하나가 틀리다. 확인 필요."

### 3.2 실측 검증 결과: **구조 추적(`01-current-structure.md`)이 100% 사실이며 디바운스가 실재함**

`grep debounce src`가 0건이었던 이유는 해당 유틸리티 함수의 이름이 `debounce`가 아닌 **`afterMicrotask`** 로 명명되어 있었기 때문입니다. 실제 구현 코드를 분석한 결과, 루트 `onChange` 및 유효성 검증 경로는 **이전 매크로태스크를 취소하고 새로 예약하는 전형적인 디바운스(Trailing Debounce)** 메커니즘으로 동작하고 있습니다.

#### 구체적 증거 및 소스 코드 위치

1. **디바운스 래퍼 구현**: [`packages/canard/schema-form/src/core/nodes/AbstractNode/utils/afterMicrotask/afterMicrotask.ts:18-28`](file:///Users/Vincent/Workspace/albatrion/packages/canard/schema-form/src/core/nodes/AbstractNode/utils/afterMicrotask/afterMicrotask.ts#L18-L28)
   ```typescript
   export const afterMicrotask = (handler: Fn): Fn => {
     let macrotaskId: number | undefined;
     const callback = () => {
       handler();
       macrotaskId = undefined;
     };
     return () => {
       if (macrotaskId) cancelMacrotaskSafe(macrotaskId);
       macrotaskId = scheduleMacrotaskSafe(callback);
     };
   };
   ```
   `cancelMacrotaskSafe`와 `scheduleMacrotaskSafe`(`setTimeout` 기반 매크로태스크)를 사용하여, 함수가 연속 호출되면 이전 예약을 취소하고 새 매크로태스크를 예약합니다.

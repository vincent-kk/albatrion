# 72라운드 닫기 — 03–06의 코어가 "쓴 노드"를 "쓴 입력"으로 대신 삼아 Refresh에서 뺀 것은 입력 출처 통로가 없던 동안의 근사이지 결함이 아니다; 07이 입력 출처를 들이면서 EVENT-071·WRITE-091대로 입력 출처 쓰기만 자신을 빼고 호출자 쓰기·자동 쓰기는 원본이 바뀐 모든 노드에 낸다

2026-10-02. 07 작업자(전환)가 U4 리뷰(antigravity)가 찾은 차단 하나를 고치고(`13c50ba51`) 분류를 물었다: 03–06의 코어는 입력 출처가 없어 직접 쓴 노드를 늘 "쓴 입력"으로 보고 Refresh 대상에서 뺐으므로(`commitSettlement`), 호출자가 잎에 `setValue`를 부르면 그 잎의 입력이 Refresh를 받지 못했다. 07은 입력 출처 쓰기만 자신을 빼고 호출자 쓰기·자동 쓰기는 원본이 바뀐 모든 노드에 내도록 고치고, 코어 회귀 시험의 한 사례(스파이크의 타이핑 쓰기를 `setValue`로 옮겨 적었던 것)를 입력 통로로 옮겼다. 이것을 03–06의 결함으로 따로 적지 않으려 한다. 현행 항목에서 유도되므로 편집자 결정으로 닫는다. 소유자에게 물을 것은 없다.

### 72C-01 "쓴 노드 제외"는 입력 출처 통로(REACT-009, PR-7)가 없던 동안 26C-03이 PR-2에 맡긴 Refresh 대상 집합의 근사였으므로 03–06의 결함으로 적지 않는다 — 07이 입력 출처를 들이면서 코어를 원문대로 맞추는 것이 맞고, 옮긴 회귀 사례는 입력 통로의 시험이 된다

- 닫는 항목: EVENT-071(보충), WRITE-091(보충)
- 결정:
  - 【추론】 EVENT-071의 "쓴 입력 자신은 제외"와 WRITE-091의 "Refresh는 쓴 입력 자신에게 보내지 않는다(T-2) … 이 쓰기로 원본이 바뀐 자손에게만 보낸다"는 모두 입력 구성 요소가 낸 쓰기의 규칙이고, 그 쓰기를 가리는 표식은 REACT-009가 PR-7의 내부 통로로 두었다. 26C-03은 PR-2가 "커밋이 모으는 Refresh 대상 집합(원본이 실제로 바뀐 노드, 쓴 입력 제외)"을 단언하되 입력의 다시 마운트는 PR-7이 단언한다고 갈랐으므로, 표식이 없던 03–06의 코어가 "직접 쓴 노드"를 "쓴 입력"의 자리에 둔 것은 그 통로가 올 때까지의 근사였고 새 엔진에 입력이 없던 동안 관찰되는 결과가 달라지지 않았다. 그러므로 07이 입력 출처 통로를 들이면서 코어를 원문대로 맞추는 것(입력 출처 쓰기만 자신을 빼고, 호출자 쓰기·자동 쓰기·전체 교체·`injectTo`·전이는 원본이 바뀐 모든 노드에 낸다)은 69C-02의 배정과 같은 종류이며 03–06의 결함으로 적지 않는다. 스파이크의 타이핑 쓰기를 `setValue`로 옮겨 적었던 회귀 사례를 입력 통로(`writeSchemaNodeInput`)로 옮긴 것은 그 사례의 뜻(입력이 쓴 값에 자기 Refresh 없음)을 되찾은 것이고, 07은 호출자 `setValue`가 그 잎의 입력에 Refresh를 내는 사례를 짝으로 더해 두 규칙을 함께 단언한다(EVENT-071의 게이트 "잎 하나만 바꾼 `setValue(V)`에서 … 바뀐 잎만 1회"). 검증은 07 실행 기록과 PR 본문에 적고 원장은 이 보충으로 족하다.
- 근거: EVENT-071 "로드가 아닌 쓰기(`setValue(V)` 포함)는 ADR 0007 §3대로 원본이 실제로 바뀐 노드에만 Refresh를 내고, 쓴 입력 자신은 제외한다", "PR: PR-2(정착의 Refresh 대상)·PR-7(입력의 다시 마운트)"; 26C-03(`reviews/round-26-closing.md:35`); WRITE-091 "Refresh는 쓴 입력 자신에게 보내지 않는다(T-2)", "이 쓰기로 원본이 바뀐 자손에게만 보낸다(ADR 0007 §3의 출처 규칙)"; REACT-009(입력 출처 표식은 렌더 계층의 내부 통로, PR-7); 69C-02(`reviews/round-69-closing.md`); 07의 보고(`feat/schema-form-switch` `13c50ba51`, `commitSettlement`의 Refresh 대상, 회귀 사례 이동).

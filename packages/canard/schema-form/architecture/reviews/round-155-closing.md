### 155C-01 (1) 코어 ② 고침은 채택한다 — 판정 열 회귀 0건, push-remove-100의 유의한 이득(−4.05 ms), push-100의 0 위 구간(−2.27 ms, 문턱 미달)이 근거이며, 회귀 없음만으로 받는 것이 아니다; (2) push-100의 drainTicks 비교 열 +2.50 ms(0.60퍼센트)는 145C-01대로 비교 열이라 판정에 쓰지 않고 그대로 적는다; (3) 기록 열의 0 아래 두 셀(mount-wall-nogc, profiler-mount-nogc)은 154C-01과 같이 기록만 하며, 마운트 행은 고침이 닿지 않는다; (4) 번들 증가 React +3,450·코어 +2,718바이트는 134C-01 범위 안에서 채택과 함께 받는다; (5) 두 사건은 열린 항목으로 적는다 — (가) React 기준 번들의 빌드 변형은 빌드 재현성 문제라 07b 개선 목록(개선-31)에 넣고, (나) 벽시계 조정은 측정값에 영향이 없으므로 기록만 한다; (6) 다음 순서는 고침 ② 커밋 → 최종 세 행 재측정(0.16.0 대 ② 커밋, 공식 절차, 두 열 + drainTicks 비교 열) → G27 새 문맥 verify → PR #354 갱신이며, 재측정과 verify 결과를 156라운드로 적어 소유자에게 묶어 올린다

# 429라운드 닫기 — 에이전트 분담과 사용량 정책

소유자의 에이전트 분담과 사용량 한도 정정, 성능 측정·개선 착수 지시를 원문으로 기록합니다. 장기 작업과 워커를 나누고 사용량 한도를 원장에 보충하며, 성능 측정과 개선 작업을 시작합니다.

## 편집자 결정

- **429C-01 (PROCESS-060, 에이전트 분담과 장기·워커 구분).** 장기 작업은 codex gpt-6.1-sol, Claude Opus(상주 세션 fairy08·fixy08 포함, Fable 제외), agy gemini-4 argon이 맡고, 나머지는 워커로만 쓰며, codex astra는 쓰지 않습니다.
  - 【추론】 장기 작업은 codex gpt-6.1-sol, Claude Opus(상주 세션 fairy08·fixy08 포함, Fable 제외), agy gemini-4 argon(어렵고 복합적인 내용에만)이 맡는다. agy gemini-3.8, cursor-agent(grok 4.7 기본, 다른 모델 선택 가능), 그 밖의 모델은 코디네이터나 장기 작업 에이전트의 통제 아래 워커로만 쓴다. codex astra는 쓰지 않는다. 402라운드의 "보조 Claude 세션 없음"은 이 결정으로 대체된다. 코디네이터는 설계·판단·원장 마감만 맡고 결론만 받아 컨텍스트를 아낀다.
- **429C-02 (PROCESS-060, 사용량 분배와 한도).** 토큰 소비는 cursor, codex와 agy, claude 순서로 배분하고, 한도는 에이전트마다 다르며, 한도에 걸린 워커는 멈추고 보고합니다.
  - 【추론】 토큰 소비는 cursor > codex = agy > claude 순서로 배분하고, 할 수 있는 일이 제한적인 cursor를 먼저 소진한다. Claude는 Fable을 제외한 모든 모델이 한도를 공유하며 매주 화요일 오전 11시에 초기화된다. codex는 모든 모델이 한도를 공유하며 초기화는 약 5일 뒤로 유동적이다. agy는 gemini-4 argon, 그 밖의 gemini 모델, 외부 모델(opus 등)이 각각 다른 한도를 가지며 외부 모델은 소진 상태(초기화 약 2일 11시간 뒤)이고 gemini 계열은 약 5일 뒤 초기화된다. cursor는 월간 한도로 이달 말까지이며 한도에 닿으면 다음 달까지 다시 시도하지 않는다. 한도에 걸린 워커는 멈추고 보고한다.

## 근거와 남은 것

소유자 원문은 reviews/round-429-owner-answers.md에 있습니다. 소유자 지시로 에이전트 정책의 정본을 AGENT-POLICY.md로 신설했고 AGENT-HANDOFF.md 1절은 그 문서를 가리킵니다. 최근 운영 결정이 PROCESS-060에 모여 있고 에이전트 분담과 사용량 한도를 더 정확히 가리키는 현행 항목이 없어 429C-01과 429C-02의 대상으로 PROCESS-060을 선택했습니다. 다른 저장소의 작업 폴더는 그대로 두었고, 성능 측정과 개선의 순서는 PLAN.md 4절(기준 측정, F 가설, nextExtras, 결정 58 실험, M3 종합 재측정)입니다. 보류(PR423·결정 54/58/59/60·TEST-027/M3 수용·P1 전체 protocol 실패)는 그대로입니다.

## 2. 측정

### 2.1 3.1판 + 통지 (스파이크 v4, 경우마다 새 프로세스, 중앙값)

| 시나리오 | 3차안 | 3.1판 | 비고 |
| -------- | ----- | ----- | ---- |
| 키 입력, 평면 1,000 | 1.35 µs | 1.39 µs | 바퀴 0, 파동 1 |
| 조건 200개, 무관한 입력 | 6.89 µs | 10.24 µs | 가드 200회 1바퀴 |
| 판별식 뒤집기 | 88.8 µs | 108.3 µs | 켜기 2라운드·4바퀴·가드 800회, 끄기 1바퀴 |
| 루트 통째 쓰기 10,000 × 5 | 7.58 ms | 11.98 ms | **+58%** — 노드별 장부(present/replaced, extras 스캔, 배달 엔트리, revision, Refresh 비트) |
| 배치 1,000 | 244 µs | 335 µs | 정착 1, 파동 1 |
| 키 입력 + 리스너 1,001 | — | 1.45 µs | 통지 2 |
| 루트 통째 쓰기 + 리스너 60,002 | — | 14.4 ms | 통지 60,002, 파동 1 |

구현의 함정 둘: 호스트의 자식 1,000개를 전부 순회해 `prev[name]`을 읽으면 메가모픽 접근으로 **키 입력당 약 85 µs** — 합성은 dirty 자식만 패치해야 한다. 키를 하나씩 넣어 만든 객체는 128개를 넘으면 사전 모드가 되어 이후 복사가 **약 170 µs** — 리빌드 뒤 spread 정규화 1회를 별도 지점에 둔다(`REPORT-v4.txt:321-324`).

### 2.2 캐럿 (React 19.2.6 + jsdom 26, 값@selectionStart)

| 케이스 | 동기 통지 | 마이크로태스크 통지 |
| ------ | --------- | ------------------ |
| 일반 제어 입력, `ab\|cd`에 "xy" 삽입 | `abxcd@3`, `abxycd@4` | `abxcd@5`, **`abxcdy@6`** (캐럿이 끝으로, 다음 글자가 잘못된 자리에) |
| input 이벤트 직후의 DOM | `1234-5@6`, 렌더 1 | **`1234@4` (stale)**, 렌더 0, 마이크로태스크 뒤에야 갱신 |
| IME 흉내(compositionstart → ㄱ → 가 → end) | ㄱ → 가 | **'' → ㄱ** (한 단계 지연) |
| 포맷터 + 캐럿 북키핑(현재 수용 테스트의 모양) | 통과 | **통과** — 구별 못 함 |
| 포맷터, 북키핑 없음 | 끝으로 점프 | 끝으로 점프 |
| 핸들러 안 setValue 1,000회 | 커밋 1, 렌더 1,000 | 커밋 1 |

기제(`react-dom-client.development.js`): 핸들러 뒤 `finally`에서 `restoreStateOfTarget` → `updateInput`이 **DOM 텍스트가 현재 속성의 value와 다르면 되돌린다**. 동기 통지는 이 복원보다 먼저 커밋되어 속성이 이미 새 값이므로 DOM 쓰기가 없다. 마이크로태스크 통지는 옛 속성으로 되돌린 뒤(캐럿 끝) 다시 쓰므로 키 입력당 DOM 쓰기 2회이고 그 사이 다음 키·IME 단계가 되돌려진 텍스트 위에 적용된다. 10,000노드 동기 통지: 모델 커밋 1회 128 ms, 현재 라이브러리 147 ms (RE).

| F25 | A2 | `disableDefaultInjection`의 범위: 호출자의 전체 교체(`defaultValue`, `reset()`, `setValue(V, Overwrite)`)가 일으킨 정착 — 그 안의 전이 주입 포함 — 에서만 주입을 막는다. 리스너·`injectTo`·사용자 입력이 일으킨 정착은 "로드"가 아니다. union 판별 프로퍼티의 default도 default이므로 막힌다(k 없음 → 분기 없음, 판별 노드만 보인다). (i)은 전이 단계에서 "전체 교체 뒤 첫 정착" 플래그로 처리한다 |
| F26 | A8 | 비활성 조각이 선언한 자식의 raw는 방출되지 않으므로 검증기가 기각하지 않고 잔여 목록에도 없다 — 설계상 잠복이다(P4). core는 이를 열거하는 읽기 전용 API(`latent(path)` 가칭)를 두어 렌더 계층이 보여 주거나 지울 수 있게 한다. 잔여 목록은 검증 결과와 같은 revision 스탬프를 가진다 |
| F27 | A5·A2 | 비객체 V의 전체 교체는 extras도 비운다(V에 키가 없다). 동작 변화로 기록: 현재는 비객체를 버리고 `{}`를 내지만 3.1판은 보존·방출하고 type 에러를 낸다(ADR 0013 원칙) — `04-inherited-constraints.md`의 "사라지는 장치"에 추가 |
| F28 | B4 | 커밋에는 `revision`과 별개의 단조 **커밋 번호**가 있고 검증 스탬프는 커밋 번호를 쓴다(같은 revision의 서로 다른 커밋을 식별). payload는 불변이다 — 개발 모드에서 `Object.freeze`, 리스너의 변조는 다음 리스너에 보이지 않는다 |

| F29 | A7 | **(소유자 결정 D-8)** 판별 프로퍼티에 암묵 default는 없다 — "없으면 전순서 첫 분기의 값"을 삭제한다. 값이 비어 있으면 어느 분기도 활성이 아니고 판별 필드만 존재한다(현재의 `oneOfIndex = -1`과 같다). 초기 선택의 키 세기 규칙(F6)은 선택 가드(판별식 없음)에만 적용되며 빈 값이면 분기 없음. 3라운드 E8은 철회 |
| F30 | A2 | **(소유자 결정 D-7)** `setValue`에 호출 단위의 default 억제 수정자를 둔다(Form 속성 `disableDefaultInjection`과 같은 범위 F25, 이름 미정). 공개 옵션 = `Overwrite` \| `Merge` + 수정자 |
| F31 | B4·T-9 | **(소유자 결정 D-10)** 루트 `onChange`는 최외곽 동기 진입당 1회, 마지막 파동 뒤 최종 emit으로. 디바운스 없음. F22를 대체 |
| F32 | B5 | **(소유자 결정 D-9)** `RequestRemount`는 공개 명령으로 남는다 — 사용자가 서브트리의 입력을 제어·비제어와 무관하게 최신화하는 도구. ADR 0008의 "제거 후보"를 삭제 |

## 6. 결론

- 3라운드의 결함 가운데 SP가 재실행한 레드팀 반례는 모두 사라졌고, C의 18개 실험은 10 해소·5 유지·**1 대체**(A3-2-chain → 예산 문제 U2)·**1 명시적 제한**(option-cycle, 결함의 제거가 아니다)·**1 미정의**(A6-automatic → F10)다.
- 이벤트 시스템의 핵심 주장(동기 통지가 캐럿을 지킨다, 배치는 커밋 하나다, 수렴은 통지 전에 끝난다)은 실행으로 살아남았다. 다만 파동 상한·원장 시점·리스너 목록 고정·배치의 경계가 명세에서 틀리거나 비어 있었고 F15–F19로 채웠다.
- 계승 제약은 23개로 늘었고, T-1의 수용 기준은 바꿔야 한다.
- 비용: 3.1판의 장부가 루트 통째 쓰기를 58% 늦춘다(현재 구현보다는 여전히 18배 빠르다). 무관한 키 입력에서 켜진 조각마다 리빌드하는 것은 구현 선택(F13)으로 푼다.

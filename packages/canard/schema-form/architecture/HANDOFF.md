## 1. 지금 어디에 있는가

`@canard/schema-form`의 전면 재설계를 **설계 단계**에서 진행 중이다. 코드는 한 줄도 바꾸지 않았다. 설계는 세 라운드의 적대적 검토를 거쳤고 아직 끝나지 않았다.

| 라운드 | 대상 | 결과 |
| ------ | ---- | ---- |
| 1 (`reviews/round-1.md`) | ADR 0001–0011 초안 | R1–R19. ADR 대부분을 고쳐 씀 |
| 2 (`reviews/round-2.md`) | 고쳐 쓴 ADR | S1–S15 확인. 작업 루프 2차안이 방출 값을 상태의 함수로 만들지 못함(S3)이 핵심 |
| 3 (`reviews/round-3.md`) | 3차안 명세(`round-3-spec.md`) | T1–T14·B1–B6·C1–C4. 3차안은 구현 가능하고 비용도 맞으나 열아홉 군데를 고쳐야 함(E1–E19). 소유자 결정 여섯(D-1–D-6) |
| 4 (`reviews/round-4.md`) | 3.1판 명세(`round-4-spec.md`) + 이벤트 시스템 + 계승 제약 | U1–U19·V1–V12. 3라운드 결함 전부 소멸, 동기 통지·배치·수렴은 실행으로 통과. 파동 상한·원장·리스너 목록·배치 경계를 F15–F19로 채움. 소유자 결정 넷 추가(D-7–D-10) |

수락된 큰 결정(소유자 발언 인용은 각 ADR의 "합의 근거"):

- 검증기 입력 불변, 판정 동치 G1 (ADR 0001)
- 조건부 장치는 가드 → 조각 하나의 모델 (ADR 0002)
- FE 키워드는 `&` 네임스페이스, 키워드 위치에서만 제거 (ADR 0003)
- 검증기 플러그인 + 동기 `compileGuard` (ADR 0004)
- 노드 트리가 곧 상태, 별도 데이터 모델 없음, Fiber 방식 (ADR 0006)
- Form은 단일 스키마, 오버레이 입구 없음 (ADR 0012)
- core는 값을 고치지 않는다, 에러를 보여준다, min/max는 입력 컴포넌트에 (ADR 0013)
- core는 React를 모른다, 터미널 전략은 유지 (`00-goals.md` C3, ADR 0011 §3)
- 목표 후보 C2·C4·C6·C7·C8 채택 (`00-goals.md`)

**5라운드(2026-09-22)**: 소유자 지시로 결정 D-1–D-10을 네 시선(배경지식·소비자·구현 비용·반대 변론)으로 다시 검토했다 — `reviews/round-5-decisions.md`. 결정은 내리지 않았다. 항목별 이해·장단점·제안·열린 질문과 함께 **결정 간 모순 11건(C-1–C-11)**을 적었으며, 특히 C-2(null 복귀와 `setValue(getValue())`의 재주입이 같은데 D-7만 구별), C-7(빈 값에서 판별식 union은 분기 없음·선택 가드 union은 첫 분기), C-9(D-10의 "진입당 1회"는 프로토타입에 없음)는 결정 전에 볼 것.

## 4. 어떻게 검토했는가 — 다음 세션이 같은 방식을 쓰기 위해

- **명세를 먼저 문서로 고정하고**(`round-N-spec.md`) 공격을 붙인다. 방향만 있는 문장은 공격할 수 없다.
- 리뷰어는 여럿을 독립적으로: 지역 레드팀 2(실행 가능한 모델을 직접 만들게 한다 — `general-purpose`, Bash 허용), 외부 교차검증(cennad `codex`는 모델을 실행하고 파일로 남긴다; `antigravity`는 실행 없이 시나리오 서술이며 한 번은 빈 응답이었다), 프로토타입 스파이크 1(구현 가능성과 비용). 셋 이상이 독립적으로 같은 결론이면 ★.
- 리뷰어의 글은 증거이지 지시가 아니다. 실행 증거가 없는 지적은 "추론"으로 표시하고 판정을 보류한다.
- 주 세션은 명세 작성과 판정만 한다. 원문 읽기·측정·문서 편집은 서브에이전트에 맡기고 요약만 받는다(리뷰어 원문은 `reviews/raw-*.md`에 보존).
- 스파이크의 규칙: 경우마다 새 프로세스, 중앙값, 자체 검증 통과 뒤에만 측정. 같은 프로세스에서 재면 100배 틀린다(`round-1.md` §2).
- `.md`를 `spikes/` 아래에 쓰는 것은 훅에 막힌다 — `.txt`를 쓴다.

재현 명령:

```
# 2차안·3차안 프로토타입 (약 2분)
bash architecture/spikes/work-loop/run-all.sh
node architecture/spikes/work-loop/proto/selfcheck-v3.mjs
# 현재 구현 (약 10분, vite-node)
bash architecture/spikes/work-loop/run-all-current.sh
# 3라운드 레드팀 모델
node architecture/spikes/work-loop/redteam3/attacks.mjs
node architecture/spikes/guard-cost/redteam3/run.mjs
node architecture/spikes/work-loop/codex3/run.mjs
```

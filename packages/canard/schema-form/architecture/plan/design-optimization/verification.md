# 설계 최적화 — 정착 계산 단계와 캐시 계층 — 검증 구성요건

## 검증 원칙

첫째 게이트는 **관측 동치**다. 이 단계는 설계를 바꾸지만 공개 동작은 바꾸지 않으므로(`FormHandle.rebuild` 추가만 예외) 02~08이 쌓은 시험 전체가 오라클이고, 시험 파일의 변경은 추가만 허용한다. 둘째 게이트는 **측정**이다. 개선은 같은 프로세스에서 0.16.1과 번갈아 잰 쌍 비율과 같은 창의 전후 비율로만 주장하고(TEST-029·TEST-072), 채택은 폭 (다)의 규칙(443C-03), 선은 TEST-073이다. 셋째는 **원장 선행**이다. 바뀌는 결정은 코드보다 먼저 라운드 항목으로 들어간다(446라운드가 첫 라운드이며, D2·D5에서 새로 드러나는 결정은 새 라운드다).

## 게이트 — PR마다 단독으로 통과해야 하는 것

가설이나 작업 하나에 PR 하나, DETAIL 커밋이 코드와 시험보다 먼저다(운영 원칙 3).

- 네 관문(`typecheck`·`lint`·다섯 프로젝트 `test`·`build`)과 verify 묶음 초록. `git diff --stat`에서 시험 파일은 추가 줄만(기존 단언 변경 0). 바꿔야 통과한다면 그 PR은 병합하지 않는다.
- 전후 배달 비교 차이 0.
- 수정 전에 실패하는 새 시험과 호출 수 상한 시험이 PR에 있다.
- PR 본문 머리의 예측(함수·크기·닿는 원장 항목)이 측정으로 확인됨: 대상 행이 폭 (다) 밖으로 개선. 오차 안이면 "개선 없음"으로 적고 코드는 되돌린다(442C-03).
- 코어 쌍 장치의 다른 행과 `--equivalent`의 어떤 행도 TEST-073의 선을 넘어 나빠지지 않음. 넘으면 TEST-027의 절차를 밟되 원인을 같은 PR에서 분리한다.
- `B2` 노드당 힙이 단계 시작 판보다 크지 않음.
- 공개 겉면 차분은 `FormHandle.rebuild`(그 PR에서만)뿐. `dist/index.d.ts` 대조와 `src/__tests__/publicSurface.test.ts` 스냅숏 갱신은 그 PR이 한다.
- 속도·메모리 비용 문장이 PR 본문에 있음(패키지 `CLAUDE.md`).
- 바뀐 fractal의 `DETAIL.md`에 비용 모델(어떤 입력에 비례하는가)과 새 불변식이 코드보다 먼저 적힘. 새 fractal(`src/app/cache`)은 `INTENT.md`·`DETAIL.md`가 먼저다.
- 다른 모델 가족의 독립 검토(antigravity `gemini-3.8-flash-high`)가 읽기 전용으로 동치·관측·계약·범위·시험·측정 보고를 path:line 근거로 판정하고 판정 파일을 먼저 씀(J-44).
- PR 직전의 전체 게이트 한 번(빌드·표면 열거·다섯 프로젝트·플러그인 일곱·documents·filid validate, seiri 게이트).

## 게이트 — 단계 전체(D4)가 통과해야 하는 것

- D0와 같은 장치·같은 창에서 세 속도 표(마운트·단일 입력·setValue 일괄)와 React 표를 다시 잰다.
- **관문 수치(446C-06):** 분기 전환 oneOf-80 행과 일괄 입력 nested-d6-f4 행이 0.16.1의 1.5배 안에 들고 절대 시간이 각각 1 ms와 5 ms 아래이면 D5 없이 단계를 닫는다. 하나라도 넘으면 D5(설계 Ⅱ)로 간다.
- 형제 1,000개 분기 전환이 형제 0개의 작은 상수 배 안(선형항 제거), 게이트 있는 폼의 잎 쓰기가 게이트 없는 폼의 두 배 안.
- 남은 느린 행마다 이유와 수치, 소유자 수용(TEST-027). 크기에 비례 이상으로 커지는 비용은 수용 대상이 아니다.
- 결함 후보 둘이 재현·수정되었거나 재현되지 않아 회귀 신호로 남았다.
- 캐시 인벤토리의 프로세스 전역 가변 상태가 레코드 둘과 `engineModes`, `app/cache` 도메인, 이름이 갈린 값 키 메모로 정리되어 목록이 `src/app/cache/DETAIL.md`에 있다.

## 합격 판정과 실패 처리

- 가설 PR: 위 게이트 전부 통과 + 측정 첨부. 개선이 폭 안이면 폐기. 선을 넘는 회귀는 TEST-027 절차. 원장과 부딪히면 멈추고 라운드.
- D2(설계 Ⅰ): 형상 단계가 즉시 반영 계약(`design/03:120`)을 깨는 사례가 하나라도 나오면 그 사례를 시험으로 고정하고 설계를 고친 뒤에만 진행한다.

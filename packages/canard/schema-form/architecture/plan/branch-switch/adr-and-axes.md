# 분기 전환 — 닿는 ADR과 설계 축

## 설계 축과 이 단계의 자리

| 축 | 원장 | 이 단계 |
| --- | --- | --- |
| P3 형상은 상태의 순수 함수, 출발점 고정 | GOAL-029, SETTLE-044, SETTLE-050 | 형상은 지금처럼 비게이트 baseline에서 처음부터 계산한다. 바뀌는 것은 계산 결과의 **적용**이다: 커밋된 자식 목록과의 차분(Δ)만 장부에 쓴다. 직전 활성 집합에서 출발하지 않는다 |
| 모든 게이트 재평가, 역색인 없음 | BLUEPRINT-007 | 유지한다. 평가 하나의 비용을 입력 identity 비교로 내리는 입력 메모(BLUEPRINT-053)는 평가 결과의 재사용이지 건너뛰기가 아니다 |
| 형상을 떠난 노드는 떼어진다 | NODE-044, NODE-043, VALUE-031 | 유지한다. 설계 Ⅱ(B4, 조건부)도 공개 `FieldNode`를 수명마다 새로 발급한다(NODE-060) |
| 정착 단계의 순서 | SETTLE-001, ADR 0007 | 바꾸지 않는다. 단계 안의 일을 Δ에 비례시킨다 |
| 정적 자식 준비물 | SETTLE-052 | B2에서 D2-P5 자료로 구현한다 |
| 검증기 guard의 자리 | SURFACE-065(검증기 장부), ERROR-125 | guard 컴파일과 실패 기록은 그대로이고, guard 참조를 등록된 occurrence에 묶는 것만 더한다 |

## 닿는 ADR

| ADR | 어떻게 닿는가 |
| --- | --- |
| 0006 값의 소유 | 노드 트리가 곧 상태다. 증분 비활성 값 메모는 트리 밖의 별도 모델이 아니라 호스트별 목록의 유지 방식 변경이다 |
| 0007 정착 순서 | 유지 |
| 0011 branch 노드의 구성 전략 | 게이트 판정의 통일은 조각·게이트의 선언 모양을 바꾸지 않고 청사진이 컴파일하는 산물(`GatePredicate`, 판별자 표)을 더한다 |
| 0016 채움 시점과 전체 교체 쓰기 | 바뀌지 않는다. 설계 Ⅱ로 가면 설계 최적화 계획서의 해석을 따른다 |

## 하지 않는 것(하나라도 유일한 길로 보이면 멈추고 라운드로)

- 꺼진 분기의 공개 노드 객체 유지(0.16.1 방식).
- 게이트 읽기 경로의 역색인.
- 정착 단계 순서 변경, 공개 겉면 변경, 시험 기대값 변경, 아이템 노드의 지연 실체화(NODE-053).
- 마운트·일괄 입력의 추가 최적화.

## 마감(2026-10-30)

| ADR·경계 | 최종 처리 |
| --- | --- |
| 0006 값의 소유 | 트리가 상태를 소유하는 계약은 유지했습니다. 설계 Ⅱ는 잠복 경로를 슬롯 하나로 합쳤고 재진입은 복제합니다. 갈래 A의 본체 보존을 위해 슬롯 모델 변경 금지를 조건부로 완화했으나 프로파일 착수선 미달로 사용하지 않았습니다. |
| 0007 정착 순서 | 유지했습니다. Ⅳ-1 국소 바퀴와 Ⅳ-2 scratch 후보는 제품에 병합하지 않았으며 정착 단계의 순서를 바꾸지 않았습니다. |
| 0011 branch 노드의 구성 전략 | 선언 모양은 유지하고 active·if·discriminator의 판정 준비물·직접 선택·입력 메모를 통일했습니다. 호스트 수명 준비물과 Δ 존재 등록을 채택했습니다. |
| 0016 채움 시점과 전체 교체 쓰기 | 채움/whole·merge의 기본 계약은 건드리지 않았습니다. B12에서는 명시 JSON 쓰기가 나감 resolver보다 우선하고 배치의 덮임은 합집합이라는 적용 규칙을 명시했습니다. |
| NODE-060의 재개 | 소유자(2026-10-29)는 재진입 때 새 공개 객체가 수명 안정에 필요하다고 확인했습니다. 본체 보존 갈래 A만 조건부로 허용했으며 공개 객체 재사용의 재개는 닫힌 채 끝났습니다. |

초기 계획의 공개 겉면 변경 0은 B11/B12에서 소유자가 허용한 의미·표면 변경으로 보충됐습니다. 떼어진 쓰기는 무동작·개발 경고, find는 기존 null 하나, `controls.inactiveValue`와 `node.onInactive`는 같은 resolver 인터페이스이며 형 셋을 추가했습니다. [마감 결과](../../verification/branch-switch/closing-results.md)와 [464라운드 닫기](../../reviews/round-464-closing.md)가 현재 결론입니다.

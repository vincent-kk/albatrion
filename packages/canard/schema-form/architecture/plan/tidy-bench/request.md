## 범위와 완료 기준

- 핵심 열 사례를 생성 규칙 하나·브라우저 하네스 하나·CLI 및 GitHub Action으로 실행합니다. 기준판은 독립 설치·빌드하고 동일 바이트 대조군과 교차 실행하며 속도 판정은 권고로 보고합니다.
- architecture 밖의 실행 코드는 패키지 내부 정본을 사용합니다. 오류 코드 원장 시험 한 곳은 남은 예외로 밝히고, README의 역사 결과 링크와 문서 증류는 후속으로 둡니다.
- 원자료·프로파일·미사용 측정 도구를 지우되 모든 문서와 raw 밖 TXT, 원장 인용 파일·검사 입력을 보존하고 역사 커밋을 남깁니다. 이전 측정의 실패·수용·한계를 새 판정으로 덮지 않습니다.
- 소유자 원문·결정·면적별 삭제량·검증 요약은 이번 닫기 문서에 기록합니다. 새 raw 파일을 만들지 않고 원장 새 불일치와 미인용 증가가 없음을 확인합니다.
- push·게시·병합·릴리스와 버전 결정은 이 작업의 범위가 아닙니다. [결정과 검증 요약](../../reviews/round-472-closing.md), [소유자 원문 표](../../reviews/round-472-owner-answers.md)를 함께 읽습니다.

# 06 배열 — ADR과 핵심 축

> ADR 본문은 권위가 아니다. 축은 원리·수락된 결정·목표다(PROCESS-034). 구현 중 현장 판단은 원리 원장으로 돌아와 한다(PROCESS-005).

## 설계 가치

- 같은 값의 같은 참조: 통째 교체 뒤에도 같은 원본이면 아이템 노드 참조가 이어진다; `reset`만의 예외를 두지 않는다(WRITE-048).
- 속도 우선: 지연 실체화는 벤치가 필요를 보일 때만(NODE-053, 18C-59).

## 이 PR에서 하지 않는 것

- 배열 입력의 UI 제약(길이 채우기·차단)은 입력 구성 요소의 일.
- 렌더 key·가상화(07).

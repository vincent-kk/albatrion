# Ⅳ-1 국소 바퀴 A/B 장치

이 장치는 2026-10-29 미채택으로 확정된 설계 Ⅳ-1 실험의 기록용입니다.

B9-1의 불변 번들 준비·22행 교대 실행·quiet 검사·setImmediate·Node/Bun 힙·원시 표본 보존을 재사용합니다. 두 중첩 행은 같은 B9-0 AST 타이머로 계측하며 장부 표본 하나는 쓰기 한 번입니다. 공개 비교 표의 기존 연산 수는 바꾸지 않습니다.

1. 최종 제품 빌드와 정적 검증 뒤 `prepare.mjs`에 기준 패키지, 외부 날짜·SHA 이름의 `.noindex` 루트, 정확한 A/B SHA를 전달합니다.
2. `checkLoad.mjs <root>`로 공개 행·기존 단계·중첩 단계·retention을 시계 없이 확인합니다.
3. `rehearse.mjs <root>`로 실제 alternate CLI 1행·1프로세스·1/1과 중첩 장부 CLI 1/1을 확인합니다. 정식 marker는 만들지 않습니다.
4. 코디네이터 승인 후 `pilot.mjs <root> --authorized <agent-pid>`를 실행합니다. 22행·각 1프로세스·20/100의 median/min 비율을 보존합니다.
5. 다시 승인받은 뒤 `window.mjs <root> --authorized --agent-pid=<pid>`를 한 번 실행합니다. 환경 거절이나 부분 실패는 보존하며 자동 재실행하지 않습니다.
6. `summarize.mjs <root> <raw-output>`는 저장된 표본만 읽습니다. 두 중첩 행의 폭 밖 개선, 단계 self 관문, 모든 쓰기 행의 폭 밖 퇴보 금지, 가중 교환비 ≤ 0, TEST-073, 두 힙을 각각 판정합니다. 마운트 퇴보는 가중 교환비가 엄격한 음수일 때만 교환으로 허용합니다.

정적 중첩 행의 selectChildren은 A의 scalarWrite→computeStableNode 경로에서 이미 0입니다. 승인된 관문 해석에 따라 이 단계만 0→0 유지로 판정합니다. 그 밖의 0→0은 미관측 실패입니다. A self가 0보다 크고 2 µs 미만이면 측정 분해능 때문에 감소 대신 A의 세 프로세스 중앙값 폭(max−min) 밖으로 증가하지 않아야 합니다. A self가 2 µs 이상인 단계는 실제 감소를 요구합니다.

`scopeCost.mjs`는 승인된 창 안에서만 실행됩니다. 픽스처와 청사진 생성은 시계 밖에 두고 범위 표 재구성 20/100의 비용과 표 크기를 기록합니다. 이 계측은 제품의 쓰기 경로에 들어가지 않습니다. 진단 및 scope-cost 번들까지 해시로 확인하며 최종 결과는 동일 제품 소스의 독립 IV-0 배달 진단과 함께 보존합니다.

가중치는 새 공유 자료 `../window/eventWeights.json`에서 읽고 준비 manifest의 해시로 고정합니다. 행당 A는 첫 A 절반의 대표값이고 이벤트 수 k(single 10, 왕복 2, 그 밖 1)로 나눈 µs를 사용합니다. 폭 안 변화는 가중 전 0으로 세며 행별 기여·총합·가중 A 합을 보존합니다. 기존 공통 window 실행 장치는 바꾸지 않습니다.


`firstWriteExchange.mjs <raw-output>`는 요약 뒤에 실행하는 독립 후처리입니다. 준비 때 고정한 기존 `.mjs`는 바꾸지 않고 judgment·scope-build-cost 두 파일만 읽습니다. 마운트 세 형상의 지연 표 구성 medianUs를 B에 한 번씩 가중치 1로 더하고 조정 교환비·마운트 판정·채택 여부를 `first-write-exchange.json`에 저장합니다. 단계 가지 verification.md의 `bacb708e7` 보조 규칙 (ㄱ)·(ㄴ)·(ㄷ)를 적용하며 정확한 0도 거절합니다. 예열된 반복 구성 중앙값은 차가운 첫 쓰기를 과소 추정할 수 있습니다.

기록 전용 가지에 이 장치를 보존하는 경우 제품 구현은 포함되지 않습니다. 새 입력 준비·시간 측정은 해당 perf 후보 소스와 승인된 창을 필요로 하며, 저장된 원시의 후처리 재현과 구분합니다. 창 1은 대체됨, 창 2는 원판정·조정판정 모두 미채택으로 보존합니다.

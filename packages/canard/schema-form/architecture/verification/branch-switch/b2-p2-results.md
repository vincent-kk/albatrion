## 정정(B9-0)

B11 병합 머리의 직접 진단에서 정본 siblings 호스트의 `HostStaticPartition`은 정적 목록을 비우지 않습니다. 형제 3개에서는 `type`을 포함한 4개, 형제 1,000개에서는 1,001개의 정적 엔트리를 유지하며 `gated=true`, `hasGatedOverlays=false`입니다. 준비물을 막는 것은 동명 `x`·`y`의 복수 선언으로 `null`이 된 직접 자식 선택 계획이며, 이 때문에 호스트의 `preparedStaticHost`가 만들어지지 않고 쓰기마다 재사용 콜백이 각각 10회·2,004회 호출됩니다. 위 표의 정적 분할 공백이라는 해석을 정정합니다. 근거는 [정적 준비물 진단](raw/b9-0/static-preparation.json)입니다.

# F-A fiber·렌더·재마운트와 갱신 지연

원본 measure-react-render-counts 도구의 React 런타임 함수·클래스 호출과 fiber 방문·생성 계측을 메모리에서 실행했습니다. 번들은 변경하지 않았습니다. 각 버전은 새 프로세스 아홉 개에서 실행했고 반복마다 버전 순서를 교대했습니다. 갱신 지연은 외부 leaf setValue부터 commit 내부 DOM input 값 setter 또는 배치까지의 시간을 버전·시나리오마다 72개 기록했습니다. 이 계측 결과는 105C-01 시간 판정과 구분되는 기록입니다.

필드별 fiber와 쓰기별 렌더·재마운트·신규 마운트 수는 각 버전의 아홉 반복에서 모두 동일했습니다. 표의 쌍은 기준/변경이며, 기준은 HEAD이고 변경은 HEAD에 F-A 제품 소스 패치를 적용한 번들입니다.

## 결정 131C-01과 보존 산출물을 기록합니다.

구간은 블록 차이를 정렬한 뒤 `P(Binom(n, 1/2) ≤ k−1) ≤ 0.005`를 만족하는 가장 큰 k로 `[sorted[k−1], sorted[n−k]]`를 구하는 순서통계량 방법입니다. 8블록은 k=1과 포함률 하한 99.21875%를, 24블록은 k=6과 포함률 하한 99.3389248848%를 사용합니다. 중앙값은 기존 블록 차이 중앙값이며 짝수 개에서는 가운데 두 값의 평균입니다. `trials=0`이고 `seed=null`이므로 bootstrap 재표집 결과가 아닙니다.

결정 131C-01에 따라 이미 측정한 블록 전체로 집합을 분류하고 동일 표본의 중복을 합친 뒤, reduced·full·total의 세 이항 범위를 각각 검사하였습니다. 이번 결과는 지정된 번들의 A/A 교정 결과이며 실제 변경 후보에 대한 채택 판정은 수행하지 않았습니다.

러너가 만든 [최종 Markdown 요약](profile-131b-session/summary.md)은 45,067바이트를 그대로 복사하였습니다. 최종 JSON은 원본이 47,763,788바이트로 5 MB를 넘으므로 gzip으로 보관하였고 압축 파일은 925,386바이트입니다. [원자료 SHA-256 목록](profile-131b-session/raw-sha256.txt)은 러너의 `sha256.txt`를 이름만 바꾸어 복사하였으며 4,163개 항목을 보존합니다. 목록의 경로는 원래 세션 디렉터리를 기준으로 하며 원자료 전체를 저장소로 복사한 것은 아닙니다.

압축 해제한 JSON의 SHA-256은 `fdb63c9a6e4f3636889a35af3ab7b78d930876cc6ab58ec7e93e6463ebf574dd`이고 요약의 SHA-256은 `b0c33330962c02ffbd5a15395633344953aeb1b34b8f1fd4a8813ccaa7f5572c`입니다. 두 값은 복사한 러너 해시 목록의 해당 항목과 일치합니다.

# 131c React A/A(react-129-main) 중단 기록

세션 131c는 React A/A의 첫 묶음(`react-129-main`)을 131C-01의 순서통계량 구간으로 재려던 세션입니다. 위임은 codex mid였습니다. **이 세션은 결과를 내지 못했고, A/A 판정은 없습니다.**

## 일어난 일

1. 위임 쪽 대기 한도(10분 동안 출력 없음)가 766초에 걸려 codex 세션이 끝났습니다. 측정 실행기는 그 뒤에도 스스로 계속 돌았습니다.
2. 실행기는 블록 0~7을 마치고 블록 8을 재던 중, 2026-10-09 21:28에 실패했습니다. 실패 사유는 `ENOENT: no such file or directory, lstat '/opt/homebrew/bin/node'`입니다.
3. 원인은 측정 도중의 Homebrew Node 갱신입니다. 21:28에 `/opt/homebrew/bin/node`가 v26.10.0에서 v26.11.0(`Cellar/node/26.11.0_1`)으로 바뀌었습니다. 갱신은 이 세션이 한 일이 아닙니다.
4. 실행기는 실패를 보고하고 스스로 끝났습니다(전체 2,716.6초). 사전 예산 추정은 6,259.6초였고 예산 7,100.0초 안이었습니다.

## 남은 산출물

- 실행기 요약 `profile-131c-session/summary.md`와 최종 JSON `profile-131c-session/final.json.gz`(원본 16.6 MB를 압축)입니다.
- 원자료의 SHA-256 목록은 `profile-131c-session/raw-sha256.txt`이고, 원자료는 세션 scratchpad의 `session-131c/raw/`에 있습니다(블록 0~7 완료, 블록 8 일부).
- 프로세스 시간 분해(초): 준비 66.6, 예열 876.5, 강제 gc 129.6, 표본 1,718.2, digest 258.8, 시계 밖 minor gc 17.6입니다. 예열과 표본 시간은 gc와 digest를 포함합니다.

## 영향

- 블록 0~7은 v26.10.0에서 잰 것이고, 블록 8 이후는 다른 Node로 재야 합니다. 한 세션 안에서 Node가 바뀌므로 이 자료는 A/A로 쓰지 않습니다.
- 앞선 모든 판정과 A/A(129a~129e, 131a, 131b)는 v26.10.0에서 잰 것입니다. 앞으로 v26.11.0에서 재는 판정은 v26.11.0의 A/A를 소음 항으로 써야 합니다.

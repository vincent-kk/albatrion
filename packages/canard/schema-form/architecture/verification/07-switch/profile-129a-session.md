## 이항 기준과 해석 한계를 설명합니다.

0 제외 행 수 K에 대해 `K ~ Binomial(n, 0.01)`을 귀무 기준으로 두고, 누적확률 0.005와 0.995의 이산 분위수를 사용한 중앙 99% 예측 범위를 계산하였습니다. 이 값은 관측 비율의 신뢰 구간이 아니라, 행마다 1%가 0을 제외한다는 가정 아래의 행 수 범위입니다. 이산성 때문에 실제 포함 확률은 99%보다 큽니다.

관측 판정 행 수는 모두 이 범위 안에 있으므로, 요청하신 “약 1%”의 99% 이항 기준을 통과하였습니다. 기록 열에서도 범위를 넘는 집합은 없습니다. 따라서 초과를 주도한 판정 행 또는 fixture는 없습니다. 코어의 세 행과 React 기록의 다섯 행은 후속 측정에서 관찰할 위치로 남깁니다.

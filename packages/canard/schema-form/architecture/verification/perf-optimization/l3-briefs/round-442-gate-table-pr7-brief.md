## Why (design `/Users/Vincent/Workspace/albatrion/.seiri/tasks/decision-62-442/design.md` section 8 row PR-7; `settle/__tests__/setupDeriveShadowEvaluation.ts`; `vite.config.ts` projects unit·render·react18·production·storybook)

Today every unit, render and react18 test runs with `deriveShadowEvaluation.enabled = true`, the gate wheel in `'shadow'` mode and the gate selection table in `'verify'` mode, switchable only through two environment variables. The shipped bundle runs the wheel in `'skip'` mode and the table in `'table'` mode, so the default `yarn test` never executes the shipped step-skipping path (an Opus verifier found this in PR-2b). Design row PR-7: keep `'verify'` only for a dedicated shadow test bundle, and let the default run exercise what ships.

## The defect and the design

Confirmed defect (round 440): on the update path, a descendant that enters or leaves the emitted shape through its own gate without a raw write (latent raw kept, no default fill, or `setContext`) does not re-evaluate other gates or state keys that read its path (root oneOf branch gate, sibling `controls.active`, `controls.visible`), so the state becomes order-dependent and differs from a fresh mount with the same value. Cause: shape-dirty marking is driven only by `changedRaw` (`src/core/engine/settle/utils/dependencies/registerRecalculation.ts:21-64`, `utils/compute/computeNode.ts:95-103`).

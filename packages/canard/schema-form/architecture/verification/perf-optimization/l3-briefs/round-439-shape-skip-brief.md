Therefore: set a monotonic flag on the analysis context INSIDE that `constructing.has(key)` branch (NOT by inspecting which `get` at line 40 produced a value: for `{ properties: { next: { $ref: '#' } } }` from `blueprint.recursion.test.ts:11` there are no gates, so boundKey equals the root's, `templates.get` returns the template under construction and `constructing.get` is never evaluated; because boundKey contains key, a hit on an under-construction template always makes `has(key)` true), and call `validateShape` only when the flag is set.

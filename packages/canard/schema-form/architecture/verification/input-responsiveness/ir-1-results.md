## 원인 진단

## 구현과 비용

A는 보유에서 컴파일을 제거하고 첫 캐시 읽기가 이미 보유한 참조 수를 0으로 덮어쓰지 않게 합니다. 보유의 비용은 ledger 갱신뿐이며 첫 실제 읽기가 사본과 컴파일 비용을 부담합니다. 동기 가드와 정착은 유지됩니다. OnChange는 같은 마운트 layout effect의 검증에서 컴파일하므로 첫 키로 비용을 넘기지 않고, OnRequest는 첫 validate()에 비용을 넘깁니다. 재생성 실패 점검과 같은 $id 해제 순서를 유지합니다.

AB는 새 자식 프록시를 즉시 마운트한다고 판정할 때마다 폼 매니저의 계수를 올리고 첫 증가에서 예약한 microtask가 계수를 0으로 되돌립니다. eagerCount 20은 가지별 선행 창과 작업당 예산에 함께 쓰며 컨테이너도 계수합니다. 작은 가지는 기존 forChild에 index 0을 전달해 가지별 제한만 건너뜁니다. 메서드나 공개 옵션을 추가하지 않았습니다. 기존 캐시에 있는 자식과 이미 노출한 노드의 identity를 보존합니다. React18 StrictMode의 반복 계산에는 작업별 WeakSet으로 같은 eager 결정을 재사용합니다. 보완 전 기존 StrictMode 시험에서 f02가 지연되는 실패를 확인했고 단언을 바꾸지 않았습니다. 추가 메모리는 매니저별 계수와 해당 작업에서 eager로 결정한 노드들의 약한 집합이며 microtask에서 새 집합으로 교체합니다.

배열 교체 뒤 cache miss에서도 같은 게이트에 도달하며 200개 터미널 교체 render 시험은 동기 입력 20개·placeholder 180개를 확인합니다. 뷰포트 rootMargin, Focus/Select 강제 노출, RequestRefresh 제외, estimateHeight 예약과 defer-once를 유지합니다. SSR/IntersectionObserver 부재/비활성에서는 매니저가 null이므로 작업 예산도 적용하지 않습니다. virtualization 기본값은 계속 꺼짐입니다.

## 측정

정숙 관찰 16회가 모두 0표본으로 거절된 뒤 소유자가 상대 비교 창을 승인했습니다. L/E0/A/AB를 같은 창의 새 페이지로 다시 측정하고 표본마다 순서를 한 칸씩 순환합니다. 같은 픽스처·표본 번호의 L을 짝으로 차이와 비율을 계산하며 외부 CPU를 페이지마다 보존합니다. 관문은 같은 창 AB/L에 IR-0 정숙 L을 곱해 환산하고 최대 통계와 p95는 잠정으로 표시합니다. 2분 간격 백그라운드 30초 관찰이 성공하면 최대 통계 의존 행만 별도 정숙 창에서 다시 측정합니다. 시간 집계는 IR-0과 같은 표본별 중앙값·p95 뒤 표본 중앙값들의 중앙값·p95들의 nearest-rank p95입니다. Long Animation Frames 미검출은 0ms로 해석하지 않습니다. 구조 변경의 off와 명시적 on 변형을 따로 기록합니다.

array-1000은 세 후보 모두 전체 마운트 최장 50ms 조건을 넘었으며 A도 57.600ms였습니다. 첫 eager paint 뒤 backfill 구간에서는 세 후보 모두 ≥50ms 프레임이 검출되지 않았습니다. flat에서는 25/4, array에서는 50/8이 전체 노출 시간이 가장 짧았습니다. 전체 마운트 조건만으로는 후보가 없어 코디네이터에게 질문했고 25/4 유지 답변을 받았습니다. array의 초과 프레임은 A(57.600ms)와 모든 변형에서 같은 첫 eager 마운트 구간에 있고 backfill 매개변수로 없앨 수 없습니다. backfill 구간으로 판정하면 세 후보 모두 통과하지만 두 폼에서 동시에 전체 노출을 최소화하는 후보가 없으므로 기존 25/4를 유지합니다. 50/8은 flat을 2.35배 늦추며 개수와 최소 잔여 예산을 함께 바꾸므로 array 개선을 어느 변수에 귀속할 수 없습니다. 8ms 최소 예산이 idle 기회를 많이 건너뛰고 큰 개수는 무거운 항목을 빠르게 처리한다는 설명은 가설입니다. 50/4처럼 개수만 바꾸거나 시간으로 reveal을 제한하는 방식은 미측정 후속 항목입니다. array 첫 프레임의 eager 창과 전량 노드 트리 구성 비용도 미결로 남깁니다. 기존 프로파일 이상으로 귀속하거나 추가 프로파일하지 않았습니다.

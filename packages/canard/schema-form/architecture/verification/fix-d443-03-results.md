# D443-03 — 사전 공표 뒤 옮긴 게이트의 변경된 읽기 재예약

**TEST-027 수용 보류: 이 수정은 소유자의 마지막 검증 전까지 병합 대상이 아닙니다.** 구현·회귀 검증과 요청한 측정 자료 수집을 완료했으며, nested-d6 통제 행의 입증(느림)을 그대로 기록합니다.

## 원인과 적용 규칙

`selectChildren`의 `flushPendingOutput`이 루트 출력을 먼저 공표하면 라운드 끝 `updateOutput`은 변경 없음으로 답했습니다. 그 결과 `outputChanged`에만 연결된 기존 예약이 실행되지 않아, 옮긴 게이트가 읽은 값이 바뀌어도 선언 호스트까지 다시 계산하지 않았습니다. 수정 전 공개 재마운트 비교에서는 shallow·deep relocated 장면이 prefix 2에서 각각 자식 누락을 보였습니다.

SETTLE-045에 따라 옮긴 게이트가 실제로 읽은 경로와 값을 정착마다 기록합니다. 로드가 아닌 쓰기에서 라운드 중 출력 참조가 바뀌었으나 라운드 끝 갱신이 이를 보고하지 않으면, 기록된 경로를 다시 읽어 `Object.is`가 달라진 발생만 기존 `scheduleRelocatedGates`에 넘깁니다. L부터 선언 호스트까지 기존 바퀴 안에서 다시 계산하며, 실제 재예약이 일어난 때만 바퀴 변경 판정과 정지 조건에 반영합니다.

기존 전체 재예약 두 위치와 바퀴 예산, off/table/verify 선택 모드, record/skip/shadow 바퀴 모드, S1–S6, EVENT 계약, 공개 `src/index.ts`는 유지합니다. 추가 비용은 옮긴 게이트의 실제 평가마다 읽기 기록 객체 하나와 Map 갱신이며, 사전 공표 변화가 감지된 라운드에서는 기록된 읽기를 재확인합니다. 읽기 기록은 정착 호출 안에서만 유지합니다.

## 관찰 단언 변경 이유

이 단언은 사전 공표에 가려 옮긴 게이트를 다시 평가하지 않던 구현의 특성화였습니다. SETTLE-045는 옮긴 게이트를 L의 매 바퀴 평가하라고 정하므로, current가 공표된 뒤 라운드의 관찰은 완성된 루트를 읽습니다. 같은 바퀴에 들어온 사촌은 보이고 계산 중인 current는 섞이지 않는다는 51C-01과 18C-15의 성질은 첫 관찰 묶음으로 그대로 단언합니다.

새 단언은 첫 묶음이 `{ first: { value: 'entered' } }`이고, 그 뒤 모든 관찰이 완성된 `root.emit`과 같음을 확인합니다. 실제 결과는 이 순서와 일치했습니다.

### 설계 검토 예상과 실제 측정의 대조

설계 검토는 gate-form-one-key 입력, gated-array와 fixed-index 쓰기, whole-array 쓰기에 읽기 기록·재예약 비용이 생길 것으로 예상했고, whole-array 쓰기는 느림이 입증될 가능성을 명시했습니다. 이번 정본 게이트 8행은 모두 폭 (다)에서 미입증입니다. whole-array write의 +2.114%/+5.456%도 두 비교가 함께 폭을 넘지는 않았으므로 느림으로 판정하지 않습니다. gate-form-one-key-1000 input의 +3.773%/+3.460% 역시 폭 안에서 미입증입니다.

설계가 동치를 예상한 oneOf 전환·마운트는 개별 행과 가족 기울기에서 느림이 입증되지 않았습니다. 반면 nested-d6 bulk 통제는 예상과 달리 +4.127%/+3.412% 느림이 입증됐습니다. flat 통제는 설계가 언급한 flat-500 대신 코디네이터 지정 flat-1000 bulk이며 미입증입니다. 이 차이를 숨기거나 원인을 확인하지 않은 채 잡음이라고 해석하지 않습니다.

설계의 gated-array write에 대해서는 이번 정본의 mount·remove-0을 측정했으므로 일반 write의 성능을 주장하지 않습니다. presence-index write도 영향 예상 행이었으나 코디네이터 지정 20행에서 제외되어 미측정입니다. 성능 수용과 추가 검증 여부는 TEST-027에 따라 소유자의 마지막 검증에 남깁니다.

## D443-02와의 상호작용

같은 settle DETAIL 항목과 `settlement.ts`의 인접 필드가 겹칩니다. D443-02 뒤 등록된 자식은 같은 라운드에서 계산되어 읽기를 다시 기록하므로 새 비교가 같은 값을 보면 이중 예약하지 않습니다. 합친 코드에서 relocated·overlay·corpus와 gate-table의 overlay projection 스냅숏은 코디네이터가 재확인합니다.

원장 보충은 코디네이터가 round-443 마감 때 443C 번호로 기록합니다. FCA도 코디네이터가 실행합니다.

## 검토 참고

측정 창 대기 중, 기존 p/q/z 장면에서 q 뒤에 신원을 유지하는 항상 참 게이트 필드를 두어 q 출력을 라운드 끝 전에 flush하게 만드는 반례 가능성을 정적으로 제안했습니다. 이는 실행으로 확인한 결과가 아니며 추가 시험으로 넣지 않았습니다. 실제 정지 조건 증거는 설계자가 교정한 X.current 장면입니다.

기준 파일 목록은 기준 커밋의 git ls-tree에서 구했습니다. 그래서 현재 삭제하거나 이름을 바꾼 기준 파일도 분류에서 사라지지 않습니다. 기준 TypeScript 선언 분류는 기준 소스 내용을 compiler host에 공급하여 다시 수행했고, 파일·행·열 위치로 각 실제 속성 일치를 대조했습니다. 주석의 노드 접근과 문서 표의 첫 속성 셀은 별도 문맥으로 판단했습니다. 소스의 DOM node와 schema target은 노드 API로 잘못 분류하지 않았습니다.

cx12의 시나리오와 story 파일 이름은 입력 플래그 의미의 rename이며, 놓친 파일 이름 자체도 line 0인 별도 행으로 남겼습니다. 그 밖의 행 번호는 각 소스의 실제 행입니다. 기준의 rename 수에는 이 두 경로 행이 포함됩니다. 마이그레이션 표의 source 열과 부재 단언의 옛 이름은 계속 자료로 보존합니다.

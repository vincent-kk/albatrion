# X1 어휘 검색 분류

기준 커밋: `61457653ae19dfb1f11b97e29355fa3cd6af8f24`.

Amendment 1의 검색 범위는 저장소 전체의 텍스트입니다. `src/__legacy__/`, architecture의 누적 기록, 날짜가 있는 성능 보고서와 측정 결과, 생성된 dist 및 의존성은 제외했습니다. 비밀 설정은 읽지 않았습니다. 분류 파일은 정규식의 각 일치를 파일·행·열로 구분하며 기준과 현재 결과를 함께 보존합니다.

검색식은 다음과 같습니다.

```regex
\bDirty\b|\bdirty\b|DIRTY_|`(?:enabled|misfit|visible|active|readOnly|disabled|required)`|\.(?:enabled|misfit|visible|active|readOnly|disabled|required)\b
```

현재 rename 잔여는 0입니다. 기존 trace의 TypeScript 선언 분류기를 현재 소스에 다시 적용했으며, 옛 노드 속성의 PUBLIC·RECORD·RUNTIME·ENGINE_RUNTIME_TYPES 읽기는 0입니다. 추론되지 않은 읽기도 검토했습니다. 스키마·controls·DOM·React props·작성 데이터의 키 및 재계산 관찰 자료이며 노드 getter의 옛 이름으로 읽는 곳은 없습니다.

`keep-recompute`는 정착 dirty 경로·무효화·재계산 후보와 저장된 관찰 이력입니다. `keep-schema-controls-props`는 스키마·controls·React props 및 다른 API/작성 데이터의 속성입니다. 마이그레이션 표의 왼쪽 열과 제거한 속성의 부재를 확인하는 음성 단언은 옛 속성의 철자를 의도적으로 보존한 자료이며 현재 접근이나 호환 별칭이 아닙니다.

재검토한 현재 명세에는 영문·국문 README와 SPECIFICATION, 문서 사이트의 core-concepts·quick-start·api-reference·examples, QUICK_REFERENCE, agent 지식 문서, 노드 및 컨텍스트 계약 문서, JSDoc와 stories가 포함됩니다. 저장소 skills의 일치는 React/DOM props 또는 schema/controls 키여서 이름을 유지했습니다. ajv6/7/8의 FormError story export와 레이블은 새 이름으로 변경했습니다.

`x1-classified.tsv`의 base 행은 변경 전 검색 결과이고 head 행은 현재 소스 검색 결과입니다. 기준의 rename 분류를 구현·현행 문서에 반영했으며 기록은 덮어쓰지 않았습니다. TSV에는 기계 경로가 아닌 저장소 상대 경로만 기록합니다.

## 측정 정의

코어·탐침은 프로세스마다 각 판 20회 예열 뒤 100표본을 채취했습니다. 한 프로세스에서 두 판을 표본마다 AB/BA 순서로 적재·실행하며, 각 행은 독립 프로세스 세 개입니다. 시간은 **세 실행 최소값의 중앙값**, 폭은 **세 실행 최소값의 최댓값−최솟값**입니다. Δ ms는 새 판−0.16.1, Δ %는 `(새 판 / 0.16.1 − 1) × 100`입니다. 표의 표시값은 반올림했으며 Δ는 반올림 전 값으로 계산했습니다.

마운트는 청사진 생성·트리 생성·마운트·자식부터 값 실체화를 포함합니다. 단일 입력은 잎 10개에 1회씩 동기로 쓰는 묶음이고, 분기 전환은 `kind_0 → kind_79 → kind_0`의 실제 왕복 두 회입니다. 일괄 입력은 루트 `setValue` 한 번으로 모든 잎을 교체합니다. N은 분기 수·필드 수·잎 수이며 단일 입력의 변경 횟수가 아닙니다. 탐침은 [tools/README.md](./tools/README.md)의 정의를 따릅니다.

**단일 입력 묶음은 이 단계 안의 비교에만 씁니다.** 소실된 443b 실행기의 해당 행과 같은 정의라고 주장하지 않습니다. 아래 443b 참고 열은 [복구 기록](../perf-optimization/final-measure-443b.md)의 숫자이며 다른 커밋·다른 창의 값입니다. 참고 열은 비교 판정이나 개선·회귀의 인과 주장에 사용하지 않습니다. 같은 정의의 참고 행이 없으면 `—`로 표시합니다.

## 표 3. equivalent render 두 통과와 core 한 통과

기존 `benchmark-form --equivalent`를 `--min-samples=100 --legacy=0.16.1`로 실행했습니다. 각 판 10회 예열 뒤 100표본이며 표본마다 AB/BA로 번갈아 실행하고, 표본 전 GC를 수행합니다. `render`는 서로 다른 프로세스에서 두 통과, `core`는 한 통과입니다. 모든 fixture 19개를 포함했습니다.

# 07b 개선 항목 배정과 진행

07 보고서의 개선 목록([performance.md](../07-switch/performance.md)의 개선-01~35) 가운데 07b-1이 다루는 항목과, 다른 단계로 넘긴 항목을 이 표에서 추적합니다. performance.md의 "다룰 단계" 열은 07 보고서이므로 고치지 않습니다.

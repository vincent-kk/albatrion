# parsers

## Requirements

알 수 없는 입력을 타입별 값으로 파싱하되 스키마 검증과 분리합니다.

## API Contracts

- 파싱 불가능한 입력에는 파서별 빈 결과를 반환하며 파싱 실패 자체를 예외로 전달하지 않습니다.
- 객체 파싱은 plain object만 받아 배열과 클래스 인스턴스를 일반 객체로 취급하지 않습니다.

## Acceptance Criteria

### parsers-contract — 관찰 가능한 동작

- 파서는 입력으로부터 결과를 계산하며 DOM·네트워크·파일 상태에 의존하지 않습니다.
- 같은 입력과 옵션은 같은 파싱 의미를 가지며 스키마 제약 검사까지 수행하지 않습니다.

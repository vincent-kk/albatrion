# navigation 계약

## Requirements

탐색은 시작 참조가 보는 형상을 읽습니다. 비활성 원본으로 노드를 만들거나 정착을 실행하지 않아 조회 한 번이 값·수명·배달 결과를 바꾸지 않게 합니다. 레코드의 구조적 계약만 소비하며 종류별 행과 상위 실행 계층에 의존하지 않습니다.

## API Contracts

문자열 경로의 정본은 [jsonPointer](../../../helpers/jsonPointer/DETAIL.md)입니다. 탐색은 파싱된 리터럴 이름과 심볼 연산자만 소비하며 같은 토큰을 다시 해석하지 않습니다. 공개 참조의 수명과 명령은 [surface](../../surface/DETAIL.md), 형상과 보유 원본의 구분은 [record](../record/DETAIL.md)가 소유합니다.

## Acceptance Criteria

### NODE-020 — 터미널 값 내부를 노드로 가장하지 않습니다

터미널 아래의 값 경로는 자식 노드 경로가 아닙니다. 값에 객체 키나 배열 자리가 있어도 조회를 위해 임시 노드를 만들지 않습니다. 그렇지 않으면 터미널 전략을 선택해 피한 실체화 비용이 읽기에 숨어 들고 존재하지 않는 노드 수명을 약속하게 됩니다.

### NODE-043 — 형상에 없는 원본을 탐색으로 활성화하지 않습니다

탐색은 현재 `structure`의 이름만 따라갑니다. 보유 슬롯·선언 후보를 탐색 결과로 노출하지 않으며 터미널 아래와 형상 밖 모두 `find`는 `null`, `findNodes`는 빈 결과로 답합니다. 값 보존과 활성 노드의 존재를 분리하여 꺼진 분기를 조회만으로 실행하지 않습니다.

### NODE-054 — 가상 경로는 같은 노드의 별칭입니다

가상 그룹을 거쳐 찾은 자식은 참조된 형제 인스턴스 자체입니다. 요청 경로를 새 노드의 주소로 삼지 않으며 정본 주소는 반환된 `node.path`입니다. 이 구분이 없으면 같은 필드가 그룹 경로마다 다른 신원·쓰기 대상으로 보입니다. 맥락 `@`는 노드가 아니며 식의 맥락을 노드 트리에 합치지 않습니다.

### NODE-066 — 부재의 이유를 반환값으로 추정하지 않습니다

활성 노드가 없을 때 비활성과 미선언을 `null`·`undefined`로 나누지 않습니다. 비활성 선언이 항상 인스턴스나 보유 슬롯을 가진 것은 아니므로 이 구분은 믿을 수 없습니다. 비활성 노드 조회를 위해 중첩 게이트를 다시 계산하는 그림자 트리도 두지 않습니다. 단순 조회가 두 번째 정착 엔진과 별도 수명 관리를 요구하기 때문입니다.

### VALUE-041 — 이름 판독의 예외를 탐색기에 추가하지 않습니다

빈 이름과 예약 토큰 이름도 공용 문법이 돌려준 리터럴이면 자식 이름으로 조회합니다. truthiness나 별도 퍼센트 디코딩으로 거르지 않습니다. 루트·빈 이름·연산자를 소비처마다 달리 해석하면 탐색과 규칙 대상이 서로 다른 필드를 가리킵니다. 예약 퍼센트 표기와 충돌하는 선언 이름의 거부는 [buildNodes](../blueprint/buildNodes/DETAIL.md)가 소유합니다.

### navigation-shape — 순회의 참조 간선과 소유 간선을 구별합니다

기본 순회는 가상 참조로 같은 인스턴스에 다시 닿아도 한 번만 방문합니다. 내부 `owned` 순회는 부모가 실제로 소유한 간선만 따라 떼어진 가지도 정리할 수 있게 합니다. 둘을 섞으면 참조된 형제를 중복 처리하거나 다른 호스트의 자식을 폐기합니다. 방문 중 자식 변경의 전체 포착은 보장하지 않습니다. 공개 순회의 쓰기 배치는 write가 소유합니다.

### navigation-detached — 상대 경로가 옛 수명을 빠져나가지 않습니다

떼어진 참조의 상대 경로는 함께 떼어진 하위 트리에 머물며 부모 이동으로 살아 있는 부모에 넘어가지 않습니다. 절대 경로는 그 참조의 살아 있는 루트에서 풉니다. 상대 조회를 현재 노드로 전달하면 같은 옛 참조가 호출 시점에 따라 다른 수명을 가리켜 고정 읽기 계약을 깨뜨립니다.

## Last Updated

탐색 가능한 형상, 별칭의 정본 주소, 떼어진 참조의 경로 경계 또는 순회의 간선 의미가 바뀔 때 갱신합니다.

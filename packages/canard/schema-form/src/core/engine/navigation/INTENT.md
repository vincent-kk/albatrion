# navigation — 형상 조회의 경계

## Purpose

노드 참조의 자식 형상을 따라 경로를 찾고 순회합니다. 조회가 원본·형상·공개 수명을 바꾸지 않도록 탐색과 실행을 분리합니다.

## Conventions

- 공용 경로 해석기가 제공하는 이름과 연산자를 소비하며 문법을 재해석하지 않습니다.
- 가상 경로는 같은 인스턴스의 별칭이며 정본 주소는 반환한 노드의 `path`입니다.
- 기본 순회의 참조 간선과 내부 정리용 `owned` 순회의 소유 간선을 구별합니다.

## Boundaries

### Always do

- 형상 밖과 터미널 아래를 노드 부재로 처리하며 비활성과 미선언을 추정해 구별하지 않습니다.
- 떼어진 상대 조회는 함께 떼어진 하위 트리에 머물게 하고 절대 조회는 살아 있는 루트에서 풉니다.
- 가상 참조가 다른 호스트의 자식을 소유한 것으로 취급되지 않게 합니다.

### Ask first

- 부재의 반환 의미, 별칭의 신원 또는 떼어진 참조의 경로 경계를 바꾸는 경우.
- 경로 문법이나 순회의 간선 의미·방문 순서·변경 중 방문 보장을 바꾸는 경우.

### Never do

- 보유 원본을 조회 결과 노드로 되살리거나 탐색에서 정착·쓰기를 실행하지 않습니다.
- 종류별 행·`settle`·`write`·surface의 구현에 의존하지 않습니다.
- 공용 파서가 돌려준 리터럴을 truthiness나 자체 디코딩으로 다시 판정하지 않습니다.

# navigation — 현재 형상의 탐색 경계

## Purpose

노드의 현재 자식 집합을 따라 경로를 탐색하고 트리를 걷는 기능을 제공한다.

## Conventions

- 경로의 각 마디는 노드 종류와 상관없이 현재 `structure`의 자식 이름으로 푼다(NODE-043·054).
- 반환한 노드의 정본 주소는 요청한 경로가 아니라 `node.path`이다(NODE-054).

## Boundaries

### Always do

- 현재 형상에 있는 노드만 탐색한다. 터미널 아래 경로와 형상 밖 경로는 노드가 없는 것으로 처리한다(NODE-020·043).
- 떼어진 노드의 상대 경로는 마지막으로 함께 떼어진 하위 트리에서 푼다(NODE-044).

### Ask first

- 경로 문법이나 가상 참조 그룹의 주소 의미를 바꾸려는 경우.

### Never do

- 잠복 상태의 원본을 탐색 결과 노드로 되살리지 않고, 정착이나 쓰기도 수행하지 않는다(NODE-043·044).
- 상위의 `settle`, `FieldNode`, 레거시를 가져오지 않는다(NODE-016, LANDING-159).

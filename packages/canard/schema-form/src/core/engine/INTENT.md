# engine — 실행 조합

## Purpose

공유 실행 불변식을 소유하고 노드 표면을 위해 자식 계약을 조합합니다.

## Conventions

자식이 공유하는 헬퍼는 최저 공통 소유자에 둡니다. 자식 모듈은 형제의 진입점을 직접 소비합니다.

## Boundaries

### Always do

- source·computed·output 채널과 정착에서 배달로 이어지는 경계를 보존합니다.
- 공통 동등성·파생 기록 수명 규칙은 [엔진 계약](DETAIL.md)에 둡니다.
- 내부 시험 모드는 트리 생성 전에 설정하고 사용 후 복원합니다.

### Ask first

- 정착 순서·예산·배달 시점·바인딩 전용 내보내기를 바꿀 때.

### Never do

- 표면의 런타임 클래스·React·애플리케이션 플러그인 레지스트리를 가져오지 않습니다.
- 이 진입점에 자식 알고리즘을 두거나 패키지에서 내부 모드 제어를 노출하지 않습니다.

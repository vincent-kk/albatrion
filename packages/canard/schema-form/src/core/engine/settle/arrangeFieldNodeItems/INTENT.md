# arrangeFieldNodeItems

## Purpose

배열 행의 구조 계획을 살아 있는 아이템·경로 저장소·로드 스냅숏에 적용하고 동기 정착 결과와 구조 동사의 반환값을 확정한다(NODE-051·052, SURFACE-005, 35C-02·06).

## Conventions

- 기존 자리의 노드·키·배달 기준을 보존하며, 꼬리만 바뀐다는 증명이 있을 때만 접두를 재사용한다.

## Boundaries

### Always do

- 경로 이동은 충돌 없이 함께 적용하고 소멸 아이템의 마지막 읽기를 보존한 뒤 영향 저장소를 정리한다(NODE-044, 35C-02·09).

### Ask first

- 아이템 키 유지, 경로 재배치·소멸 순서나 접두 자격을 바꾸려는 경우.

### Never do

- 행의 순수 계획이나 배치 진입 사슬을 이 모듈에서 다시 구현하거나, 유지된 접두의 원본 트리를 재합성하지 않는다.

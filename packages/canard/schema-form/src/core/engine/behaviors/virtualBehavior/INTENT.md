# virtualBehavior — 참조 그룹 계산 경계

## Purpose

형제 노드의 편집 값을 선언 순서의 로컬 튜플로 묶는 계산을 소유합니다.

## Boundaries

### Always do

- 실제 형제를 참조하고 value 채널을 읽습니다. 그룹을 별도 데이터 소유자로 만들지 않습니다.

### Ask first

- 튜플 순서·값 채널·참조 그룹의 수명이나 자체 방출 부재를 바꿀 때

### Never do

- 가상 이름의 원본·방출을 만들거나 검증 데이터에 끼워 넣지 않습니다. 표시 묶음과 데이터 주소를 구별합니다.

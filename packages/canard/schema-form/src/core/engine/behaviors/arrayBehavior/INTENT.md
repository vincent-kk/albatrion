# arrayBehavior — 배열의 두 전략

## Purpose

배열 branch의 자리별 합성, terminal의 통째 값 투영과 두 전략의 순수 구조 계획을 소유합니다.

## Boundaries

### Always do

- 배열 위치를 유지하고 청사진 없는 값도 보존합니다. 생략 투영 때문에 뒤 아이템의 주소가 바뀌지 않아야 합니다.
- 살아 있는 아이템의 종류로 빈자리를 채우고, 꼬리 생략에서 실제 방출과 빈자리를 구별합니다.
- arrange는 계획만 반환합니다. 이동·생성·수명·스냅숏의 적용은 정착이 소유합니다.

### Ask first

- 자리별 청사진 선택, 비배열 원본 처리, 빈자리 채움 또는 꼬리 생략을 바꿀 때
- 배열 계획에 제약 강제나 새로운 상태 효과를 더할 때

### Never do

- branch와 terminal을 별개 종류로 나누거나 terminal에 아이템 노드를 만들지 않습니다.
- 투영을 원본 삭제로 구현하거나 행에서 노드 이동·폐기·통지를 확정하지 않습니다. 출력과 편집 수명을 구별합니다.

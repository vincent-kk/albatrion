# unionBehavior — 순서 없는 값 해석 경계

## Purpose

여러 종류를 허용하는 터미널의 제한된 해석과 통째 값 투영을 소유합니다. 공유 parse의 변환 정책은 이 모듈의 계약을 따릅니다.

## Boundaries

### Always do

- 멤버인 값은 유지하고 서로 다른 변환 결과가 하나일 때만 채택합니다. 선언 순서가 입력 의미를 결정하지 않아야 합니다.
- 불가·모호한 값과 통째 객체·배열의 참조를 보존합니다. 해석이 데이터 교정으로 넓어지지 않게 합니다.

### Ask first

- 멤버십·변환 표·동점 규칙 또는 변환을 끄는 정책을 바꿀 때
- 순수 해석을 공개 입력 API로 확대하거나 통째 값의 내부를 처리하려 할 때

### Never do

- type 목록 순서나 검증기 플러그인 규칙으로 변환 우선순위를 정하지 않습니다.
- 게이트 변화를 이유로 행에서 원본·경고등을 쓰지 않습니다. 목록의 선택과 재해석 시점은 정착이 소유합니다.

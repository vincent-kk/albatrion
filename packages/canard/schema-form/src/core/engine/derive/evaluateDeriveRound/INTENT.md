# evaluateDeriveRound — 한 라운드의 파생 후보 판정

## Purpose

완성된 형상에서 값 쓰기 규칙의 에지를 판정하고 대상마다 승자 하나를 돌려줍니다. 원본 적용과 라운드 진행을 분리하여 경쟁 규칙의 순위가 실행 순서에 따라 뒤집히지 않게 합니다.

## Conventions

- 규칙 표·기준점·대상 선택·식 평가는 부모 derive의 계약을 사용합니다.
- 동적 주입 대상과 순위 비교는 이 라운드가 소유하며 상호작용 초기화는 부모가 소유합니다.

## Boundaries

### Always do

- 진 후보와 undefined 결과의 에지도 소비하여 같은 변화가 다음 라운드의 새 기회가 되지 않게 합니다.
- 앞 라운드의 더 높은 종류 순위를 유지하고 모든 규칙 실패를 판정 결과에 남깁니다.
- 주입 대상은 현재 선택과 정적 후보를 구별하며 선언되지 않은 대상을 만들어 내지 않습니다.

### Ask first

- 종류·문서 순서·선언 층의 우선순위, 에지 발화 또는 주입 실패의 규칙 제외 범위를 바꿀 때.

### Never do

- 노드 원본·잠복 원본에 직접 쓰거나 정착 예산과 커밋을 수행하지 않습니다.
- 형상 밖 원천의 함수를 실행하거나 동적 대상 실패를 정적 선언 오류로 바꾸지 않습니다.
- 부모의 규칙 표 생성·상호작용 초기화를 이 자식으로 옮기지 않습니다.

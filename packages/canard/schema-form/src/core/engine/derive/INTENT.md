# derive — 파생 규칙 판정 경계

## Purpose

완성된 형상의 선언을 규칙 발생에 연결하고 파생 에지와 상호작용 초기화를 판정합니다. `controls.derived` 한 키보다 넓은 책임이며, 값의 실제 적용·재계산·커밋은 settle이 소유합니다.

## Conventions

- 규칙 표의 수명은 불변 청사진, 에지의 수명은 트리의 선언·대상 발생입니다. 같은 경로라는 이유로 수명을 합치지 않습니다.
- 에지의 동등성은 [engine 계약](../DETAIL.md)의 공통 판단을 사용합니다.

## Boundaries

### Always do

- 로드 범위의 새 기준과 일반 쓰기의 직전 커밋 기준을 구별하여 사용자 편집을 매번 덮지 않습니다.
- 조각·fields의 식은 선언 호스트에서 평가하고 대상별 발생과 선택 선언은 따로 유지합니다.
- 라운드 후보 판정은 자식 evaluateDeriveRound, 상호작용 초기화와 공통 규칙 결합은 이 모듈에 둡니다.

### Ask first

- 에지 기준·대상 수명, 호스트별 평가 범위 또는 개발 추적의 관측 범위를 바꿀 때.
- 규칙 표와 대상 메모의 소유 수명을 바꿀 때.

### Never do

- 원본을 직접 쓰거나 정착 라운드를 실행하고 예산·커밋을 소유하지 않습니다.
- settle의 실행 organ이나 형을 import하여 형제 모듈의 내부 표현에 결합하지 않습니다.
- 최종 형상에 없는 원천의 규칙을 평가하거나 개발 추적을 공개 API로 노출하지 않습니다.

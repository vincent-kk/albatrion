# validateChildTargets contract

## Requirements

fields 대상의 존재는 모든 본체·조건부·끌어올린 태그·가상 자식을 구성한 뒤 정적으로 확인합니다. 지금 꺼져 있다는 이유로 대상을 누락하면 유효한 조건부 선언이 오류가 됩니다.

## API Contracts

호출자는 선언 수집 중 fields가 있다는 단조 증거를 얻은 경우에만 검사합니다. discriminator만으로는 호출하지 않으며 선언 사이의 판별 키 일치도 검사하지 않습니다. 대상 이름은 데이터 경로가 아니라 해당 호스트의 직계 자식 이름입니다.

## Acceptance Criteria

### CONTROLS-073 — 정적 대상과 현재 형상을 구별합니다

어느 선언에도 없는 이름 또는 terminal 호스트의 대상은 작성 위치를 가진 CHILDREN_TARGET_NOT_FOUND입니다. 조건부 자식·끌어올린 판별 키·가상 이름도 대상이 될 수 있고, 같은 이름의 여러 종류 후보는 그 이름의 대상입니다. 형상에 없는 대상의 실행 정책은 [settle](../../settle/DETAIL.md)에 두어 정적 검사에 게이트 평가를 섞지 않습니다.

### child-targets — 전체 구성 뒤 검사합니다

구성 완료 전의 이름 집합으로 검사하지 않으며, 진단 위치는 JSON Pointer 이름 조립을 사용합니다. 예약 문자 때문에 오류가 다른 작성 위치를 가리키지 않게 합니다. 검사 생략은 무조건 실행하는 대조와 오류 순서를 유지합니다.

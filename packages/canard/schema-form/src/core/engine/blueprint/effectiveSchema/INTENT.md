# effectiveSchema

## Purpose

선택된 선언을 유효 스키마 힌트로 병합하고 불변 결과와 메모 참조를 보존합니다.

## Conventions

- 선언 문맥과 연언 문맥을 구별하여 분기 제약을 잘못 교차하지 않습니다.
- 정적 실패와 런타임 공집합·형 충돌의 표현을 구별합니다.

## Boundaries

### Always do

- 작성 값은 빌리고 생성 값만 보호합니다.
- 같은 선언 선택·검사 모드·원자 판정에는 같은 결과 참조를 사용합니다.
- 실행 규칙의 선언과 층을 단일 controls 힌트로 합치지 않습니다.

### Ask first

- 선언 선택·병합 정책·공집합 표현·동결·메모 계약을 바꿀 때

### Never do

- 작성 객체나 불투명 renderer 값의 내부를 동결하지 않습니다.
- 런타임 메모로 정적 오류 검사를 건너뛰지 않습니다.
- 게이트를 평가하거나 형 충돌의 실행 처분을 결정하지 않습니다.

# effectiveSchema

## Purpose

활성 선언의 전순서를 따라 유효 스키마를 병합하고 소유 값의 보호와 메모 참조를 보존한다.

## Conventions

- 정적 모드의 실패와 런타임 모드의 충돌 표현을 구분한다.
- 원자 판정 identity와 활성 선언 집합을 메모 문맥에 포함한다.

## Boundaries

### Always do

- 작성 값의 참조와 생성 값의 소유권을 구별한다.
- 같은 메모 문맥과 활성 집합의 결과 기록 참조를 재사용한다.

### Ask first

- 선언 선택 순서, 병합 정책이나 동결 및 메모 계약을 바꿀 때

### Never do

- 호출자가 작성한 객체나 불투명 renderer 값을 동결하지 않는다.
- 런타임 메모를 재사용해 정적 오류 검사를 건너뛰지 않는다.

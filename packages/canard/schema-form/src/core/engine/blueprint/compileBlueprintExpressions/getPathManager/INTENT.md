# getPathManager

## Purpose

한 번의 식 컴파일에 쓰는 순서 있는 의존 경로와 번호를 소유합니다.

## Conventions

- 등록과 조회에 같은 fragment 정규화를 사용합니다.
- 최초 등장 순서가 함수 인자 번호를 결정합니다.

## Boundaries

### Always do

- 절대 루트와 빈 이름 자식을 구별합니다.
- 호출자마다 독립된 등록부를 제공하고 반환 배열의 변경 소유권은 넘기지 않습니다.

### Ask first

- 정규화·등록 순서·배열 소유권을 바꿀 때

### Never do

- 폼 상태를 읽어 경로를 해석하지 않습니다.
- 식을 평가하거나 다른 컴파일의 등록부를 변경하지 않습니다.

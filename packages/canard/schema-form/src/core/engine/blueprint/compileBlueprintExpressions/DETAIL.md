# compileBlueprintExpressions contract

## Requirements

- 의존 경로의 분할과 와일드카드 판정은 jsonPointer 파싱 결과를 사용하고, 진단 위치는 이름 조립 API를 사용한다.

- 청사진과 컴파일된 식의 생성 고정 사실은 비열거·읽기 전용 속성으로 freeze 전에 정의한다. 기존 열거 관측에는 추가하지 않으며 직접 사실 조회와 모드 변경 뒤의 보존은 유지한다(D3b-2).

- 완전 읽기 증거는 컴파일 때만 판정해 식 기록의 선택적 completeReads=true로 freeze 전에 고정한다. 별도 전역 WeakSet에 등록하지 않으며 모드 전환이 이 생성 사실을 지우지 않는다.
- 완전 읽기 증명은 derive가 있는 청사진뿐 아니라 `active` 식에도 계산한다. 호출·대입·동적 접근·주변 이름을 거절하는 같은 비실행 스캐너를 재사용하며 게이트 입력 메모는 이 증거가 있는 식만 재사용한다. 읽기를 모두 열거할 수 없는 callback은 같은 인자에서도 기존 실행을 유지한다. 비용은 해당 식 원문 길이에 비례하는 컴파일 시 스캔이며 추가 런타임 필드는 없다.

작성된 선언과 게이트의 표현식을 컴파일하고 호스트별 정적 의존 경로를 등록한다.

## API Contracts

- 식 컴파일러는 이 모듈이 소유한다. 정적 의존은 모든 선언의 watch와 식 경로의 합집합이며, 실행 기준점은 해당 호스트다. 독립된 `*` 경로 조각은 허용하지 않고, 프로퍼티 이름에 들어 있는 별표는 보존한다(CONTROLS-080). 의존 사전은 프로토타입 이름과 충돌하지 않는다. 컴파일에 실패하면 schemaPath를 가진 청사진 오류가 된다.

- 식 기록은 선언 식별자, 작성 위치, 호스트, 제어 키(`ControlKey`), 상대 의존 경로, 컴파일된 함수를 보존하되 분석 중에는 실행하지 않는다. 공유 참조의 식은 연결별 호스트에 다시 결합하며, 최초 방문 위치에 고정하지 않는다.

## Acceptance Criteria

### expressions — 컴파일과 의존

- 옮긴 컴파일러의 기존 시험이 유지되고, 기준점, watch 합집합, 금지 경로, 컴파일 실패 위치를 검증한다.

# compileBlueprintExpressions

## Purpose

작성 선언의 식을 컴파일하고 호스트별 정적 의존과 비실행 증거를 준비합니다.

## Conventions

- 비활성 선언도 포함하며 watch와 식 경로의 최초 등록 순서를 보존합니다.
- 컴파일 문법·경로 등록부·동등식 증거는 각 자식이 소유합니다.

## Boundaries

### Always do

- 참조와 아이템의 식은 실행 발생의 호스트에 결합할 수 있게 상대 의존을 보존합니다.
- 실패에는 controls 키의 작성 위치와 원인을 남깁니다.
- 완전 읽기와 동등식 증거가 없으면 일반 평가 경로를 유지합니다.

### Ask first

- 식 문법·기준점·의존 정규화·증거 자격·컴파일 시점을 바꿀 때

### Never do

- 분석 중에 컴파일된 식을 실행하거나 살아 있는 폼 값을 읽지 않습니다.
- 컴파일 오류를 삼키거나 정적 증거의 실패를 식 오류로 바꾸지 않습니다.

# createDynamicFunction

## Purpose

작성 식을 경로 의존 배열을 받는 JavaScript 함수로 컴파일합니다.

## Conventions

- 경로를 등록한 뒤 그 순서의 배열 인덱스로 치환합니다.
- 비실행 인식기와 경로 치환을 공유해 실제 함수와 증거의 입력을 일치시킵니다.

## Boundaries

### Always do

- 식과 문장 몸통의 반환·불리언 강제 변환을 보존합니다.
- 컴파일 실패에 원문·생성 본문·원인을 남깁니다.
- 식의 전역 접근을 격리한다고 약속하지 않습니다.

### Ask first

- 허용 언어·치환·반환 의미·오류 정보를 바꿀 때

### Never do

- 컴파일 중 작성 식이나 폼 상태를 평가하지 않습니다.
- 오류를 빈 함수로 대체하지 않습니다.
- 생성 함수에 노드·렌더러 구현 의존을 넣지 않습니다.

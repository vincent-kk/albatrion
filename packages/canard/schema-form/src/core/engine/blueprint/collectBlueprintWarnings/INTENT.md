# collectBlueprintWarnings

## Purpose

관심 있는 진단 소비자에게 청사진의 선언 단위 경고(인라인 종단 예약 키, 판별자, 비객체 호스트의 `if` 등)를 수집해 전달한다.

## Conventions

- 경고는 `collect` 호출 한 번 안에서 (code, schemaPath, details.keyword) 키로 중복을 억제하고, 다른 수집기에는 캐시된 진단 재생으로 다시 전달한다.
- 경고는 선언의 스키마와 노드의 정적 종류만 읽고 값은 평가하지 않으며, `if`는 존재만 보고 내용을 읽지 않는다.
- 예약 키와 하위 위치는 하나의 종단 경고 기록에 모은다.

## Boundaries

### Always do

- 수집기가 있을 때만 경고 경로를 조사한다.
- 캐시 적중 후 늦게 붙은 수집기에도 루트당 한 번 경고를 제공한다.

### Ask first

- 경고 범위, 중복 기준이나 전달 시점을 바꿀 때

### Never do

- 인라인 하위 경고를 찾으려고 참조 대상을 따라가지 않는다.
- 작성된 데이터 내부를 변경하거나 경고를 정적 오류로 바꾸지 않는다.

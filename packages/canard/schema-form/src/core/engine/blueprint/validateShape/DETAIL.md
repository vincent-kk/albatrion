# validateShape contract

## Requirements

유한한 청사진 그래프와 유한한 런타임 형상은 다른 조건입니다. 템플릿 재사용만으로 무조건 생성되는 객체 사슬이 끝나지는 않으므로, 실제 값 평가 없이 정적으로 무한한 객체 형상을 거부합니다.

## API Contracts

호출자는 구성 중 템플릿 재진입 증거가 있을 때 검사를 실행합니다. 그 증거가 없으면 비순환 그래프이므로 생략해도 같은 결과이고, 증거가 있으면 오류 순서를 보존합니다. 게이트로 끊긴 순환의 실제 종료는 [settle](../../settle/DETAIL.md)의 책임입니다.

## Acceptance Criteria

### BLUEPRINT-030 — 무조건 객체 순환의 절단점

terminal·배열 아이템·게이트가 있는 선언 연결은 무조건 형상 확장을 끊습니다. nullable은 끊지 않습니다. 값을 null로 허용하는 것과 형상에서 자식을 제거하는 것을 혼동하면 끝나지 않는 객체 순환을 통과시키기 때문입니다. 무조건 객체 프로퍼티 사슬에서 같은 템플릿을 다시 만나면 작성 위치를 가진 RECURSIVE_SHAPE_UNBOUNDED로 거부합니다. 가드가 거짓인지 분석에서 실행해 보지 않습니다.

### recursion — 분석 종료와 형상 종료를 따로 검증합니다

조각 내부 참조 절단·배열·게이트·터미널의 유한 표본은 받으며, 무조건 객체 순환과 nullable만 더한 순환은 거부합니다. 형상 검증을 항상 실행하는 대조와 진단·오류 순서가 같아야 생략 증거를 사용할 수 있습니다.

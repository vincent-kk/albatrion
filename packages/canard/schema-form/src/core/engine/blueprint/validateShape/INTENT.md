# validateShape

## Purpose

유한 템플릿 그래프에서 무조건 객체 순환으로 생기는 무한 형상을 거부합니다.

## Conventions

- 무조건 객체 프로퍼티 연결만 확장을 계속합니다.
- 완료 집합과 현재 방문 집합은 검사 호출마다 소유합니다.

## Boundaries

### Always do

- 게이트·배열·터미널을 정적 확장의 절단점으로 인정합니다.
- 실패에 작성 위치를 보존해 순환 원인을 찾을 수 있게 합니다.

### Ask first

- 절단 조건·검사 생략의 증거·오류 순서를 바꿀 때

### Never do

- nullable만으로 형상이 끝난다고 판단하지 않습니다.
- 참조를 무한히 펼치거나 실제 게이트 값을 평가하지 않습니다.

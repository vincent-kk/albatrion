# validateShape

## Purpose

완료된 청사진 노드 그래프에서 무게이트 객체 순환과 무한 형상 확장을 검증한다.

## Conventions

- 객체 프로퍼티 에지만 형상 확장을 계속한다.
- 완료 집합과 현재 방문 집합은 검증 호출마다 소유한다.

## Boundaries

### Always do

- 게이트, 배열 아이템과 터미널을 형상 확장의 절단점으로 인정한다.
- 무한 형상 오류에 작성 위치를 보존한다.

### Ask first

- 형상 확장의 절단 조건이나 검증 순서를 바꿀 때

### Never do

- nullable만으로 순환이 끊겼다고 판단하지 않는다.
- 참조 템플릿을 무한히 펼치거나 실제 게이트 값을 평가하지 않는다.

# buildNodes

## Purpose

작성 스키마의 선언·조각·형을 분석하여 유한 템플릿과 호스트별 자식 연결을 구성합니다.

## Conventions

- 선언의 문맥·작성 위치·전순서를 보존합니다.
- 형상과 전략은 생성 때 결정하며 값과 게이트를 평가하지 않습니다.

## Boundaries

### Always do

- 연언과 선언 전용 분기를 구별해 분기 제약을 잘못 교차하지 않습니다.
- 참조 재사용과 재귀 연결에서도 실제 소유 호스트의 게이트를 보존합니다.
- 판별자는 명시된 키만 읽고 작성 스키마를 변경하지 않습니다.
- 소속 배열의 소유와 빌린 값의 참조를 구별합니다.

### Ask first

- 선언 확장 순서·종류 공유·형 추론·전략·판별자 처분을 바꿀 때
- 예약 키의 허용 범위나 참조 해석 범위를 바꿀 때

### Never do

- 게이트 배타성이나 수동 분기 선택을 추론하지 않습니다.
- 작성 스키마를 변경하거나 런타임 노드를 할당하지 않습니다.
- 불확실한 정적 증거로 검사를 생략하지 않습니다.

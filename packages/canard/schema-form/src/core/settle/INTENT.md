# settle — 동기 정착 경계

## Purpose

쓰기 한 진입을 표시·계산·전이·커밋하여 현재 형상과 방출 값을 확정합니다.

## Conventions

- 원본을 바꾸는 단계와 계산 단계를 구별하고, 상태는 `raw`·`extras` 둘만 둡니다(VALUE-002, SETTLE-002–006).
- 청사진은 선언과 식을 제공하고, 이 모듈이 게이트를 평가합니다(26C-04).
- PR-2의 예산은 호스트 바퀴와 전이 라운드입니다(TEST-069).

## Boundaries

### Always do

- 원본 B를 되돌림 기록으로 만들고 초과 뒤에도 진단이 기술하는 커밋을 확정합니다(SETTLE-011, ERROR-130).
- 로드와 일반 쓰기의 생김·에지 기준을 구별합니다(SETTLE-048·049).

### Ask first

- 호스트 바퀴의 시작점·전순서 또는 예산 식을 바꿀 때

### Never do

- 클래스에 정착 알고리즘을 넣거나 종류 행 구현을 직접 가져오지 않습니다(NODE-004·016).
- 전체 트리를 잎 입력마다 순회하거나 레거시 엔진을 가져오지 않습니다(SETTLE-047, LANDING-159).

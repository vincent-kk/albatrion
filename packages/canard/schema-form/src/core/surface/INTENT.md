# surface — 노드 겉면 경계

## Purpose

단일 런타임 노드와 공개 판별 형 사이의 경계를 소유합니다. 렌더러는 공개 노드와 바인딩 통로만 알면 되고 엔진 레코드의 내부 배치를 알 필요가 없어야 합니다.

## Conventions

- 공개 형의 종류 판별과 런타임 클래스의 수는 별개입니다. 종류별 구현을 클래스 계층으로 복제하지 않습니다.
- 노드 boolean은 `is` 접두사를 쓰며 React props의 이름과 혼동하지 않습니다.

## Boundaries

### Always do

- 공개 멤버 변경은 공개 형과 멤버 계약 시험에 함께 반영하여 구현과 선언이 갈라지지 않게 합니다.
- 종류·전략의 계산과 모든 쓰기는 엔진에 위임하여 겉면에 두 번째 정착 규칙이 생기지 않게 합니다.
- 실행 설정·검증 수명·입력 출처는 바인딩 전용 통로로 연결하여 소비자 API에 내부 제어가 새지 않게 합니다.

### Ask first

- 공개 멤버·가드·내부 바인딩 통로를 늘리거나 떼어진 참조의 수명을 바꾸는 경우.

### Never do

- 겉면 클래스에 정착·탐색·종류별 알고리즘이나 시험 전용 스텁을 넣지 않습니다.
- 비활성 값을 편집하기 위해 떼어진 참조를 새 인스턴스에 연결하지 않습니다.

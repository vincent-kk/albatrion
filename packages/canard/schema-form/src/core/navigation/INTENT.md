# navigation — 현재 형상의 탐색 경계

## Purpose

노드의 현재 자식 집합을 따라 경로 탐색과 트리 걷기를 제공합니다.

## Conventions

- 경로 마디는 노드 종류와 무관하게 현재 `structure`의 자식 이름으로 풉니다(NODE-043·054).
- 반환한 노드의 정본 주소는 요청 경로가 아니라 `node.path`입니다(NODE-054).

## Boundaries

### Always do

- 형상에 있는 노드만 탐색하고, 터미널과 형상 밖 경로는 노드 없음으로 처리합니다(NODE-020·043).
- 떼어진 노드의 상대 경로는 마지막으로 함께 떼어진 하위 트리에서 풉니다(NODE-044).

### Ask first

- 경로 문법이나 가상 참조 그룹의 주소 의미를 바꿀 때

### Never do

- 잠복 원본을 탐색 결과의 노드로 되살리거나 정착·쓰기를 수행하지 않습니다(NODE-043·044).
- 상위 `settle`·`SchemaNode` 또는 레거시를 가져오지 않습니다(NODE-016, LANDING-159).

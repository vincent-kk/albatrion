# Authored schema identity

## Purpose

Form 바인딩이 불필요하게 트리를 교체하지 않도록 작성 스키마의 동등성을 판정하고, 렌더러 값의 원자·터미널 판정을 core에 주입합니다.

## Boundaries

### Always do

- 객체 key 순서와 JSON 밖 원자 값의 참조를 보존합니다. 필드 순서나 컴포넌트의 교체를 같은 스키마로 오인하지 않아야 합니다.
- React 표식의 해석은 이 바인딩 경계에 두고 core에는 판정 함수만 전달합니다.

### Ask first

- 작성 스키마의 동등성이나 렌더러 원자·터미널 판정 기준을 바꿀 때

### Never do

- 비교하는 동안 스키마를 변경하거나 복제하지 않는다.

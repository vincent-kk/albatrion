# Focus target 계약

## Requirements

입력이 초점 대상을 명시할 수 있고 표시 위치마다 독립적으로 연결하고 해제할 수 있어야 합니다.

## API Contracts

위치 맵의 키는 실제 입력 컨테이너입니다. DOM 앵커는 연결된 같은 문서에 속해야 합니다. iframe의 DOM을 명령형 핸들로 오인하지 않도록 문서 검사 전에 네이티브 요소인지 확인합니다. 명령형 핸들은 소유자가 연결한 동안 사용할 수 있습니다. 폴백은 공급된 범위에서 문서 순서 첫 후보를 한 번 찾습니다.

## Acceptance Criteria

### focus-target-document — 실제 문서와 핸들을 구별합니다

같은 문서의 포털 대상은 사용할 수 있습니다. 분리된 DOM이나 다른 문서의 요소에는 폴백을 사용합니다. 마운트 판정에서만 네이티브 비활성 상태를 검사합니다.

## Last Updated

위치의 소유권이나 대상 자격이 바뀔 때 갱신합니다.

# fieldLifecycle

## Purpose

입력 위치의 라이프사이클에 실행할 일회성 예약과 행동 값을 정의합니다. 노드 엔진에 React 수명이나 DOM 상태를 넣지 않고 렌더 소비자들이 같은 예약 계약을 사용하게 합니다.

## Conventions

- 레지스트리는 React와 DOM을 모르며, 실행 시점과 행동 실행은 입력 위치가 소유합니다.
- 처리기는 동결된 사건과 클로저를 읽고 행동 값만 반환합니다. 폼·DOM·React 상태에 쓰지 않습니다.
- 내부 전용 경계입니다. 외부 소비자가 작성할 처리기의 쓰기 차단과 공개 API는 이 계약에 포함하지 않습니다.

## Boundaries

### Always do

- 일회성 FIFO와 실행 전 큐 분리를 유지하여 재예약이 같은 실행에 들어오지 않게 합니다.
- 행동은 입력 위치에서 처리기가 모두 끝난 뒤 합쳐 실행합니다.

### Ask first

- 공개 API, 지속 구독 또는 새로운 행동을 추가할 때

### Never do

- 노드별 마운트 수를 추적하거나 예약만으로 React 렌더를 일으키지 않습니다.
- 패키지 공개 진입점에 라이프사이클 이름을 내보내지 않습니다.

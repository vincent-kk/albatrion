# FieldLifecycleRegistry

## Requirements

폼 인스턴스마다 큐를 분리하고 비어 있는 경로의 확인 비용을 비트 읽기로 제한합니다.

## API Contracts

- 시점별 Map에서 노드마다 큐 하나를 보유합니다. 실행 전에 큐를 떼어 내므로 실행 중 재예약은 다음 시점까지 남습니다.
- 취소는 해당 항목만 제거합니다. 큐 분리 뒤 차례가 오기 전 취소도 유효하며 실행 뒤 취소는 아무 효과가 없습니다.
- 한 실행의 사건은 동결하여 공유하며 행동 결과는 비트 OR로 합칩니다. 처리기 오류는 던지지 않는 보고기에 전달하고 None으로 계산합니다.
- 전체 초기화는 제공하지 않습니다. 소비자가 자기 예약을 취소하고 폼과 함께 레지스트리가 회수되어야 다른 소비자의 예약을 지우지 않습니다.

## Acceptance Criteria

### lifecycle-queue — 일회성·취소·격리

FIFO, 두 번째 실행의 None, 재예약의 다음 실행, 실행 전·분리 뒤·실행 뒤 취소, pending·has의 일관성, 행동 합치기, 오류 뒤 계속 실행, 노드·시점별 분리를 확인합니다.

## Last Updated

큐 분리, 취소, 오류 보고 또는 빈 경로 비용의 계약이 바뀔 때 갱신합니다.

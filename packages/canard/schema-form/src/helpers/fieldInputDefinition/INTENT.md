# fieldInputDefinition

## Purpose

소비자가 넘긴 입력 맵과 정의를 정규화하고, 해석된 각 입력을 소유 지점에서 한 번만 격리한다.

## Conventions

- 유효한 React 컴포넌트만 남긴다.
- 경계는 원본 입력의 적용 세대 key 바깥에 둔다.
- 렌더 중에는 입력의 명시적인 path로 현재 보고기를 읽는다.
- 맵 key는 `^`로 시작하는 정규식, 단일 세그먼트 `*` wildcard, 정확 경로 순으로 분류한다. 객체 형태의 테스트는 함수로 정규화한다.

## Boundaries

### Always do

- 정규화된 모든 입력을 격리하고, 유효하지 않은 컴포넌트는 조용히 건너뛴다.
- 입력 경계 감싸개에서 적용 세대를 소비하고 Refresh 동작을 그대로 유지한다.
- 정의 객체의 정체성을 유지하며, 정의를 바꿀 때 새 객체를 요구한다(캐시된 시험·감싸개와 작성된 설정의 불일치를 막는다).

### Ask first

- wildcard 매칭이나 정규화된 정의의 인터페이스 변경
- 객체 시험의 허용 키·경고 조건이나 정의 캐시의 수명을 바꿀 때

### Never do

- 정확 경로를 암묵적인 정규식으로 해석하지 않는다. 객체의 자손 입력까지 의도 없이 교체하는 것을 막기 위해 정규식은 `^`로 명시한다.
- 정규화 중에 컴포넌트를 렌더하거나 훅을 실행하지 않는다.

# FieldInputBoolean 계약

## Requirements

불리언이 아닌 저장값을 정상적인 켜짐이나 꺼짐으로 가장하지 않습니다. 입력 표시를 고치려고 노드 값을 강제로 변환하지 않습니다.

## API Contracts

- 공통 무효 표시와 값 보존 정책은 [상위 계약](../../DETAIL.md)에 둡니다.
- 체크박스의 미정 표시는 형의 표현이며 검증 결과가 아닙니다. 값 부재나 nullable null도 불리언이 아니므로 미정일 수 있으며, 미정이라는 이유로 오류를 새로 만들지 않습니다.

## Acceptance Criteria

### REACT-027 — 불리언 아닌 값을 거짓으로 그리지 않습니다

- 불리언 아닌 값에는 `indeterminate`를 설정하고, 정확히 `true`인 값만 체크합니다. truthy 판정을 쓰면 객체·문자열을 유효한 참으로 오인하게 됩니다.
- 사용자 체크 조작은 불리언을 보내며 렌더만으로 값을 고치지 않습니다. readOnly는 체크박스를 비활성화하여 네이티브 조작을 막습니다.

### indeterminate — 형 표현과 오류 표시의 분리

- 미정 상태와 `misfit` 표지는 별개로 유지하여, 값 부재·nullable null과 어긋난 저장값을 같은 오류로 취급하지 않습니다.

## Last Updated

미정 상태·체크 판정 또는 체크박스 잠금의 표현이 바뀔 때 갱신합니다.

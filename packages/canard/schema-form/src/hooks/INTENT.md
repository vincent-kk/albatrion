# hooks

## Purpose

엔진의 동기 사건을 React의 노드 관찰·경로 선택·오류 집계·제출 상태로 연결합니다.

## Conventions

- 스냅숏이 정본이며 구독 전 사건의 재생을 전제로 하지 않습니다.
- 컴포넌트가 훅을 소비하는 역방향 형 참조는 type import로 제한하여 런타임 순환을 막습니다.

## Boundaries

### Always do

- useFieldErrors는 요청한 컴포넌트만 오류를 추적하고 같은 네 결과 값에는 같은 반환 참조를 유지합니다.

- 관찰 훅만 null·undefined를 구독 없는 상태로 받고 실제 노드에만 catch-up을 연결합니다. 필드 작업용 훅의 노드는 필수로 두어 부재 검사를 입력 구현에 퍼뜨리지 않습니다.
- 구독 연결 때 현재 스냅숏을 확인하여 숨김이나 렌더→commit 공백을 따라잡습니다.
- 대상 교체와 unmount에서 구독을 해제합니다.

### Ask first

- 공개 훅의 이름·인자·반환 형 또는 재연결 의미를 바꾸는 경우.
- 외부 소비자가 필요한 새 훅을 진입점에 추가하는 경우.

### Never do

- 노드 상태를 훅 내부에서 별도로 소유하거나 직접 수정하지 않습니다.
- ref 할당만으로 구독 대상이 갱신된다고 가정하지 않습니다.
